# dbt Cloud 전용 어댑터, 레이크하우스 데이터 변환을 연결하다

- 날짜: 2022-11-17 (기사·발표일)

- 정리 기준일: 2026-10-16

## 핵심 내용

- Databricks와 dbt가 dbt Cloud의 dbt-databricks 어댑터 지원을 발표했다. Unity Catalog의 3단계 이름 공간을 활용한다.
- 새 프로젝트는 새 어댑터를 사용하고 기존 프로젝트는 이전이 필요하다고 안내했다. 단순한 이름 변경에 그치지 않는 통합이다.

## 무엇이 달라졌나

SQL 변환의 테스트·문서화와 플랫폼의 권한 관리가 같은 개발 흐름에서 만났다.

## 앞으로의 관전 포인트 · 해석

분석 엔지니어의 협업 비용을 줄일 여지가 있다. 기존 모델의 동작과 권한을 시험 환경에서 비교하는 이전 절차가 중요하다.

## 사회적 쟁점과 한계 · 해석

자동 기본값이 조직의 접근 통제를 대신하지는 않는다. 잘못된 모델 의존성이나 권한 이전은 데이터 노출로 이어질 수 있다.
