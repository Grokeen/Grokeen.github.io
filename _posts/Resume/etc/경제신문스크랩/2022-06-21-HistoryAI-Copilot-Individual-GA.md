# GitHub Copilot 개인 정식 출시, 코드 제안의 구독화

- [원문: GitHub Copilot is now available to individual developers](https://github.blog/changelog/2022-06-21-github-copilot-is-now-available-to-individual-developers/)
- 날짜: 2022-06-21 (기사·발표일)
- 원문 발행일: 2022-06-21
- 자료 성격: 공식 연구·제품 발표 · GitHub
- 정리 기준일: 2026-10-16

## 핵심 내용

- GitHub가 편집기에서 코드를 제안하는 Copilot을 개인 개발자에게 정식 제공했다. 기술 미리보기에서 유료 구독 서비스로 전환했다.
- 당시 월 10달러·연 100달러와 일부 학생·오픈소스 관리자 무료 조건을 안내했다. 이는 출시 당시 조건이다.

## 무엇이 달라졌나

AI 코드 생성이 연구 시연을 넘어 일상적인 개발 도구의 구매 항목이 됐다.

## 앞으로의 관전 포인트 · 해석

작성 시간 절감과 검토 시간 증가를 함께 측정해야 한다. 개발자의 가치는 요구사항 판단과 검증으로 넓어질 수 있다.

## 사회적 쟁점과 한계 · 해석

그럴듯한 제안에 보안 취약점이나 라이선스 문제가 섞일 수 있다. 비밀정보 입력을 피하고 사람이 코드 책임을 맡아야 한다.
