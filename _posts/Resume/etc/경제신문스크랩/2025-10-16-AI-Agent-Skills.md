# Agent Skills, 업무 지식을 재사용 가능한 묶음으로

- [원문: Introducing Agent Skills](https://www.anthropic.com/news/skills)
- 날짜: 2025-10-16 (기사·발표 발행일)
- 자료 성격: 기업 공식 발표 · Anthropic
- 정리 기준일: 2026-10-16

## 핵심 내용

- 앤트로픽은 지침·스크립트·참고 자료를 폴더 형태로 제공하는 Agent Skills를 발표했다. 모델은 작업에 필요한 자료를 선택적으로 불러오도록 설계됐다.
- 초기 발표는 Claude 앱·Claude Code·API에 걸쳐 전문 작업 방식을 재사용하는 데 초점을 맞췄다.

## 무엇이 달라졌나

매번 긴 프롬프트를 복사하는 방식에서 업무 절차와 실행 도구를 함께 관리하는 방식으로 이동했다.

## 앞으로의 관전 포인트 · 해석

조직에서는 스킬의 버전, 담당자, 검증 결과를 관리해야 한다. 재사용 빈도보다 실제 산출물의 일관성과 오류 감소가 평가 기준이 될 수 있다.

## 사회적 쟁점과 한계 · 해석

외부 스킬에 실행 코드나 잘못된 지침이 포함될 수 있다. 출처 검토 없이 설치하거나 필요 이상의 파일 접근 권한을 부여하는 것은 위험하다.
