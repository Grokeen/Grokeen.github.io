# 텍스트·코드를 벡터로: 의미 검색을 API로 제공하다

- [원문: Introducing text and code embeddings · OpenAI](https://openai.com/index/introducing-text-and-code-embeddings/)
- 날짜: 2022-01-25 (기사·발표일)
- 원문 발행일: 2022-01-25
- 자료 성격: 공식 연구·제품 발표 · OpenAI
- 정리 기준일: 2026-10-16

## 핵심 내용

- OpenAI는 텍스트 유사도·텍스트 검색·코드 검색용 임베딩 모델과 API를 소개했다. 문서나 코드를 숫자 벡터로 바꾸어 검색·군집·분류 등의 입력으로 활용하는 기능이다.
- 키워드의 동일 여부 외에 학습된 표현 사이 유사도로 자료를 찾는 접근을 제공했다. 벡터가 가깝다는 사실이 두 문장의 사실관계나 업무상 적합성을 보증하는 것은 아니다.

## 무엇이 달라졌나

조직 내부 문서와 코드의 탐색을 자체 모델 구축 없이 시험할 수 있는 길이 넓어졌다. 활용 비용에는 API 호출 외에 색인 저장·갱신과 검색 품질 평가가 포함될 수 있다.

## 앞으로의 관전 포인트 · 해석

실제 업무에서는 관련 문서를 놓치는 비율과 잘못 가져오는 비율을 함께 측정해야 한다. 긴 문서 분할과 데이터 변경을 처리하는 방식이 품질을 좌우할 수 있다.

## 사회적 쟁점과 한계 · 해석

문서를 외부 서비스로 전송할 때 자료 이용 범위와 민감성을 검토해야 한다. 의미 검색은 접근 권한을 대신하지 않으므로 사용자별 문서 권한을 유지하는 설계가 필요하다.
