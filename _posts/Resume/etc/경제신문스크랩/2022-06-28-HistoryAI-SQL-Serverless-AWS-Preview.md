# SQL 서버리스 공개 미리보기, 대기·유휴 자원 비용을 줄이려는 경쟁

- [원문: Databricks SQL Serverless Now Available on AWS](https://www.databricks.com/blog/2022/06/28/databricks-sql-serverless-now-available-on-aws.html)
- 날짜: 2022-06-28 (기사·발표일)
- 원문 발행일: 2022-06-28
- 자료 성격: 공식 연구·제품 발표 · Databricks
- 정리 기준일: 2026-10-16

## 핵심 내용

- Databricks는 AWS에서 SQL 서버리스 계산의 공개 미리보기를 발표했다. 자원 준비·확장과 관리 작업을 서비스가 처리해 분석에 집중하도록 하는 방향이다.
- 현재 원문 상단의 정식 제공 후속 안내와 2022년 6월 28일 미리보기를 구분해야 한다. 비용 개선 사례는 고객 환경과 사용 패턴에 따라 달라지는 회사 측 설명이다.

## 무엇이 달라졌나

분석 비용의 경쟁 단위가 실행 장비 사양에서 유휴 시간과 운영 공수까지 넓어졌다. 서버리스 단가와 실제 가동 패턴을 함께 계산해야 총비용을 비교할 수 있다.

## 앞으로의 관전 포인트 · 해석

짧은 요청·동시 급증·긴 배치가 섞인 실제 이용에서 지연과 청구를 측정할 필요가 있다. 필요한 보안·네트워크 기능과 지역별 제공 범위도 확인 대상이다.

## 사회적 쟁점과 한계 · 해석

인프라 관리를 추상화해도 데이터 접근과 예산 통제는 필요하다. 예상보다 많은 자동 실행이나 쿼리 오류의 비용을 누가 감지·중단할지 정해야 한다.
