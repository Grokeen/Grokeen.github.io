# Spatial Lingo, 주변 물건에 외국어를 붙이는 공개 MR 학습 앱

- [원문: Spatial Lingo: An Open Source App for AI-Assisted Language Practice with Everyday Objects](https://developers.meta.com/vr/blog/spatial-lingo-open-source-app-ai-assisted-language-practice/)
- 날짜: 2026-01-22 (기사·발표일)
- 원문 발행일: 2026-01-22
- 자료 성격: 공식 오픈소스 앱 공개 · Meta
- 정리 기준일: 2026-10-16

## 핵심 내용

- Meta는 주변 물건을 인식해 영어·스페인어 단어와 연결하는 Spatial Lingo를 공개했다. Unity 프로젝트 소스와 미국 스토어의 체험 앱을 별도로 안내했다.
- 카메라 이미지의 객체 인식에는 YOLOv9, 잘라낸 이미지 해석·번역에는 Llama API 등을 사용한다. 전체 과정이 기기 안에서만 처리되는 앱으로 설명하면 안 된다.

## 무엇이 달라졌나

추상적인 단어 목록을 사용자가 실제 보는 사물과 연결한다. 공개 코드는 카메라·AI·음성·공간 UI를 결합하는 학습용 구현 사례가 된다.

## 앞으로의 관전 포인트 · 해석

다양한 물체·조명에서 인식 정확도와 잘못된 번역을 평가해야 한다. 재미있는 시연과 장기적인 학습 성과는 구분해 실험할 필요가 있다.

## 사회적 쟁점과 한계 · 해석

집 안 물건과 음성은 민감한 생활 정보를 포함할 수 있다. 외부 API 전송 경로와 비용·보존 정책을 확인하고 아동 대상 서비스에는 별도의 동의와 보호 설계가 필요하다.
