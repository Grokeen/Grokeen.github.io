# Quest RGB 카메라 API 공개, 현실 인식 앱의 배포 경로 확대

- [원문: Explore a New Era of Mixed Reality with the Passthrough Camera API](https://developers.meta.com/vr/blog/new-era-mixed-reality-passthrough-camera-api-machine-learning-computer-vision/)
- 날짜: 2025-04-30 (기사·발표일)
- 원문 발행일: 2025-04-30
- 자료 성격: 공식 API 공개 · Meta
- 정리 기준일: 2026-10-16

## 핵심 내용

- Meta는 v76에서 Quest 3·3S의 전면 RGB 카메라에 접근하는 Passthrough Camera API를 공개했다. 이를 쓰는 앱의 Horizon Store 게시도 가능하다고 안내했다.
- Android Camera2 기반으로 여러 개발 경로를 지원하며 브라우저 지원은 이후로 예고했다. 객체 인식·길 안내·현실 질감 활용은 응용 사례이며 API 자체가 정확도를 보장하지 않는다.

## 무엇이 달라졌나

개발자가 단순한 투과 화면 표시를 넘어 카메라 프레임을 직접 분석할 수 있다. 현실의 사물과 앱의 행동을 연결하는 범위가 넓어진다.

## 앞으로의 관전 포인트 · 해석

기기·엔진별 권한과 성능 제한, 배터리 비용을 확인해야 한다. 같은 카메라 API라도 앱마다 데이터 처리와 외부 서버 이용 방식이 달라질 수 있다.

## 사회적 쟁점과 한계 · 해석

방 안의 문서·얼굴·모니터가 앱에 노출될 수 있다. 권한 요청을 이해하기 쉽게 만들고 촬영 최소화·민감 영역 제외·보존 기간 제한을 함께 설계해야 한다.
