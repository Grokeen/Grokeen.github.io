# Stable Diffusion 공개, 이미지 모델을 직접 실행하는 생태계

- [원문: Stable Diffusion Public Release](https://stability.ai/news-updates/stable-diffusion-public-release)
- 날짜: 2022-08-22 (기사·발표일)
- 원문 발행일: 2022-08-22
- 자료 성격: 공식 연구·제품 발표 · Stability AI
- 정리 기준일: 2026-10-16

## 핵심 내용

- Stability AI가 Stable Diffusion의 공개 배포를 알렸다. 모델 가중치와 코드·모델 카드를 제공하고 당시 권장 가중치는 v1.4라고 안내했다.
- CreativeML OpenRAIL-M은 상업·비상업 활용을 허용하면서 사용 제한과 배포 시 조건 전달을 요구했다. 아무 제한 없는 라이선스는 아니다.

## 무엇이 달라졌나

이미지를 원격 서비스에 요청하는 방식 외에 모델을 직접 실행·수정하는 선택지가 커졌다.

## 앞으로의 관전 포인트 · 해석

특화 모델과 도구 생태계가 확장될 수 있다. 하드웨어 비용과 운영·안전 관리 부담도 사용자가 맡게 된다.

## 사회적 쟁점과 한계 · 해석

학습 자료의 저작권과 비동의 이미지 생성 문제는 라이선스 허용 범위와 별개다. 안전 분류기도 모든 오용을 막지는 못한다.
