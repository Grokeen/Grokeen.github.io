**학습 유형:** 그래프·추이 폐쇄

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

알려진 승패를 추이적으로 확장해 각 선수가 나머지 모두와 비교 가능한지 확인한다. 직접 경기 횟수만으로 순위를 결정하지 않는다.

## 풀이 순서

1. 승리 관계를 boolean 행렬에 기록한다.
2. i가 k를, k가 j를 이기면 i가 j를 이기는 것으로 확장한다.
3. 승리 또는 패배가 알려진 상대가 N-1명이면 센다.

## 풀이가 성립하는 이유

일관된 실력 순서 조건에서 경로로 이어지는 승리 관계는 비교 정보를 준다. 모든 다른 선수와 비교 가능하면 그 선수보다 위인 수와 아래인 수가 확정된다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(int n,int[][] results){boolean[][] win=new boolean[n][n];for(int[] r:results)win[r[0]-1][r[1]-1]=true;for(int k=0;k<n;k++)for(int i=0;i<n;i++)for(int j=0;j<n;j++)win[i][j]|=win[i][k]&&win[k][j];int answer=0;for(int i=0;i<n;i++){int known=0;for(int j=0;j<n;j++)if(i!=j&&(win[i][j]||win[j][i]))known++;if(known==n-1)answer++;}return answer;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(3,new int[][]{{1,2},{2,3}}));
    System.out.println(new Solution().solution(3,new int[][]{{1,2}}));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
3
0
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N³), 공간 O(N²).

자기 자신을 비교 수에 넣지 않는다. 모순된 경기 결과를 허용하는 일반 그래프와 문제의 실력 가정을 구분한다.
