**학습 유형:** 탐욕법·투 포인터

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

한 보트에 최대 두 명이라는 조건에서 가장 무거운 사람은 반드시 한 보트를 사용한다. 가장 가벼운 사람과 함께 탈 수 있으면 묶고 아니면 혼자 보낸다.

## 풀이 순서

1. 몸무게를 정렬한다.
2. 가장 가벼운 사람과 가장 무거운 사람의 합을 비교한다.
3. 무거운 사람은 항상 처리하고 가능하면 가벼운 사람도 처리한다.

## 풀이가 성립하는 이유

가장 가벼운 사람과도 못 타면 누구와도 함께 탈 수 없다. 함께 탈 수 있으면 그 둘을 묶는 최적해로 교환할 수 있어 필요한 보트 수를 늘리지 않는다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(int[] people,int limit){int[] a=people.clone();Arrays.sort(a);int l=0,r=a.length-1,count=0;while(l<=r){if(a[l]+a[r]<=limit)l++;r--;count++;}return count;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(new int[]{40,60,80},100));
    System.out.println(new Solution().solution(new int[]{50,50,50},100));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
2
2
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N log N), 공간 O(N) 원본 복사 포함.

두 명 제한이 없는 배낭 변형에 같은 논리를 쓰지 않는다. 마지막 한 명도 한 보트로 센다.
