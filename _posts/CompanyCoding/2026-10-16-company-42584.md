**학습 유형:** 단조 스택

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

가격이 처음 떨어질 때까지의 시간을 구한다. 아직 하락을 만나지 않은 인덱스를 스택에 두고 더 낮은 현재 가격이 오면 기간을 확정한다.

## 풀이 순서

1. 현재보다 높은 가격의 인덱스를 스택에서 뺀다.
2. 기간을 현재 인덱스-이전 인덱스로 적는다.
3. 끝까지 남은 것은 마지막 시점까지의 기간이다.

## 풀이가 성립하는 이유

스택의 각 인덱스는 지금까지 하락한 적 없는 후보이다. 더 낮은 값을 처음 만나는 시점에 제거하므로 정확한 최초 하락 시간을 얻는다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public int[] solution(int[] prices) {
    int n = prices.length,
      top = 0;
    int[] stack = new int[n],
      answer = new int[n];
    for (int i = 0; i < n; i++) {
      while (top > 0 && prices[stack[top - 1]] > prices[i]) {
        int j = stack[--top];
        answer[j] = i - j;
      }
      stack[top++] = i;
    }
    while (top > 0) {
      int j = stack[--top];
      answer[j] = n - 1 - j;
    }
    return answer;
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(Arrays.toString(new Solution().solution(new int[] { 3, 2, 2 })));
    System.out.println(Arrays.toString(new Solution().solution(new int[] { 5 })));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
[1, 1, 0]
[0]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N), 공간 O(N).

같은 가격은 하락이 아니다. 마지막 값의 기간은 0이며 마지막에 1을 더하지 않는다.
