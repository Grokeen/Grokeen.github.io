**학습 유형:** 그래프·사전순 오일러 경로

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

모든 항공권을 정확히 한 번 쓰는 경로를 ICN에서 시작한다. 목적지 최소 힙과 후위 경로 구성을 사용해 막히는 분기를 마지막 부분으로 배치한다.

## 풀이 순서

1. 출발지별 목적지 최소 힙을 만든다.
2. 스택에서 사용할 간선이 있으면 이동한다.
3. 더 갈 곳이 없으면 경로 앞에 넣으며 되돌아온다.

## 풀이가 성립하는 이유

Hierholzer 방식이 간선을 한 번씩 소비해 전체 경로를 합친다. 사전순 후보를 먼저 소비하되 후위로 결과를 만들어 남은 표를 못 쓰는 조기 막힘을 처리한다. 원문의 전체 사용 가능 조건을 사용한다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

```java
import java.util.*;

class Solution {

  public String[] solution(String[][] tickets) {
    Map<String, PriorityQueue<String>> routes = new HashMap<>();
    for (String[] t : tickets)
      routes.computeIfAbsent(t[0], k -> new PriorityQueue<>()).add(t[1]);
    Deque<String> stack = new ArrayDeque<>();
    LinkedList<String> answer = new LinkedList<>();
    stack.push("ICN");
    while (!stack.isEmpty()) {
      String from = stack.peek();
      PriorityQueue<String> next = routes.get(from);
      if (next != null && !next.isEmpty()) stack.push(next.poll());
      else answer.addFirst(stack.pop());
    }
    return answer.toArray(new String[0]);
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(
      Arrays.toString(
        new Solution().solution(
          new String[][] { { "ICN", "AAA" }, { "ICN", "BBB" }, { "AAA", "ICN" } }
        )
      )
    );
    System.out.println(
      Arrays.toString(
        new Solution().solution(new String[][] { { "ICN", "AAA" }, { "AAA", "ICN" } })
      )
    );
  }
}
```

## 기대 출력과 확인 관점

```text
[ICN, AAA, ICN, BBB]
[ICN, AAA, ICN]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(E log E), 공간 O(E).

매번 가장 작은 목적지만 바로 정답 배열에 쓰면 막다른 분기에서 실패한다. 동일 항공권도 개별 간선으로 보존한다.
