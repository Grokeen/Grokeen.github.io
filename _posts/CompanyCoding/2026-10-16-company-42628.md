**학습 유형:** 정렬 Map

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

최솟값과 최댓값 삭제를 모두 지원해야 한다. TreeMap에 값별 빈도를 저장하면 양 끝 키를 조회하면서 중복 원소도 정확히 관리할 수 있다.

## 풀이 순서

1. 삽입은 빈도를 늘린다.
2. 삭제는 firstKey 또는 lastKey의 빈도를 줄인다.
3. 빈도 0이 되면 키를 제거한다.

## 풀이가 성립하는 이유

Map의 각 빈도는 아직 삭제되지 않은 해당 값의 개수다. 양 끝 키가 실제 최소·최대이며 한 개씩 줄여 중복 삭제를 처리한다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public int[] solution(String[] operations) {
    TreeMap<Integer, Integer> count = new TreeMap<>();
    for (String op : operations) {
      String[] p = op.split(" ");
      int x = Integer.parseInt(p[1]);
      if (p[0].equals("I")) count.merge(x, 1, Integer::sum);
      else if (!count.isEmpty()) {
        int key = x == 1 ? count.lastKey() : count.firstKey();
        int left = count.get(key) - 1;
        if (left == 0) count.remove(key);
        else count.put(key, left);
      }
    }
    return count.isEmpty()
      ? new int[] { 0, 0 }
      : new int[] { count.lastKey(), count.firstKey() };
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(
      Arrays.toString(
        new Solution().solution(new String[] { "I 5", "I 5", "I -2", "D 1" })
      )
    );
    System.out.println(
      Arrays.toString(new Solution().solution(new String[] { "D -1", "I 1", "D 1" }))
    );
  }
}
```

## 기대 출력과 확인 관점

```text
[5, -2]
[0, 0]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N log U), 공간 O(U).

비어 있을 때 삭제는 무시한다. Set만 사용하면 같은 값 두 개를 한 번에 잃는다.
