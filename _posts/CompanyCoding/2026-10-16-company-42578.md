**학습 유형:** 해시·경우의 수

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

종류마다 의상 하나를 고르거나 아무것도 고르지 않을 수 있다. 종류별 선택 수를 곱하고 전부 안 입은 경우 하나를 제외한다.

## 풀이 순서

1. 종류별 의상 수를 센다.
2. 각 개수+1을 곱한다.
3. 모두 미선택한 1을 뺀다.

## 풀이가 성립하는 이유

서로 다른 종류의 선택은 독립적이며 같은 종류에서 동시에 두 개를 고르지 않는다. 곱의 법칙이 모든 조합을 세고 제외할 빈 조합은 정확히 하나다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(String[][] clothes){Map<String,Integer> count=new HashMap<>();for(String[] c:clothes)count.merge(c[1],1,Integer::sum);int ways=1;for(int x:count.values())ways*=x+1;return ways-1;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(new String[][]{{"hat1","head"},{"hat2","head"},{"shirt","body"}}));
    System.out.println(new Solution().solution(new String[][]{{"cap","head"}}));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
5
1
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

평균 시간 O(N), 공간 O(종류 수), 문자열 비용 별도.

종류별 합을 구하는 문제가 아니다. 실제 의상 조합을 전부 만들면 지수적 공간이 필요하다.
