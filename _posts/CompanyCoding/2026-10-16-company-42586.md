**학습 유형:** 스택·큐

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

각 기능의 완료 날짜를 올림 나눗셈으로 구한다. 앞 기능이 배포될 때 이미 끝난 뒤 기능을 같은 묶음으로 포함한다.

## 풀이 순서

1. (남은 진도+속도-1)/속도로 완료일을 계산한다.
2. 현재 배포일 이하인 뒤 기능은 묶음 개수를 늘린다.
3. 더 늦게 끝나는 기능을 만나면 새 배포 묶음을 시작한다.

## 풀이가 성립하는 이유

기능 순서를 바꿀 수 없으므로 배포일은 현재 묶음 첫 기능의 완료일이다. 뒤 기능이 그날까지 끝나면 함께 나가고 늦으면 새 기준일이 된다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public int[] solution(int[] progresses, int[] speeds) {
    List<Integer> batches = new ArrayList<>();
    int release = -1,
      count = 0;
    for (int i = 0; i < progresses.length; i++) {
      int day = (100 - progresses[i] + speeds[i] - 1) / speeds[i];
      if (day > release) {
        if (count > 0) batches.add(count);
        release = day;
        count = 1;
      } else count++;
    }
    if (count > 0) batches.add(count);
    return batches.stream().mapToInt(Integer::intValue).toArray();
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(
      Arrays.toString(
        new Solution().solution(new int[] { 90, 99, 99 }, new int[] { 1, 1, 1 })
      )
    );
    System.out.println(
      Arrays.toString(
        new Solution().solution(new int[] { 95, 90, 99 }, new int[] { 1, 1, 1 })
      )
    );
  }
}
```

## 기대 출력과 확인 관점

```text
[3]
[1, 2]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N), 공간 O(N) 결과 포함.

정수 나눗셈을 내림으로 쓰면 하루 일찍 배포된다. 완료 날짜를 정렬하면 기능의 원래 순서를 잃는다.
