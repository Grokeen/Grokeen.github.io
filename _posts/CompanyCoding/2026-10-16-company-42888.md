**학습 유형:** 카카오 공개 기출·해시

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

공식 분류는 2019 KAKAO BLIND RECRUITMENT다. 과거 메시지에도 최종 닉네임을 적용하므로 이벤트를 읽는 단계와 최종 문구를 만드는 단계를 분리한다.

## 풀이 순서

1. 입장·변경마다 사용자 ID의 최신 닉네임을 갱신한다.
2. 전체 기록을 다시 보며 입장·퇴장 이벤트만 선택한다.
3. 최신 닉네임으로 최종 메시지를 만든다.

## 풀이가 성립하는 이유

사용자 ID는 고정이고 닉네임만 변한다. 모든 변경 후 이름을 조회하면 과거 이벤트도 최종 이름으로 일관되게 표시된다. 변경 이벤트 자체는 출력 메시지가 아니다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public String[] solution(String[] record) {
    Map<String, String> names = new HashMap<>();
    for (String s : record) {
      String[] p = s.split(" ");
      if (!p[0].equals("Leave")) names.put(p[1], p[2]);
    }
    List<String> answer = new ArrayList<>();
    for (String s : record) {
      String[] p = s.split(" ");
      if (p[0].equals("Enter")) answer.add(names.get(p[1]) + "님이 들어왔습니다.");
      else if (p[0].equals("Leave")) answer.add(names.get(p[1]) + "님이 나갔습니다.");
    }
    return answer.toArray(new String[0]);
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(
      Arrays.toString(
        new Solution().solution(new String[] { "Enter u1 A", "Leave u1", "Enter u1 B" })
      )
    );
    System.out.println(
      Arrays.toString(
        new Solution().solution(new String[] { "Enter u2 X", "Change u2 Y" })
      )
    );
  }
}
```

## 기대 출력과 확인 관점

```text
[B님이 들어왔습니다., B님이 나갔습니다., B님이 들어왔습니다.]
[Y님이 들어왔습니다.]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

평균 시간 O(RL), 공간 O(RL), R은 기록 수.

닉네임은 서로 같을 수 있어 키로 사용하지 않는다. 재입장 때의 이름 변경도 반영한다.
