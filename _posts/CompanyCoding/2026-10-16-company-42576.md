**학습 유형:** 해시

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

참가자 이름의 빈도를 세고 완주자마다 하나씩 차감한다. 동명이인이 있을 수 있어 이름의 존재 여부만 저장하는 Set은 부족하다.

## 풀이 순서

1. 참가자 빈도를 Map에 저장한다.
2. 완주자 빈도를 한 번씩 뺀다.
3. 남은 양수 빈도의 이름을 반환한다.

## 풀이가 성립하는 이유

처리 후 빈도는 참가 횟수-완주 횟수다. 미완주자가 한 명이라는 조건에서 양수로 남는 이름이 답이다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public String solution(String[] participant,String[] completion){Map<String,Integer> count=new HashMap<>();for(String s:participant)count.merge(s,1,Integer::sum);for(String s:completion)count.merge(s,-1,Integer::sum);for(Map.Entry<String,Integer> e:count.entrySet())if(e.getValue()>0)return e.getKey();throw new IllegalStateException();}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(new String[]{"a","b","a"},new String[]{"a","b"}));
    System.out.println(new Solution().solution(new String[]{"solo"},new String[]{}));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
a
solo
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

평균 시간 O(N·L), 공간 O(N·L). L은 이름 길이.

동명이인을 제거하지 않는다. 이름 해시값을 더하고 빼는 방식은 충돌과 오버플로를 별도 고려해야 한다.
