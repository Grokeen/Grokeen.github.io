**학습 유형:** 동적 계획법·원형

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

원형으로 이웃한 집을 동시에 고를 수 없다. 첫 집과 마지막 집을 함께 고르지 않는 두 선형 문제로 나누어 최댓값을 비교한다.

## 풀이 순서

1. 마지막 집을 제외한 구간의 최대합을 구한다.
2. 첫 집을 제외한 구간의 최대합을 구한다.
3. 각 선형 구간은 선택·미선택 DP로 계산한다.

## 풀이가 성립하는 이유

유효 선택은 첫 집을 고르지 않거나 마지막 집을 고르지 않는 경우에 반드시 속한다. 각 구간의 최적값을 비교하면 중복은 있어도 해를 놓치지 않는다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public int solution(int[] money) {
    return Math.max(rob(money, 0, money.length - 2), rob(money, 1, money.length - 1));
  }

  int rob(int[] a, int start, int end) {
    int prev2 = 0,
      prev1 = 0;
    for (int i = start; i <= end; i++) {
      int now = Math.max(prev1, prev2 + a[i]);
      prev2 = prev1;
      prev1 = now;
    }
    return prev1;
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(new Solution().solution(new int[] { 5, 1, 1, 5 }));
    System.out.println(new Solution().solution(new int[] { 1, 2, 3 }));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
6
3
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N), 추가 공간 O(1).

선형 도둑질 결과를 그대로 쓰면 첫·마지막을 함께 선택할 수 있다. 두 경우를 명확히 분리한다.
