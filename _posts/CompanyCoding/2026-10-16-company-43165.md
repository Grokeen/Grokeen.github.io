**학습 유형:** DFS

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

각 숫자의 부호를 더하기 또는 빼기로 정한다. 순서를 바꾸지 않고 두 가지 선택을 모든 위치에 적용해 목표 합이 되는 경우를 센다.

## 풀이 순서

1. 현재 인덱스와 누적합을 상태로 둔다.
2. 다음 수를 더한 가지와 뺀 가지를 탐색한다.
3. 마지막 위치에서 목표와 같은 경우만 센다.

## 풀이가 성립하는 이유

각 부호 배치는 DFS 경로 하나와 일대일 대응한다. 숫자 값이 같아도 위치별 선택은 다른 배치이므로 별도 경로로 세는 것이 맞다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public int solution(int[] numbers, int target) {
    return dfs(numbers, target, 0, 0);
  }

  int dfs(int[] a, int target, int at, int sum) {
    if (at == a.length) return sum == target ? 1 : 0;
    return dfs(a, target, at + 1, sum + a[at]) + dfs(a, target, at + 1, sum - a[at]);
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(new Solution().solution(new int[] { 1, 1, 1 }, 1));
    System.out.println(new Solution().solution(new int[] { 2, 2 }, 4));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
3
1
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(2^N), 재귀 공간 O(N).

숫자를 재정렬하거나 같은 값의 선택을 중복 제거하지 않는다. 경우 수를 묻는 문제다.
