**학습 유형:** 정렬·문자열

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

두 숫자 문자열 a,b의 앞뒤 순서는 a+b와 b+a를 비교해 결정한다. 숫자 크기나 단순 사전순 정렬과 다른 기준이다.

## 풀이 순서

1. 정수를 문자열로 바꾼다.
2. b+a와 a+b를 비교하는 내림차순 기준으로 정렬한다.
3. 모두 0이면 하나의 0만 반환한다.

## 풀이가 성립하는 이유

두 이웃의 순서를 바꿨을 때 연결 결과가 더 큰 쪽을 앞에 두는 기준이다. 이 비교로 정렬한 연결 문자열이 최대가 된다. 결과가 매우 길 수 있어 정수로 파싱하지 않는다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public String solution(int[] numbers){String[] a=Arrays.stream(numbers).mapToObj(Integer::toString).toArray(String[]::new);Arrays.sort(a,(x,y)->(y+x).compareTo(x+y));if(a[0].equals("0"))return "0";return String.join("",a);}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(new int[]{12,121}));
    System.out.println(new Solution().solution(new int[]{0,0}));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
12121
0
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N log N·L), 공간 O(NL). L은 개별 숫자 길이.

12와 121처럼 접두사가 겹치는 경우를 확인한다. 000을 정답으로 반환하지 않는다.
