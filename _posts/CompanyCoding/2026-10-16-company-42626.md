**학습 유형:** 힙

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

가장 작은 두 값을 정해진 식으로 섞어 전체 최솟값을 기준 이상으로 만든다. 최소 힙은 매 단계 필요한 두 원소를 효율적으로 제공한다.

## 풀이 순서

1. 최솟값이 K 이상이면 종료한다.
2. 원소가 두 개 미만이면 실패다.
3. 작은 값+두 번째 작은 값×2를 다시 넣는다.

## 풀이가 성립하는 이유

문제 규칙이 섞을 두 원소를 최소 두 개로 지정하므로 각 연산은 유일하게 결정된다. 힙의 최솟값이 기준 이상이면 나머지 모두도 기준 이상이다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public int solution(int[] scoville, int K) {
    PriorityQueue<Long> q = new PriorityQueue<>();
    for (int x : scoville) q.add((long) x);
    int count = 0;
    while (q.peek() < K) {
      if (q.size() < 2) return -1;
      long a = q.poll(),
        b = q.poll();
      q.add(a + 2 * b);
      count++;
    }
    return count;
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(new Solution().solution(new int[] { 1, 2, 3 }, 7));
    System.out.println(new Solution().solution(new int[] { 1, 1 }, 10));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
2
-1
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N log N), 공간 O(N).

한 개만 남아 기준 미달이면 -1이다. 혼합 중간값은 long으로 계산한다.
