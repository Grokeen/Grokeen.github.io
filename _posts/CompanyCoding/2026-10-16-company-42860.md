**학습 유형:** 탐욕법·경로 비교

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

각 문자 변경의 상하 비용과 커서의 좌우 이동 비용을 분리한다. 좌우는 연속 A 구간을 건너뛰기 위해 어느 지점에서 방향을 바꿀지 모두 비교한다.

## 풀이 순서

1. 문자별 A에서 가까운 방향의 비용을 더한다.
2. 기본 좌우 비용을 N-1로 둔다.
3. 각 A 연속 구간 앞뒤에서 왕복 방향 두 경우를 비교한다.

## 풀이가 성립하는 이유

바꿀 필요 없는 A 구간을 방문 경로에서 제외할 수 있다. 방향을 바꾸는 위치를 모두 비교하며 오른쪽 구간을 왕복하는 경우와 왼쪽 구간을 왕복하는 경우를 포함한다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public int solution(String name) {
    int n = name.length(),
      vertical = 0,
      move = n - 1;
    for (int i = 0; i < n; i++) {
      int x = name.charAt(i) - 'A';
      vertical += Math.min(x, 26 - x);
      int next = i + 1;
      while (next < n && name.charAt(next) == 'A') next++;
      move = Math.min(move, Math.min(2 * i + n - next, i + 2 * (n - next)));
    }
    return vertical + move;
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(new Solution().solution("ABAAAAA"));
    System.out.println(new Solution().solution("BAAAB"));
    System.out.println(new Solution().solution("AA"));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
2
3
0
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N²), 공간 O(1). N은 이름 길이.

매번 가까운 문자만 찾아가는 단순 탐욕은 실패할 수 있다. 전부 A이거나 끝쪽 한 문자만 다른 경우를 확인한다.
