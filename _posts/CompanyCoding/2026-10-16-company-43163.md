**학습 유형:** BFS·문자열 그래프

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

한 글자만 다른 단어로 바꿀 수 있다. 단어를 정점, 한 글자 차이를 간선으로 보면 최소 변환 횟수는 BFS 거리다. 목표가 목록에 없거나 도달하지 못하면 0이다.

## 풀이 순서

1. 시작 단어 거리 0에서 큐를 시작한다.
2. 목록에서 한 글자 차이인 미방문 단어를 찾는다.
3. 목표를 꺼내면 거리, 끝까지 없으면 0을 반환한다.

## 풀이가 성립하는 이유

모든 변환 비용이 1이므로 BFS의 첫 도달이 최소 횟수다. 차이 개수를 정확히 1로 검사해 같은 단어나 두 글자 이상 바꾸는 이동을 제외한다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(String begin,String target,String[] words){Map<String,Integer> distance=new HashMap<>();Deque<String> q=new ArrayDeque<>();q.add(begin);distance.put(begin,0);while(!q.isEmpty()){String s=q.poll();if(s.equals(target))return distance.get(s);for(String next:words)if(!distance.containsKey(next)&&diff(s,next)==1){distance.put(next,distance.get(s)+1);q.add(next);}}return 0;}int diff(String a,String b){int count=0;for(int i=0;i<a.length();i++)if(a.charAt(i)!=b.charAt(i))count++;return count;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution("aaa","bbb",new String[]{"aab","abb","bbb"}));
    System.out.println(new Solution().solution("hit","hot",new String[]{"dot"}));
  }
}
```

## 기대 출력과 확인 관점

```text
3
0
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(W²L), 공간 O(WL), 단어 저장 포함.

목표 문자열이 같아 보이는지보다 목록에 포함되어 실제 경로로 도달하는지 확인한다.
