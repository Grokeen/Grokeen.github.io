**학습 유형:** 이분 탐색·탐욕 판정

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

바위를 제거해 인접한 두 지점 사이 최소 거리를 최대화한다. 목표 간격을 정하고 그보다 가까운 바위를 제거하는 데 필요한 최소 횟수를 센다.

## 풀이 순서

1. 바위를 정렬한다.
2. 직전 유지 지점과 간격이 부족하면 현재 바위를 제거한다.
3. 필요 제거 수가 N 이하면 간격을 늘린다.

## 풀이가 성립하는 이유

가까운 바위를 제거하고 더 먼 위치를 기다리면 다음 지점을 유지할 공간이 줄지 않는다. 마지막 도착점 간격이 부족하면 직전 유지 바위 하나를 제거하는 것으로 판정할 수 있다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(int distance,int[] rocks,int n){int[] a=rocks.clone();Arrays.sort(a);int lo=0,hi=distance;while(lo<hi){int mid=lo+(hi-lo+1)/2,last=0,removed=0;for(int x:a){if(x-last<mid)removed++;else last=x;}if(distance-last<mid)removed++;if(removed<=n)lo=mid;else hi=mid-1;}return lo;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(10,new int[]{3,6},1));
    System.out.println(new Solution().solution(10,new int[]{3,6},2));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
4
10
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(R log R+R log D), 공간 O(R) 복사 포함.

도착점을 실제 제거하는 것이 아니다. 마지막 짧은 구간의 추가 제거는 직전 바위를 없앤 경우에 대응한다.
