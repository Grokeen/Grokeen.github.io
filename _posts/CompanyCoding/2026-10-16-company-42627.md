**학습 유형:** 힙·작업 스케줄링

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

현재 대기 중인 작업에서 소요시간, 요청시각, 작업번호 순으로 고른다. 요청부터 완료까지의 반환 시간을 합산한다. 공식 원문은 2024년 11월 14일 개정되었으며 여기서는 확인한 현재 규칙을 따른다.

## 풀이 순서

1. 원래 작업 번호를 보존하고 요청 시각순으로 정렬한다.
2. 현재 시각까지 온 작업을 모두 힙에 넣는다.
3. 최우선 작업을 끝내거나 큐가 비면 다음 요청 시각으로 이동한다.

## 풀이가 성립하는 이유

힙은 실행 가능한 작업만 포함한다. 완료 시각과 같은 시각의 요청도 먼저 추가한 뒤 선택해 규칙을 지킨다. 임의의 전체 최적 스케줄을 찾는다는 주장 대신 지정된 장치를 정확히 시뮬레이션한다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

```java
import java.util.*;

class Solution {

  public int solution(int[][] jobs) {
    int n = jobs.length;
    int[][] a = new int[n][3];
    for (int i = 0; i < n; i++) {
      a[i][0] = jobs[i][0];
      a[i][1] = jobs[i][1];
      a[i][2] = i;
    }
    Arrays.sort(a, Comparator.comparingInt((int[] x) -> x[0]));
    PriorityQueue<int[]> q = new PriorityQueue<>(
      Comparator.comparingInt((int[] x) -> x[1])
        .thenComparingInt(x -> x[0])
        .thenComparingInt(x -> x[2])
    );
    int at = 0,
      done = 0,
      time = 0;
    long total = 0;
    while (done < n) {
      if (q.isEmpty() && at < n) time = Math.max(time, a[at][0]);
      while (at < n && a[at][0] <= time) q.add(a[at++]);
      int[] x = q.poll();
      time += x[1];
      total += time - x[0];
      done++;
    }
    return (int) (total / n);
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(
      new Solution().solution(new int[][] { { 0, 4 }, { 1, 2 }, { 4, 1 } })
    );
    System.out.println(new Solution().solution(new int[][] { { 5, 3 } }));
  }
}
```

## 기대 출력과 확인 관점

```text
3
3
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N log N), 공간 O(N).

현재 원문은 동률 기준까지 명시한다. 예전 풀이의 전역 최적 평균 보장 설명을 그대로 붙이지 않는다.
