**학습 유형:** 탐욕법·단조 스택

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

정해진 개수의 숫자를 제거해 남은 수를 최대화한다. 현재 숫자보다 작은 앞 숫자를 제거할 수 있다면 가장 왼쪽 자리부터 크게 만드는 것이 유리하다.

## 풀이 순서

1. 작은 꼭대기를 K가 남은 동안 제거한다.
2. 현재 숫자를 스택에 넣는다.
3. 제거가 남았으면 뒤에서 남은 개수만큼 자른다.

## 풀이가 성립하는 이유

앞자리의 차이가 뒷자리 전체보다 우선하므로 더 큰 현재 숫자 앞의 작은 후보를 제거하는 교환이 안전하다. 내림차순으로 남아 제거가 부족하면 영향이 작은 끝을 지운다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public String solution(String number,int k){char[] stack=new char[number.length()];int top=0;for(char c:number.toCharArray()){while(k>0&&top>0&&stack[top-1]<c){top--;k--;}stack[top++]=c;}return new String(stack,0,top-k);}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution("12345",2));
    System.out.println(new Solution().solution("54321",2));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
345
543
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N), 공간 O(N).

같은 숫자에서는 불필요하게 제거하지 않는다. 끝까지 K가 남는 내림차순 입력을 처리한다.
