**학습 유형:** 동적 계획법·격자

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

오른쪽·아래로만 이동할 때 물웅덩이를 피하는 최단 경로 수를 센다. 현재 칸의 경로 수는 위와 왼쪽의 경로 수 합이다.

## 풀이 순서

1. 물웅덩이를 행 y, 열 x에 표시한다.
2. 출발 경로 수를 1로 둔다.
3. 웅덩이는 0, 나머지는 위+왼쪽을 나머지 연산으로 계산한다.

## 풀이가 성립하는 이유

허용 이동이 오른쪽·아래뿐이라 모든 경로의 길이가 같고 순환도 없다. 마지막 이동이 위 또는 왼쪽에서 오는 두 경우로 나뉘어 합으로 셀 수 있다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(int m,int n,int[][] puddles){boolean[][] blocked=new boolean[n+1][m+1];for(int[] p:puddles)blocked[p[1]][p[0]]=true;int[][] dp=new int[n+1][m+1];dp[1][1]=1;for(int r=1;r<=n;r++)for(int c=1;c<=m;c++){if(blocked[r][c])dp[r][c]=0;else if(r!=1||c!=1)dp[r][c]=(dp[r-1][c]+dp[r][c-1])%1000000007;}return dp[n][m];}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(3,3,new int[][]{{2,2}}));
    System.out.println(new Solution().solution(2,2,new int[][]{}));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
2
2
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(MN), 공간 O(MN).

물웅덩이 좌표 순서는 x,y다. 1,000,000,007로 매번 나머지를 계산한다.
