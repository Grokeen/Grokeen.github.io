**학습 유형:** 완전 탐색·주기

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

세 응답 패턴을 정답 길이만큼 반복해 맞힌 개수를 센다. 최고점이 동률인 사람을 모두 번호순으로 반환한다.

## 풀이 순서

1. 정해진 세 패턴을 배열로 둔다.
2. i%패턴 길이 위치와 정답을 비교한다.
3. 최댓값인 모든 사람의 번호를 모은다.

## 풀이가 성립하는 이유

나머지 인덱스가 반복 패턴의 현재 위치를 정확히 가리킨다. 각 정답을 세 사람 모두에게 비교해 점수를 계산하므로 동률도 빠짐없이 찾는다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int[] solution(int[] answers){int[][] p={{1,2,3,4,5},{2,1,2,3,2,4,2,5},{3,3,1,1,2,2,4,4,5,5}};int[] score=new int[3];for(int i=0;i<answers.length;i++)for(int k=0;k<3;k++)if(answers[i]==p[k][i%p[k].length])score[k]++;int max=Arrays.stream(score).max().getAsInt();return java.util.stream.IntStream.range(0,3).filter(i->score[i]==max).map(i->i+1).toArray();}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(Arrays.toString(new Solution().solution(new int[]{1,1,1,1,1})));
    System.out.println(Arrays.toString(new Solution().solution(new int[]{5,5})));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
[3]
[1, 2, 3]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N), 공간 O(1), 결과 길이는 최대 3.

최고점 한 명만 고르지 않는다. 패턴 길이가 세 사람마다 다르다.
