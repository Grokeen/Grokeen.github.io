**학습 유형:** 큐·우선순위

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

현재 대기 중인 더 높은 우선순위가 있으면 맨 앞 작업을 뒤로 보낸다. 작업의 우선순위와 원래 위치를 구분해 목표 작업의 실행 순서를 찾는다.

## 풀이 순서

1. 큐에는 작업 인덱스를 저장한다.
2. 현재 최대 우선순위보다 작으면 뒤로 보낸다.
3. 실행 가능한 작업이면 순번을 늘리고 목표인지 검사한다.

## 풀이가 성립하는 이유

최대 힙은 아직 실행되지 않은 우선순위를 유지하고 큐는 대기 순서를 유지한다. 실행 때 두 자료구조에서 같은 작업 우선순위를 하나 제거해 일관성을 지킨다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public int solution(int[] priorities, int location) {
    Deque<Integer> q = new ArrayDeque<>();
    PriorityQueue<Integer> max = new PriorityQueue<>(Comparator.reverseOrder());
    for (int i = 0; i < priorities.length; i++) {
      q.add(i);
      max.add(priorities[i]);
    }
    int done = 0;
    while (!q.isEmpty()) {
      int id = q.poll();
      if (priorities[id] < max.peek()) q.add(id);
      else {
        max.poll();
        done++;
        if (id == location) return done;
      }
    }
    throw new IllegalStateException();
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(new Solution().solution(new int[] { 1, 2, 3, 2 }, 2));
    System.out.println(new Solution().solution(new int[] { 1, 1, 9, 1, 1, 1 }, 0));
  }
}
```

## 기대 출력과 확인 관점

```text
1
5
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

최악 시간 O(N²+N log N), 공간 O(N), 큐 회전 포함.

같은 우선순위의 작업을 하나로 합치면 위치별 실행 순서가 사라진다.
