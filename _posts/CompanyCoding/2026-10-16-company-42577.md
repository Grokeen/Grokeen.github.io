**학습 유형:** 해시·정렬

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

어떤 전화번호가 다른 번호의 접두사인지 검사한다. 사전순 정렬하면 접두사 관계가 있는 문자열들이 붙어서 나타나므로 인접한 두 번호만 비교할 수 있다.

## 풀이 순서

1. 원본을 복사해 사전순 정렬한다.
2. 뒤 번호가 앞 번호로 시작하는지 검사한다.
3. 한 번이라도 맞으면 false, 없으면 true다.

## 풀이가 성립하는 이유

접두사 p를 가진 번호들은 사전순에서 연속 구간을 이룬다. p 자체가 목록에 있으면 그 바로 다음 번호가 확장 번호이므로 인접 비교로 충분하다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public boolean solution(String[] phone_book) {
    String[] a = phone_book.clone();
    Arrays.sort(a);
    for (int i = 1; i < a.length; i++) if (a[i].startsWith(a[i - 1])) return false;
    return true;
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(new Solution().solution(new String[] { "12", "123", "45" }));
    System.out.println(new Solution().solution(new String[] { "12", "34" }));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
false
true
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N log N·L), 공간 O(N) 복사와 정렬 보조 공간.

숫자로 변환하면 선행 0을 잃는다. 길이순 정렬만으로 인접 비교가 성립하지 않는다.
