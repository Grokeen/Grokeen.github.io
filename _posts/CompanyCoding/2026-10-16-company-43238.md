**학습 유형:** 이분 탐색

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

시간 T 안에 처리 가능한 사람 수는 각 심사대의 floor(T/소요시간) 합이다. 시간이 늘면 처리 수가 줄지 않으므로 모두 처리하는 최소 시간을 찾는다.

## 풀이 순서

1. 가장 빠른 심사대 혼자 처리하는 시간을 상한으로 둔다.
2. 중간 시간의 처리 수가 N 이상인지 판정한다.
3. 가능하면 상한을 낮추고 아니면 하한을 높인다.

## 풀이가 성립하는 이유

가능한 시간은 큰 쪽 연속 구간이다. 하한 이분 탐색이 첫 가능 시간을 찾으며 검사 중 처리 수가 N 이상이면 더하지 않아 오버플로를 줄일 수 있다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public long solution(int n,int[] times){long fastest=Arrays.stream(times).min().getAsInt(),lo=0,hi=fastest*n;while(lo<hi){long mid=lo+(hi-lo)/2,count=0;for(int t:times){count+=mid/t;if(count>=n)break;}if(count>=n)hi=mid;else lo=mid+1;}return lo;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(3,new int[]{2,3}));
    System.out.println(new Solution().solution(1,new int[]{5,7}));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
4
5
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(S log(minTime·N)), 공간 O(1). S는 심사대 수.

시간×사람 수는 long으로 계산한다. 합산은 N에 도달하면 중단해 불필요하게 커지는 값을 막는다.
