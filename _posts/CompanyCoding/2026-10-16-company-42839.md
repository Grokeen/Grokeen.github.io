**학습 유형:** 완전 탐색·중복 제거

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

숫자 조각의 일부를 순열로 이어 만든 모든 정수를 구하고 고유한 소수의 수를 센다. 선행 0이나 같은 숫자 때문에 같은 정수가 여러 경로에서 생길 수 있다.

## 풀이 순서

1. 인덱스 사용 여부로 모든 길이 순열을 만든다.
2. 정수 값은 Set으로 중복을 제거한다.
3. 2 이상 값에 제곱근까지 나눗셈 검사를 한다.

## 풀이가 성립하는 이유

모든 비어 있지 않은 선택 순서를 방문하므로 만들 수 있는 정수를 모두 포함한다. Set이 같은 값을 한 번만 남기고 소수 판정은 비자명 약수가 제곱근 이하에 있다는 성질을 쓴다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
Set<Integer> values=new HashSet<>();char[] digits;boolean[] used;public int solution(String numbers){digits=numbers.toCharArray();used=new boolean[digits.length];build(0,0);int count=0;for(int v:values)if(prime(v))count++;return count;}void build(int value,int depth){if(depth>0)values.add(value);for(int i=0;i<digits.length;i++)if(!used[i]){used[i]=true;build(value*10+digits[i]-'0',depth+1);used[i]=false;}}boolean prime(int n){if(n<2)return false;for(int i=2;i*i<=n;i++)if(n%i==0)return false;return true;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution("23"));
    System.out.println(new Solution().solution("22"));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
3
1
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

탐색 노드 수 S와 최대값 V에 대해 O(S+U√V), 공간 O(S+D). U는 고유 수, D는 자릿수.

1은 소수가 아니다. 숫자 값 중복과 조각 인덱스 중복을 구분한다.
