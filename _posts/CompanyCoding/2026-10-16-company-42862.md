**학습 유형:** 탐욕법

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

분실과 여벌을 함께 반영해 실제로 빌릴 수 있는 학생부터 확정한다. 왼쪽부터 부족한 학생을 보고 왼쪽 여벌을 우선 사용하면 뒤 학생의 선택지를 보존할 수 있다.

## 풀이 순서

1. 모두 1벌에서 분실은 -1, 여벌은 +1한다.
2. 0벌인 학생은 왼쪽, 없으면 오른쪽에서 빌린다.
3. 1벌 이상인 학생 수를 센다.

## 풀이가 성립하는 이유

자기 여벌을 잃은 학생은 1벌이므로 빌려줄 수 없다. 왼쪽 여벌은 현재 학생을 놓치면 더 오른쪽 학생에게 줄 수 없으므로 먼저 사용하는 선택이 안전하다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(int n,int[] lost,int[] reserve){int[] count=new int[n+2];Arrays.fill(count,1);for(int x:lost)count[x]--;for(int x:reserve)count[x]++;for(int i=1;i<=n;i++)if(count[i]==0){if(count[i-1]>1){count[i-1]--;count[i]++;}else if(count[i+1]>1){count[i+1]--;count[i]++;}}int answer=0;for(int i=1;i<=n;i++)if(count[i]>0)answer++;return answer;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(5,new int[]{2,4},new int[]{1,3,5}));
    System.out.println(new Solution().solution(3,new int[]{1,2},new int[]{2,3}));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
5
2
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N+L+R), 공간 O(N).

분실과 여벌의 교집합을 먼저 상쇄해야 한다. 번호 순서와 입력 배열 순서를 혼동하지 않는다.
