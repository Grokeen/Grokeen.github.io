**학습 유형:** 해시·다중 정렬

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

장르 총 재생 수로 장르 순서를 정하고 각 장르 안에서는 곡 재생 수, 고유 번호 순으로 최대 두 곡을 고른다. 합계 순서와 개별 곡 순서를 분리한다.

## 풀이 순서

1. 장르별 합계와 곡 인덱스 목록을 만든다.
2. 장르를 합계 내림차순으로 정렬한다.
3. 각 목록을 재생 내림차순·번호 오름차순으로 정렬해 두 곡을 고른다.

## 풀이가 성립하는 이유

요구된 우선순위를 두 단계 사전식 정렬로 그대로 구현한다. 곡 번호가 원본 인덱스이므로 출력 모델을 새로 만들어도 번호를 보존해야 한다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int[] solution(String[] genres,int[] plays){Map<String,Integer> total=new HashMap<>();Map<String,List<Integer>> songs=new HashMap<>();for(int i=0;i<genres.length;i++){total.merge(genres[i],plays[i],Integer::sum);songs.computeIfAbsent(genres[i],k->new ArrayList<>()).add(i);}List<String> order=new ArrayList<>(total.keySet());order.sort((a,b)->Integer.compare(total.get(b),total.get(a)));List<Integer> result=new ArrayList<>();for(String g:order){List<Integer> ids=songs.get(g);ids.sort((a,b)->plays[a]==plays[b]?Integer.compare(a,b):Integer.compare(plays[b],plays[a]));for(int i=0;i<Math.min(2,ids.size());i++)result.add(ids.get(i));}return result.stream().mapToInt(Integer::intValue).toArray();}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(Arrays.toString(new Solution().solution(new String[]{"rock","pop","rock","pop"},new int[]{10,20,30,10})));
    System.out.println(Arrays.toString(new Solution().solution(new String[]{"g","g","g"},new int[]{5,5,1})));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
[2, 0, 1, 3]
[0, 1]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N log N), 공간 O(N).

장르 안 동률에서 번호가 작은 곡이 먼저다. 장르 총 재생 수가 서로 다르다는 원문 조건을 사용한다.
