**학습 유형:** 그래프·BFS

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

1번에서 최단 거리로 가장 멀리 있는 정점 수를 센다. 최장 경로를 찾는 문제가 아니라 최단 거리 배열의 최댓값 빈도를 찾는 문제다.

## 풀이 순서

1. 무방향 인접 목록을 만든다.
2. 1번에서 BFS로 각 거리를 계산한다.
3. 도달한 정점 거리의 최대값과 개수를 센다.

## 풀이가 성립하는 이유

BFS가 모든 도달 가능한 정점의 최단 거리를 준다. 최대 거리와 같은 정점이 여러 개면 모두 세어야 하며 큐의 마지막 원소 하나만 답은 아니다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(int n,int[][] edge){List<Integer>[] g=new ArrayList[n+1];for(int i=1;i<=n;i++)g[i]=new ArrayList<>();for(int[] e:edge){g[e[0]].add(e[1]);g[e[1]].add(e[0]);}int[] d=new int[n+1];Arrays.fill(d,-1);Deque<Integer> q=new ArrayDeque<>();q.add(1);d[1]=0;while(!q.isEmpty()){int v=q.poll();for(int next:g[v])if(d[next]<0){d[next]=d[v]+1;q.add(next);}}int max=0,count=0;for(int i=1;i<=n;i++)max=Math.max(max,d[i]);for(int i=1;i<=n;i++)if(d[i]==max)count++;return count;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(4,new int[][]{{1,2},{2,3},{2,4}}));
    System.out.println(new Solution().solution(2,new int[][]{{1,2}}));
  }
}
```

## 기대 출력과 확인 관점

```text
2
1
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(V+E), 공간 O(V+E).

미방문 거리 -1은 최댓값 계산에서 제외된다. 간선 방향을 양쪽에 추가한다.
