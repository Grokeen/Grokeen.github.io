**학습 유형:** 정렬·경계

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

인용 횟수가 h 이상인 논문이 최소 h개인 최대 h를 찾는다. 정렬하면 현재 위치 이후의 논문 개수를 바로 알 수 있다.

## 풀이 순서

1. 인용 수를 오름차순 정렬한다.
2. 위치 i에서 후보 h=N-i를 확인한다.
3. 인용 수가 h 이상인 첫 위치의 h를 반환한다.

## 풀이가 성립하는 이유

오름차순이므로 i 이후 모든 값은 a[i] 이상이다. 후보 h는 순회하며 감소하므로 처음 가능한 h가 가장 크다. 인용 수 그 자체만 후보로 검사할 필요는 없다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(int[] citations){int[] a=citations.clone();Arrays.sort(a);for(int i=0;i<a.length;i++)if(a[i]>=a.length-i)return a.length-i;return 0;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(new int[]{0,1,4,5}));
    System.out.println(new Solution().solution(new int[]{0,0}));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
2
0
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N log N), 공간 O(N) 원본 복사 포함.

h가 목록에 실제 인용 수로 존재할 필요는 없다. 전부 0이면 답 0이다.
