**학습 유형:** BFS·연결 요소

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

컴퓨터 연결 행렬에서 연결 요소 수를 센다. 직접 연결이 없어도 다른 컴퓨터를 거쳐 연결되면 같은 네트워크다.

## 풀이 순서

1. 모든 컴퓨터를 시작점 후보로 본다.
2. 미방문이면 네트워크 수를 늘리고 BFS한다.
3. 현재 컴퓨터의 연결 행을 검사해 새 컴퓨터를 넣는다.

## 풀이가 성립하는 이유

한 탐색이 도달 가능한 전체 요소를 방문하고 이미 본 정점에서 다시 시작하지 않으므로 요소마다 한 번만 센다. 대각선의 자기 연결은 방문 표시로 무시된다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(int n,int[][] computers){boolean[] seen=new boolean[n];int count=0;for(int s=0;s<n;s++)if(!seen[s]){count++;Deque<Integer> q=new ArrayDeque<>();q.add(s);seen[s]=true;while(!q.isEmpty()){int v=q.poll();for(int next=0;next<n;next++)if(computers[v][next]==1&&!seen[next]){seen[next]=true;q.add(next);}}}return count;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(3,new int[][]{{1,1,0},{1,1,0},{0,0,1}}));
    System.out.println(new Solution().solution(2,new int[][]{{1,0},{0,1}}));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
2
2
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(N²), 공간 O(N), 입력 행렬 제외.

1번 컴퓨터에서만 탐색하면 다른 네트워크를 놓친다. 행렬은 모든 열을 검사해야 한다.
