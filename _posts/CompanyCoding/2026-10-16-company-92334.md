**학습 유형:** 카카오 공개 기출·집합

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

공식 분류는 2022 KAKAO BLIND RECRUITMENT다. 같은 사람이 같은 대상을 여러 번 신고해도 한 번만 세고 정지된 대상을 신고한 사람에게 결과 수를 반영한다.

## 풀이 순서

1. 사용자 ID를 원래 순서의 인덱스로 매핑한다.
2. 대상별 신고자 Set을 만든다.
3. 기준 이상 신고된 대상의 신고자에게 결과를 하나씩 더한다.

## 풀이가 성립하는 이유

Set은 동일 신고자·대상 쌍을 중복 제거한다. 각 정지 대상마다 신고자에게 한 번만 더하므로 메일 수가 정확하며 결과 배열은 ID 목록 순서와 일치한다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int[] solution(String[] id_list,String[] report,int k){Map<String,Integer> ids=new HashMap<>();for(int i=0;i<id_list.length;i++)ids.put(id_list[i],i);Set<Integer>[] reporters=new HashSet[id_list.length];for(int i=0;i<reporters.length;i++)reporters[i]=new HashSet<>();for(String s:report){String[] p=s.split(" ");reporters[ids.get(p[1])].add(ids.get(p[0]));}int[] answer=new int[id_list.length];for(Set<Integer> set:reporters)if(set.size()>=k)for(int id:set)answer[id]++;return answer;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(Arrays.toString(new Solution().solution(new String[]{"a","b","c"},new String[]{"a b","a b","c b"},2)));
    System.out.println(Arrays.toString(new Solution().solution(new String[]{"a","b","c"},new String[]{"a b","a b","c b"},3)));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
[1, 0, 1]
[0, 0, 0]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

평균 시간 O(U+R), 공간 O(U+R), 문자열 길이 비용 별도.

신고 문자열 개수로 정지 여부를 판단하면 중복 신고가 과대 반영된다. 신고자 수와 대상 수를 구분한다.
