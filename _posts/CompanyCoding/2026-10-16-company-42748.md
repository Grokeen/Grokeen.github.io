**학습 유형:** 정렬·구간

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

지정한 구간을 복사하고 정렬한 뒤 K번째 값을 고른다. 입력 명령은 양 끝을 포함하는 1기준이고 Java 복사는 끝을 제외하는 0기준이다.

## 풀이 순서

1. 시작 인덱스를 i-1로 바꾼다.
2. 끝 j는 copyOfRange의 제외 경계로 그대로 쓴다.
3. 정렬 후 k-1 위치를 읽는다.

## 풀이가 성립하는 이유

원래 i~j의 원소가 Java 구간 [i-1,j)에 정확히 대응한다. 정렬된 배열의 k-1 인덱스가 1기준 K번째 순서 통계값이다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {

  public int[] solution(int[] array, int[][] commands) {
    int[] answer = new int[commands.length];
    for (int i = 0; i < commands.length; i++) {
      int[] c = commands[i],
        part = Arrays.copyOfRange(array, c[0] - 1, c[1]);
      Arrays.sort(part);
      answer[i] = part[c[2] - 1];
    }
    return answer;
  }
}

public class Main {

  public static void main(String[] args) {
    System.out.println(
      Arrays.toString(
        new Solution().solution(
          new int[] { 5, 1, 4, 2 },
          new int[][] { { 2, 4, 2 }, { 1, 1, 1 } }
        )
      )
    );
    System.out.println(
      Arrays.toString(
        new Solution().solution(new int[] { 7 }, new int[][] { { 1, 1, 1 } })
      )
    );
  }
}
```

## 기대 출력과 확인 관점

```text
[2, 5]
[7]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

질의 길이 L일 때 O(L log L), 공간 O(L), 전체는 질의별 비용 합.

원본 전체를 먼저 정렬하면 각 구간에 들어 있는 값이 바뀐다. 원본을 보존한다.
