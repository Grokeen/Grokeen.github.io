**학습 유형:** 동적 계획법·Set

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

N을 정확히 i번 써서 만들 수 있는 정수 집합을 저장한다. 마지막 연산의 왼쪽·오른쪽 사용 횟수를 나누어 사칙연산 결과를 합치고 이어 쓴 수도 포함한다.

## 풀이 순서

1. 1회부터 8회까지 집합을 만든다.
2. 모든 분할 j와 i-j의 값들을 조합한다.
3. 목표가 처음 등장한 i를 반환한다.

## 풀이가 성립하는 이유

모든 식은 하나의 마지막 연산 또는 이어 붙인 수로 볼 수 있다. 가능한 두 부분식의 사용 횟수와 값을 모두 조합하므로 괄호 구조까지 포함한 식을 빠짐없이 생성한다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int solution(int N,int number){List<Set<Integer>> dp=new ArrayList<>();dp.add(new HashSet<>());int repeated=0;for(int i=1;i<=8;i++){Set<Integer> now=new HashSet<>();repeated=repeated*10+N;now.add(repeated);for(int j=1;j<i;j++)for(int a:dp.get(j))for(int b:dp.get(i-j)){now.add(a+b);now.add(a-b);now.add(a*b);if(b!=0)now.add(a/b);}dp.add(now);if(now.contains(number))return i;}return -1;}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution(2,11));
    System.out.println(new Solution().solution(5,5));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
3
1
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간은 각 분할의 |Sj|·|Si-j| 합, 공간은 1~8회 집합 크기 합. 단순 O(N) 문제가 아니다.

0으로 나누는 경우를 제외한다. 8회까지 없으면 -1이다. Java 정수 나눗셈의 0 방향 절삭을 사용한다.
