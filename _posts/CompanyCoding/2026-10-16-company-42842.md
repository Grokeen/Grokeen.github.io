**학습 유형:** 완전 탐색·약수

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

전체 넓이의 약수 쌍을 가로·세로로 보고 안쪽 노란 영역의 넓이를 비교한다. 테두리가 한 칸이므로 안쪽 크기는 각각 2씩 작다.

## 풀이 순서

1. 전체 넓이를 brown+yellow로 구한다.
2. 세로를 3부터 제곱근까지 확인한다.
3. (가로-2)(세로-2)가 yellow인 쌍을 반환한다.

## 풀이가 성립하는 이유

가로≥세로인 직사각형은 세로가 전체 넓이의 제곱근 이하인 약수다. 이 약수 쌍을 모두 검사하므로 조건을 만족하는 크기를 놓치지 않는다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public int[] solution(int brown,int yellow){int total=brown+yellow;for(int h=3;h*h<=total;h++)if(total%h==0){int w=total/h;if((w-2)*(h-2)==yellow)return new int[]{w,h};}throw new IllegalArgumentException();}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(Arrays.toString(new Solution().solution(18,6)));
    System.out.println(Arrays.toString(new Solution().solution(12,4)));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
[8, 3]
[4, 4]
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(√(brown+yellow)), 공간 O(1).

가로와 세로의 출력 순서를 지킨다. 전체 넓이만 맞고 테두리 조건이 틀린 약수 쌍은 제외한다.
