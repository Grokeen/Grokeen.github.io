**학습 유형:** 카카오 공개 기출·문자열

[백준 추가 100문제](/study/2024/baekjoon/)와 별도로 정리한 기업 코딩테스트 대비 글이다. 2026년 10월 16일 공식 원문의 조건을 확인했고 아래 입력은 직접 구성했다. 특정 기업의 반복 출제 횟수나 온라인 정답 판정을 주장하지 않는다.

## 문제를 이해한 방식

공식 분류는 2021 KAKAO BLIND RECRUITMENT다. 정해진 정규화 단계를 순서대로 적용한다. 단계 자체의 순서가 계약이므로 단순히 비슷한 문자열을 만드는 것으로는 충분하지 않다.

## 풀이 순서

1. 소문자화·허용 문자 필터·연속 점 축약을 한다.
2. 양 끝 점 제거 후 빈 값 보정과 15자 제한을 한다.
3. 끝 점을 다시 지우고 3자 미만이면 마지막 문자를 반복한다.

## 풀이가 성립하는 이유

각 단계의 결과가 다음 단계 입력이다. 길이 절단이 새 끝 점을 만들 수 있어 재검사가 필요하고 빈 값 보정을 먼저 해야 마지막 문자 반복이 안전하다.

## Java 풀이와 실행 예제

아래 전체를 UTF-8 Main.java에 저장하고 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다. 별도 표준 입력 없이 main의 두 예제를 호출한다. 공식 플랫폼에 제출할 때는 imports와 Solution 클래스만 사용하고 로컬 실행용 Main은 제외한다.

{% raw %}
```java
import java.util.*;

class Solution {
public String solution(String new_id){String s=new_id.toLowerCase(Locale.ROOT).replaceAll("[^a-z0-9._-]","").replaceAll("\\.+",".");if(s.startsWith("."))s=s.substring(1);if(s.endsWith("."))s=s.substring(0,s.length()-1);if(s.isEmpty())s="a";if(s.length()>15)s=s.substring(0,15);if(s.endsWith("."))s=s.substring(0,s.length()-1);StringBuilder result=new StringBuilder(s);while(result.length()<3)result.append(result.charAt(result.length()-1));return result.toString();}
}

public class Main {
  public static void main(String[] args) {
    System.out.println(new Solution().solution("...ABC__.."));
    System.out.println(new Solution().solution("!!"));
  }
}
```
{% endraw %}

## 기대 출력과 확인 관점

```text
abc__
aaa
```

main의 호출 순서대로 결과를 출력한다. 먼저 반환값을 예상한 뒤 결과와 비교하고, 아래 주의점에 해당하는 입력도 직접 바꾸어 실행해 본다. 배열 출력은 로컬 확인을 위한 표기다.

## 복잡도와 주의점

시간 O(L), 공간 O(L).

점은 정규식의 임의 문자 기호라 이스케이프해야 한다. 소문자화에는 Locale.ROOT를 지정한다.
