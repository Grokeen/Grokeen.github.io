라즈베리파이 GPIO만으로 연속 전압을 바로 읽을 수 없다는 점을 정리했다. 외부 ADC가 변환을 담당했다.

> 장비와 해당 모듈이 필요한 예제. 코드를 `example.py`로 저장하고 라즈베리파이에서 `python3 example.py`로 실행한다. 실제 장비 실행 결과는 확인 방법으로 구분했다.

## 오늘 정리한 개념

MCP3008의 VDD·VREF를 3.3V, AGND·DGND를 GND에 연결한다. CLK → `BCM11(물리23)`, DOUT → `BCM9(물리21)`, DIN → `BCM10(물리19)`, CS → `BCM8(물리24)`이다. 10kΩ 가변저항 양 끝을 3.3V·GND, 가운데를 CH0에 연결한다. raspi-config에서 SPI를 활성화한 뒤 사용한다.

## 따라 해 보기

{% raw %}
```python
from gpiozero import MCP3008
from time import sleep

with MCP3008(channel=0) as adc:
    for _ in range(3):
        ratio = adc.value
        voltage = ratio * 3.3
        print(f"비율 {ratio:.3f}, 추정 전압 {voltage:.2f} V")
        sleep(0.5)
```
{% endraw %}

## 장비에서 확인할 내용

장비 확인: 가변저항 위치에 따라 0~1 근처 비율과 0~3.3V 근처 추정 전압이 표시된다.

## 코드를 따라 읽기

MCP3008은 10비트 ADC이고 value는 원시 코드가 아니라 정규화된 비율이다. 기준 전압을 3.3V로 가정해 곱했다. 실제 VREF와 ADC 오차가 있으므로 계측 정확도와 소수점 표시 자릿수는 다르다. 칩의 홈·핀 1 방향은 데이터시트로 대조한다.

## 헷갈린 부분과 주의점

5V 센서의 아날로그 출력을 3.3V 기준 ADC에 직접 넣지 않는다. 입력은 ADC 전원·기준 전압 범위를 지키고 공통 접지를 확인한다.

## 복습 문제

value가 0.5이면 예제의 추정 전압은?

**풀이:** 1.65V다. 기준 전압 3.3V의 절반으로 계산한다.
