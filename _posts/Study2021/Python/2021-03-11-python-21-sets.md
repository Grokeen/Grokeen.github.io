중복된 태그를 없애고 두 목록의 공통 항목을 구했다. 집합에는 순서가 없다는 점을 출력 예제에도 반영했다.

> Python 3.9 기준. 코드를 `example.py`로 저장해 `python3 example.py`로 실행한다.

## 오늘 정리한 개념

set은 중복 없는 해시 가능한 항목들의 집합이다. |는 합집합, &는 교집합, -는 차집합이다. 빈 집합은 `set()`으로 만들며 {}는 빈 딕셔너리다. 집합의 순회·출력 순서를 가정하지 않고, 읽기 좋은 결과가 필요하면 sorted로 정렬해 리스트로 변환한다.

## 따라 해 보기

{% raw %}
```python
left = {"python", "gpio", "python"}
right = {"gpio", "linux"}
print(len(left))
print(sorted(left & right))
print(sorted(left | right))
print(sorted(left - right))
```
{% endraw %}

## 실행 결과

```text
2
['gpio']
['gpio', 'linux', 'python']
['python']
```

## 코드를 따라 읽기

중복 python은 한 번만 남으므로 left 길이는 2다. 교집합에는 두 집합에 모두 있는 gpio만 남는다. 차집합은 방향이 있어 left - right에서는 python이 남는다. 정렬은 결과를 보기 위해 적용했으며 집합 자체에 순서를 부여한 것은 아니다.

## 헷갈린 부분과 주의점

set으로 중복을 제거하면 원래 입력 순서가 보존되지 않는다. 순서까지 필요할 때는 딕셔너리 키나 별도 seen 집합을 함께 사용한다.

## 복습 문제

left <= left | right의 결과는?

**풀이:** True다. <=는 집합에서 왼쪽이 오른쪽의 부분집합인지 검사한다.
