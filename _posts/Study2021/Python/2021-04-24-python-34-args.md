함수에서 받는 *와 호출할 때 쓰는 *를 비교했다. 하나는 모으고 다른 하나는 펼친다고 읽으니 이해하기 쉬웠다.

> Python 3.9 기준. 코드를 `example.py`로 저장해 `python3 example.py`로 실행한다.

## 오늘 정리한 개념

함수 정의의 *values는 남는 위치 인자들을 튜플로 모은다. 호출문의 *items는 반복 가능한 객체의 항목을 개별 위치 인자로 펼친다. 인자 개수가 유동적인 합계 함수 등에 사용할 수 있다. 특정 역할이 중요한 입력이라면 무조건 가변 인자로 만들기보다 이름 있는 매개변수를 유지한다.

## 따라 해 보기

{% raw %}
```python
def total(*values):
    print(type(values).__name__)
    return sum(values)

print(total(1, 2, 3))
measurements = [10, 20]
print(total(*measurements))
print(total())
```
{% endraw %}

## 실행 결과

```text
tuple
6
tuple
30
tuple
0
```

## 코드를 따라 읽기

1·2·3은 values 튜플에 모인다. 두 번째 호출은 리스트를 펼쳐 10과 20 두 인자로 전달한다. 아무 인자도 없으면 빈 튜플이 되고 sum의 기본 합계는 0이다. `total(measurements)`와는 전달 구조가 다르다는 점을 구별했다.

## 헷갈린 부분과 주의점

*를 빼고 리스트 자체를 넘기면 values는 리스트 하나를 담은 튜플이 된다. 현재 sum 함수는 그 구조를 숫자 합계로 처리하지 못한다.

## 복습 문제

`max(*[3, 8, 5])`는 `max(3, 8, 5)`와 같을까?

**풀이:** 이 입력에서는 같은 인자를 전달해 결과도 8이다.
