쉼표가 포함된 항목도 올바르게 저장하기 위해 문자열 split 대신 csv 모듈을 사용했다. 먼저 메모리 안의 파일로 형식을 연습했다.

> Python 3.9 기준. 코드를 `example.py`로 저장해 `python3 example.py`로 실행한다.

## 오늘 정리한 개념

CSV는 행과 열을 텍스트로 표현하는 형식이다. csv.writer와 reader는 따옴표·구분자 처리를 맡아 준다. 기본 reader가 반환하는 각 셀은 문자열이다. 실제 파일을 열 때는 newline=`""`와 적절한 encoding을 지정한다. 숫자 열은 읽은 뒤 직접 변환해야 한다.

## 따라 해 보기

{% raw %}
```python
import csv
import io

buffer = io.StringIO(newline="")
writer = csv.writer(buffer)
writer.writerow(["장소", "온도"])
writer.writerow(["실내, 창가", 23])
buffer.seek(0)
rows = list(csv.reader(buffer))
print(rows)
print(int(rows[1][1]) + 1)
```
{% endraw %}

## 실행 결과

```text
[['장소', '온도'], ['실내, 창가', '23']]
24
```

## 코드를 따라 읽기

장소 안의 쉼표를 writer가 필요한 따옴표로 처리하므로 한 셀로 읽힌다. `seek(0)`은 쓰기가 끝난 메모리 파일의 위치를 처음으로 돌린다. 온도 23도 읽은 뒤에는 문자열이므로 int로 변환한다. 직접 쉼표로 나누면 장소를 두 칸으로 잘못 나눌 수 있다.

## 헷갈린 부분과 주의점

CSV 파일이 모두 같은 구분자를 쓰는 것은 아니다. 헤더 유무와 구분자, 인코딩을 먼저 확인한다. 숫자처럼 보여도 식별자는 문자열로 유지할 수 있다.

## 복습 문제

csv.DictReader는 일반 reader와 어떻게 다를까?

**풀이:** 일반적으로 첫 행을 열 이름으로 읽고 각 행을 열 이름과 값의 딕셔너리로 반환한다.
