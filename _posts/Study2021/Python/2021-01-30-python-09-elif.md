점수를 여러 구간으로 나누는 조건문을 작성했다. 여러 if와 하나의 if·elif 묶음이 다르게 동작한다는 점을 비교했다.

> Python 3.9 기준. 코드를 `example.py`로 저장해 `python3 example.py`로 실행한다.

## 오늘 정리한 개념

if·elif·else는 위에서부터 조건을 검사하고 처음 참인 블록 하나만 실행한다. 큰 값부터 검사하면 높은 점수가 낮은 구간에도 해당하는 문제를 피할 수 있다. 조건이 모두 거짓이면 else가 실행된다. 서로 독립적으로 수행해야 하는 조건이라면 별도의 if를 사용한다.

## 따라 해 보기

{% raw %}
```python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "재학습"
print(grade)
```
{% endraw %}

## 실행 결과

```text
B
```

## 코드를 따라 읽기

85는 첫 조건 90 이상을 만족하지 않지만 두 번째 조건은 만족한다. grade에 B를 대입한 뒤 나머지 elif는 검사하지 않는다. 80점·90점처럼 경계값을 직접 넣어 보면 부등호와 조건 순서가 맞는지 확인하기 좋다.

## 헷갈린 부분과 주의점

score >= 70을 맨 위에 두면 95도 그 조건에서 끝난다. 문자열 점수를 변환하지 않은 채 숫자와 대소 비교하면 TypeError가 난다.

## 복습 문제

score를 90으로 바꾸면 어느 블록이 실행될까?

**풀이:** 첫 if 블록이다. >=가 경계 90을 포함하므로 A가 선택된다.
