센서 이름과 값을 같은 위치끼리 연결했다. 목록 길이가 다를 때 조용히 짧은 쪽에서 끝나는 점을 확인했다.

> Python 3.9 기준. 코드를 `example.py`로 저장해 `python3 example.py`로 실행한다.

## 오늘 정리한 개념

zip은 여러 반복 가능 객체에서 항목을 하나씩 꺼내 튜플로 묶는다. Python 3.9에서 기본 zip은 가장 짧은 입력이 소진되면 끝난다. 이름과 값의 짝을 딕셔너리로 바꾸기에도 편리하다. 중요한 데이터라면 길이를 미리 비교하여 누락을 발견해야 한다.

## 따라 해 보기

{% raw %}
```python
names = ["온도", "습도", "기압"]
values = [22, 45]
print(list(zip(names, values)))
readings = dict(zip(names, values))
print(readings)
print(len(names) == len(values))
```
{% endraw %}

## 실행 결과

```text
[('온도', 22), ('습도', 45)]
{'온도': 22, '습도': 45}
False
```

## 코드를 따라 읽기

기압에 대응하는 값이 없으므로 결과에 기압 항목은 생기지 않는다. dict는 각 두 항목 튜플을 키와 값으로 읽는다. 마지막 길이 비교는 데이터가 완전히 대응하지 않는다는 사실을 알려 준다. 반복자이므로 결과를 다시 사용할 때는 보관 방식도 생각해야 한다.

## 헷갈린 부분과 주의점

zip 결과를 한 번 모두 소비하면 같은 반복자에서 다시 값이 나오지 않는다. strict 인자는 Python 3.10 이후 기능이므로 이 3.9 예제에서는 사용하지 않는다.

## 복습 문제

길이가 3인 목록과 길이가 5인 목록을 zip하면 몇 쌍일까?

**풀이:** 3쌍이다. 짧은 입력이 끝나는 시점에 종료한다.
