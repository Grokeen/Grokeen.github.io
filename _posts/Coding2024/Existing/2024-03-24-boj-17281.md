> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

1번 선수를 네 번째 타자로 고정하고 나머지 타순을 전부 탐색한다. 각 타순에서는 아웃·주자·점수를 규칙대로 시뮬레이션하며 타자 위치를 이닝 사이에 이어 간다.

## 풀이 순서

1. 고정 타자를 제외한 여덟 명의 순열을 만든다.
2. 이닝마다 아웃과 주자를 초기화하고 타자 위치는 유지한다.
3. 안타 결과에 맞게 주자를 이동시켜 득점하고 최대 점수를 갱신한다.

## 풀이가 성립하는 이유

가능한 타순 8!개를 모두 검사하므로 최적 타순을 놓치지 않는다. 주자를 3비트로 표현하면 이동 후 3루 밖으로 나간 비트의 개수가 득점이다. 3아웃 때 주자를 비우고 타순만 이어 간다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    innings = fs.nextInt();
    plays = new int[innings][9];
    for (int i = 0; i < innings; i++) for (int p = 0; p < 9; p++) plays[i][p] =
      fs.nextInt();
    order[3] = 0;
    used[0] = true;
    permute(0);
    System.out.println(best);
  }

  static int innings, best;
  static int[][] plays;
  static int[] order = new int[9];
  static boolean[] used = new boolean[9];

  static void permute(int at) {
    if (at == 9) {
      simulate();
      return;
    }
    if (at == 3) {
      permute(at + 1);
      return;
    }
    for (int p = 1; p < 9; p++) if (!used[p]) {
      used[p] = true;
      order[at] = p;
      permute(at + 1);
      used[p] = false;
    }
  }

  static void simulate() {
    int batter = 0,
      score = 0;
    for (int i = 0; i < innings; i++) {
      int outs = 0,
        bases = 0;
      while (outs < 3) {
        int hit = plays[i][order[batter]];
        batter = (batter + 1) % 9;
        if (hit == 0) outs++;
        else {
          bases = (bases << hit) | (1 << (hit - 1));
          score += Integer.bitCount(bases >> 3);
          bases &= 7;
        }
      }
    }
    best = Math.max(best, score);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(8!·N·한 이닝 타석 수), 공간 O(N+9). 각 이닝에 아웃 결과가 존재하는 조건을 사용한다.

이닝마다 첫 타자로 되돌리면 틀린다. 1번 선수는 인덱스 0이고 네 번째 타자는 인덱스 3이다.
