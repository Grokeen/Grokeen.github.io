기존 메모를 개념·풀이·검증 예제로 다시 정리했다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

겹치지 않는 회의 수를 최대화한다. 종료 시간이 빠른 순서로 고르면 다음 회의에 남기는 시간이 가장 많다. 종료 시간이 같으면 시작 시간이 빠른 순서로 정렬한다.

## 풀이 순서

1. 끝 시간, 시작 시간 순으로 정렬한다.
2. 직전 선택 회의의 끝 이후에 시작하는 회의를 선택한다.
3. 끝과 시작이 같은 경우는 이어서 배정할 수 있다.

## 풀이가 성립하는 이유

어떤 최적해의 첫 회의를 가장 빨리 끝나는 회의로 바꿔도 이후 회의를 위한 시간이 줄지 않는다. 이 교환 논리를 남은 회의에도 반복해 정당화한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {
  static final FastScanner fs=new FastScanner(System.in);
  public static void main(String[] args) throws Exception {
    StringBuilder out=new StringBuilder();
    int n=fs.nextInt();int[][] a=new int[n][2];for(int i=0;i<n;i++){a[i][0]=fs.nextInt();a[i][1]=fs.nextInt();}Arrays.sort(a,Comparator.comparingInt((int[] p)->p[1]).thenComparingInt(p->p[0]));int end=Integer.MIN_VALUE,count=0;for(int[] p:a)if(p[0]>=end){count++;end=p[1];}System.out.println(count);
  }

  static final class FastScanner {
    private final InputStream in; private final byte[] buffer=new byte[1<<16]; private int ptr,len;
    FastScanner(InputStream in){this.in=in;}
    private int read() throws IOException {if(ptr>=len){len=in.read(buffer);ptr=0;if(len<0)return -1;}return buffer[ptr++]&255;}
    String next() throws IOException {int c;do{c=read();}while(c<=32&&c!=-1);if(c==-1)return null;ByteArrayOutputStream b=new ByteArrayOutputStream();while(c>32&&c!=-1){b.write(c);c=read();}return b.toString("UTF-8");}
    long nextLong() throws IOException {int c;do{c=read();}while(c<=32&&c!=-1);if(c==-1)throw new EOFException();int sign=1;if(c==45){sign=-1;c=read();}long value=0;while(c>32&&c!=-1){value=value*10+c-48;c=read();}return value*sign;}
    int nextInt() throws IOException {return Math.toIntExact(nextLong());}
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3
1 1
1 2
2 2
```

**기대 출력**

```text
3
```

**예제 2 입력**

```text
3
1 4
2 3
3 5
```

**기대 출력**

```text
2
```

## 복잡도와 주의점

시간 O(N log N), 공간 O(N).

길이가 0인 회의와 같은 종료 시간의 동률을 확인한다. 조건을 start>last로 쓰면 바로 이어지는 회의를 놓친다.
