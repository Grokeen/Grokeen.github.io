> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

3과 5 크기 봉지로 정확한 무게를 만들며 봉지 수를 최소화한다. 3 봉지를 하나씩 사용해 남은 무게가 5로 나누어지는 첫 경우를 찾는다.

## 풀이 순서

1. 남은 무게가 5의 배수인지 검사한다.
2. 아니면 3을 빼고 사용한 봉지 수를 늘린다.
3. 0보다 작아질 때까지 실패하면 -1이다.

## 풀이가 성립하는 이유

가능한 경우에서 3 봉지가 적을수록 5 봉지가 많다. 같은 무게에서 더 큰 봉지를 최대한 쓰는 첫 해가 최소 개수다. 5만 고집하다 나머지를 버리면 정확한 무게 조건을 어긴다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      used = 0,
      ans = -1;
    while (n >= 0) {
      if (n % 5 == 0) {
        ans = used + n / 5;
        break;
      }
      n -= 3;
      used++;
    }
    System.out.println(ans);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(N), 공간 O(1).

N=4처럼 만들 수 없는 무게를 1개로 반올림하지 않는다. 남은 무게가 0인 경우도 정상 성공이다.
