> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

땅의 연결 요소 수를 센다. 이 문제의 인접은 대각선을 포함한 여덟 방향이므로 일반적인 사방 격자 탐색과 구분한다.

## 풀이 순서

1. 가로·세로를 읽고 둘 다 0이면 종료한다.
2. 아직 방문하지 않은 땅에서 BFS를 시작하며 섬 수를 1 늘린다.
3. 연결된 땅을 모두 방문 표시한 뒤 다음 시작점을 찾는다.

## 풀이가 성립하는 이유

각 땅은 정확히 한 연결 요소에 포함된다. 새 BFS를 시작한 횟수와 섬의 개수가 같고 대각선 연결도 같은 탐색에 흡수된다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    while (true) {
      int w = fs.nextInt(),
        h = fs.nextInt();
      if (w == 0 && h == 0) break;
      int[][] a = new int[h][w];
      for (int r = 0; r < h; r++) for (int c = 0; c < w; c++) a[r][c] = fs.nextInt();
      int count = 0;
      for (int r = 0; r < h; r++) for (int c = 0; c < w; c++) if (a[r][c] == 1) {
        count++;
        a[r][c] = 0;
        ArrayDeque<int[]> q = new ArrayDeque<>();
        q.add(new int[] { r, c });
        while (!q.isEmpty()) {
          int[] p = q.poll();
          for (int dr = -1; dr <= 1; dr++) for (int dc = -1; dc <= 1; dc++) {
            int x = p[0] + dr,
              y = p[1] + dc;
            if (x >= 0 && x < h && y >= 0 && y < w && a[x][y] == 1) {
              a[x][y] = 0;
              q.add(new int[] { x, y });
            }
          }
        }
      }
      out.append(count).append("\n");
    }
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(WH), 공간 O(WH), 지도 한 장 기준.

입력은 가로 W 다음 세로 H다. 행과 열을 뒤집거나 종료 입력을 지도에 포함하지 않는다.
