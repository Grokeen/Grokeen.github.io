> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

현재 수를 1로 만드는 최소 연산 횟수를 DP로 저장한다. 마지막 연산의 이전 상태를 모두 비교하므로 나눌 수 있을 때 무조건 나누는 탐욕법보다 안전하다.

## 풀이 순서

1. dp[1]=0으로 둔다.
2. i-1, i/2, i/3 중 가능한 이전 상태의 최솟값에 1을 더한다.
3. 작은 수부터 계산하고 dp[N]을 출력한다.

## 풀이가 성립하는 이유

각 연산은 더 작은 수로 이동한다. 그 작은 수의 최적 횟수를 이미 알고 있으므로 가능한 마지막 연산을 모두 비교하면 i의 최적 횟수를 얻는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    int[] d = new int[n + 1];
    for (int i = 2; i <= n; i++) {
      d[i] = d[i - 1] + 1;
      if (i % 2 == 0) d[i] = Math.min(d[i], d[i / 2] + 1);
      if (i % 3 == 0) d[i] = Math.min(d[i], d[i / 3] + 1);
    }
    System.out.println(d[n]);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
10
```

**기대 출력**

```text
3
```

**예제 2 입력**

```text
1
```

**기대 출력**

```text
0
```

**예제 3 입력**

```text
6
```

**기대 출력**

```text
2
```

## 복잡도와 주의점

시간 O(N), 공간 O(N).

10은 3으로 나누기만 우선하는 방식이 아닌 10→9→3→1이 최적이다. 나누어떨어지는지 검사한다.
