실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

모든 정점을 연결하되 간선 비용 합을 최소화한다. Kruskal은 가벼운 간선부터 사이클을 만들지 않을 때만 선택하며 DSU로 연결 여부를 확인한다.

## 풀이 순서

1. 간선을 가중치 순으로 정렬한다.
2. 서로 다른 집합을 잇는 간선만 선택한다.
3. N-1개 선택하면 총 비용을 출력한다.

## 풀이가 성립하는 이유

현재 연결 요소를 가르는 컷의 최소 간선을 선택하는 것은 안전하다. 사이클을 만드는 간선은 이미 연결된 정점을 불필요하게 잇기 때문에 버린다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    int[][] edges = new int[m][3];
    for (int[] e : edges) {
      e[0] = fs.nextInt();
      e[1] = fs.nextInt();
      e[2] = fs.nextInt();
    }
    Arrays.sort(edges, Comparator.comparingInt((int[] e) -> e[2]));
    init(n);
    long total = 0;
    int used = 0;
    for (int[] e : edges)
      if (union(e[0], e[1])) {
        total += e[2];
        if (++used == n - 1) break;
      }
    System.out.println(total);
  }

  static int[] parent, size;

  static void init(int n) {
    parent = new int[n + 1];
    size = new int[n + 1];
    for (int i = 0; i <= n; i++) {
      parent[i] = i;
      size[i] = 1;
    }
  }

  static int find(int x) {
    while (x != parent[x]) {
      parent[x] = parent[parent[x]];
      x = parent[x];
    }
    return x;
  }

  static boolean union(int a, int b) {
    a = find(a);
    b = find(b);
    if (a == b) return false;
    if (size[a] < size[b]) {
      int t = a;
      a = b;
      b = t;
    }
    parent[b] = a;
    size[a] += size[b];
    return true;
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3 3
1 2 1
2 3 2
1 3 5
```

**기대 출력**

```text
3
```

**예제 2 입력**

```text
2 1
1 2 -4
```

**기대 출력**

```text
-4
```

## 복잡도와 주의점

시간 O(E log E+E α(V)), 공간 O(V+E).

최단 경로 트리와 MST는 목적이 다르다. 음수 가중치도 정렬·사이클 검사 방식에 문제되지 않는다.
