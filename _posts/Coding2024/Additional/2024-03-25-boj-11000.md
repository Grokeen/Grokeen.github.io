실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

모든 강의를 배정할 최소 강의실 수는 동시에 진행 중인 강의의 최대 개수다. 시작 순서로 보며 종료된 강의를 최소 힙에서 제거한다.

## 풀이 순서

1. 강의를 시작 시간 순으로 정렬한다.
2. 현재 시작 시각 이하로 끝난 강의를 모두 제거한다.
3. 현재 종료 시각을 넣고 힙 크기의 최댓값을 기록한다.

## 풀이가 성립하는 이유

힙에는 현재 강의 시작 시점에 겹치는 강의들의 종료 시각만 남는다. 이 수보다 적은 방으로는 동시에 배정할 수 없고 끝난 방을 재사용하면 그 수로 충분하다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    int[][] a = new int[n][2];
    for (int[] p : a) {
      p[0] = fs.nextInt();
      p[1] = fs.nextInt();
    }
    Arrays.sort(a, Comparator.comparingInt((int[] p) -> p[0]));
    PriorityQueue<Integer> ends = new PriorityQueue<>();
    int best = 0;
    for (int[] p : a) {
      while (!ends.isEmpty() && ends.peek() <= p[0]) ends.poll();
      ends.offer(p[1]);
      best = Math.max(best, ends.size());
    }
    System.out.println(best);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3
1 3
2 4
3 5
```

**기대 출력**

```text
2
```

**예제 2 입력**

```text
2
0 1
1 2
```

**기대 출력**

```text
1
```

## 복잡도와 주의점

시간 O(N log N), 공간 O(N).

종료와 다음 시작이 같은 시각이면 방을 재사용할 수 있다. 회의 일부를 고르는 1931과 목적이 다르다.
