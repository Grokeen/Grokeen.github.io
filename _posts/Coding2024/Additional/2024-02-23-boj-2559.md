실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

길이가 정확히 K인 연속 구간의 최대 합을 찾는다. 한 칸 이동할 때 빠지는 값과 들어오는 값만 반영하면 된다.

## 풀이 순서

1. 첫 K개 합을 구한다.
2. 오른쪽 새 값을 더하고 K칸 전 값을 뺀다.
3. 각 창의 합으로 최댓값을 갱신한다.

## 풀이가 성립하는 이유

인접한 두 창은 K-1개 원소를 공유한다. 두 값만 갱신해도 다음 창의 정확한 합을 얻으므로 모든 시작점을 빠짐없이 O(1)씩 처리한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      k = fs.nextInt();
    int[] a = new int[n];
    for (int i = 0; i < n; i++) a[i] = fs.nextInt();
    long sum = 0;
    for (int i = 0; i < k; i++) sum += a[i];
    long best = sum;
    for (int i = k; i < n; i++) {
      sum += a[i] - a[i - k];
      best = Math.max(best, sum);
    }
    System.out.println(best);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
5 2
-3 -2 -5 -1 -4
```

**기대 출력**

```text
-5
```

**예제 2 입력**

```text
3 3
1 2 3
```

**기대 출력**

```text
6
```

## 복잡도와 주의점

시간 O(N), 공간 O(N).

값이 모두 음수일 수 있어 최댓값을 0으로 초기화하면 틀린다. 첫 구간 합으로 시작한다.
