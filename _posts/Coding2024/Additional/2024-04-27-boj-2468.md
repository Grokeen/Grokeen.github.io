실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

비의 높이에 따라 잠기지 않은 칸의 연결 요소 수가 달라진다. 가능한 수위를 모두 검사하고 안전 영역 수의 최댓값을 구한다.

## 풀이 순서

1. 격자의 최대 높이를 구한다.
2. 수위 0부터 최대 높이까지 방문 배열을 새로 만든다.
3. 수위보다 높은 칸의 사방 연결 요소를 센다.

## 풀이가 성립하는 이유

수위가 같은 높이 사이에서 바뀌어도 잠기는 칸은 같으므로 정수 높이 후보만 검사하면 충분하다. 비가 오지 않은 수위 0도 포함해 한 영역인 경우를 놓치지 않는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      max = 0;
    int[][] a = new int[n][n];
    for (int r = 0; r < n; r++) for (int c = 0; c < n; c++) {
      a[r][c] = fs.nextInt();
      max = Math.max(max, a[r][c]);
    }
    int best = 0;
    int[] dr = { -1, 1, 0, 0 },
      dc = { 0, 0, -1, 1 };
    for (int water = 0; water <= max; water++) {
      boolean[][] seen = new boolean[n][n];
      int count = 0;
      for (int r = 0; r < n; r++) for (int c = 0; c < n; c++) if (
        !seen[r][c] && a[r][c] > water
      ) {
        count++;
        Deque<Integer> q = new ArrayDeque<>();
        q.add(r * n + c);
        seen[r][c] = true;
        while (!q.isEmpty()) {
          int p = q.poll(),
            x = p / n,
            y = p % n;
          for (int k = 0; k < 4; k++) {
            int rr = x + dr[k],
              cc = y + dc[k];
            if (
              rr >= 0 && cc >= 0 && rr < n && cc < n && !seen[rr][cc] && a[rr][cc] > water
            ) {
              seen[rr][cc] = true;
              q.add(rr * n + cc);
            }
          }
        }
      }
      best = Math.max(best, count);
    }
    System.out.println(best);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(HN²), 공간 O(N²). H는 최대 높이+1.

물 높이와 같은 칸도 잠긴다. 이전 수위의 방문 배열을 초기화한다.
