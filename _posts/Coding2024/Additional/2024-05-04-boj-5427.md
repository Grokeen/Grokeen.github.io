> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

불의 확산 시간과 사람의 이동 시간을 나누어 계산한다. 사람은 불이 이미 있거나 같은 시간에 도달하는 칸으로 갈 수 없고 격자 밖으로 한 번 더 이동해야 탈출이다.

## 풀이 순서

1. 모든 불에서 다중 시작점 BFS한다.
2. 사람은 불보다 먼저 도달 가능한 칸만 BFS한다.
3. 격자 밖 이동을 발견하면 현재 시간+1을 반환한다.

## 풀이가 성립하는 이유

위험 도착 시간 제한 아래의 무가중 최단 경로다. 밖으로 나가는 간선도 1초이므로 가장 먼저 발견한 탈출 시간이 최소다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

import java.io.*;
import java.util.*;

public class Main {
  static final FastScanner fs=new FastScanner(System.in);
  public static void main(String[] args) throws Exception {
    StringBuilder out=new StringBuilder();
    int t=fs.nextInt();while(t-->0){int m=fs.nextInt(),n=fs.nextInt(),start=0;char[][] a=new char[n][];int[][] fire=new int[n][m],d=new int[n][m];for(int[] row:fire)Arrays.fill(row,-1);for(int[] row:d)Arrays.fill(row,-1);Deque<Integer> q=new ArrayDeque<>();for(int r=0;r<n;r++){a[r]=fs.next().toCharArray();for(int c=0;c<m;c++){if(a[r][c]=='*'){fire[r][c]=0;q.add(r*m+c);}if(a[r][c]=='@')start=r*m+c;}}int[] dr={-1,1,0,0},dc={0,0,-1,1};while(!q.isEmpty()){int p=q.poll(),r=p/m,c=p%m;for(int k=0;k<4;k++){int x=r+dr[k],y=c+dc[k];if(x>=0&&y>=0&&x<n&&y<m&&a[x][y]!='#'&&fire[x][y]<0){fire[x][y]=fire[r][c]+1;q.add(x*m+y);}}}q.add(start);d[start/m][start%m]=0;int answer=-1;escape:while(!q.isEmpty()){int p=q.poll(),r=p/m,c=p%m;for(int k=0;k<4;k++){int x=r+dr[k],y=c+dc[k],next=d[r][c]+1;if(x<0||y<0||x>=n||y>=m){answer=next;break escape;}if(a[x][y]!='#'&&d[x][y]<0&&(fire[x][y]<0||fire[x][y]>next)){d[x][y]=next;q.add(x*m+y);}}}out.append(answer<0?"IMPOSSIBLE":Integer.toString(answer)).append("\n");}System.out.print(out);
  }

  static final class FastScanner {
    private final InputStream in; private final byte[] buffer=new byte[1<<16]; private int ptr,len;
    FastScanner(InputStream in){this.in=in;}
    private int read() throws IOException {if(ptr>=len){len=in.read(buffer);ptr=0;if(len<0)return -1;}return buffer[ptr++]&255;}
    String next() throws IOException {int c;do{c=read();}while(c<=32&&c!=-1);if(c==-1)return null;ByteArrayOutputStream b=new ByteArrayOutputStream();while(c>32&&c!=-1){b.write(c);c=read();}return b.toString("UTF-8");}
    long nextLong() throws IOException {int c;do{c=read();}while(c<=32&&c!=-1);if(c==-1)throw new EOFException();int sign=1;if(c==45){sign=-1;c=read();}long value=0;while(c>32&&c!=-1){value=value*10+c-48;c=read();}return value*sign;}
    int nextInt() throws IOException {return Math.toIntExact(nextLong());}
  }
}

## 복잡도와 주의점

시간 O(T·WH), 공간 O(WH).

가장자리 칸에 서는 것과 밖으로 나가는 것은 1초 차이다. 테스트별 불·사람 거리 배열을 초기화한다.
