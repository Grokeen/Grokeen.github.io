## 문제를 이해한 방식

2×2 정사각형 타일이 추가되어 폭 2를 마무리하는 방식이 두 가지가 된다. 이전 타일링 문제의 점화식에서 달라진 선택 수를 분리한다.

## 풀이 순서

1. 폭 0과 1의 방법을 초기화한다.
2. 세로 한 장은 dp[n-1]을 더한다.
3. 폭 2 두 방식은 2·dp[n-2]를 더한다.

## 풀이가 성립하는 이유

오른쪽 끝이 세로, 가로 두 장, 정사각형 한 장인 세 경우로 나뉜다. 폭 2 두 경우의 나머지 배치 수가 같아 계수 2가 붙는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    int[] d = new int[n + 2];
    d[0] = 1;
    d[1] = 1;
    for (int i = 2; i <= n; i++) d[i] = (d[i - 1] + 2 * d[i - 2]) % 10007;
    System.out.println(d[n]);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(N), 공간 O(N).

11726의 점화식을 그대로 복사하지 않는다. 나머지 10007을 매번 적용한다.
