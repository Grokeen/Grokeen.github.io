> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

절댓값이 작은 수를 먼저 꺼내고 같은 절댓값이면 원래 수가 작은 것을 먼저 꺼낸다. 두 비교 기준을 일관되게 구성한다.

## 풀이 순서

1. 절댓값을 long으로 비교한다.
2. 동률이면 정수 자체를 비교한다.
3. 0 입력은 제거 요청으로 처리한다.

## 풀이가 성립하는 이유

비교 함수가 요구된 사전식 우선순위를 표현하므로 poll이 곧 정답이다. 음수의 절댓값 계산에서 int 최솟값 문제를 피하도록 long으로 먼저 바꾼다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    PriorityQueue<Integer> q = new PriorityQueue<>((a, b) -> {
      int c = Long.compare(Math.abs((long) a), Math.abs((long) b));
      return c != 0 ? c : Integer.compare(a, b);
    });
    for (int i = 0; i < n; i++) {
      int x = fs.nextInt();
      if (x != 0) q.offer(x);
      else {
        Integer v = q.poll();
        out.append(v == null ? 0 : v).append("\n");
      }
    }
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(N log N), 공간 O(N).

절댓값만 비교하면 -1과 1의 순서가 정해지지 않는다. a-b 비교 오버플로도 피한다.
