실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

질의 값이 보유 목록에 몇 번 등장하는지 센다. 같은 질의가 반복될 수 있으므로 매번 배열 전체를 스캔하지 않고 빈도를 미리 집계한다.

## 풀이 순서

1. 카드 값을 읽어 Map의 개수를 증가시킨다.
2. 질의마다 getOrDefault로 개수를 읽는다.
3. 질의 순서에 맞춰 결과를 출력한다.

## 풀이가 성립하는 이유

Map의 값은 입력에서 해당 카드가 등장한 횟수다. 카드가 없는 경우 0을 반환하므로 모든 질의를 같은 방식으로 처리할 수 있다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    Map<Integer, Integer> count = new HashMap<>();
    for (int i = 0; i < n; i++) count.merge(fs.nextInt(), 1, Integer::sum);
    int m = fs.nextInt();
    for (int i = 0; i < m; i++) {
      if (i > 0) out.append(" ");
      out.append(count.getOrDefault(fs.nextInt(), 0));
    }
    System.out.println(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
5
2 -1 2 3 2
4
2 0 -1 3
```

**기대 출력**

```text
3 0 1 1
```

**예제 2 입력**

```text
1
7
2
7 8
```

**기대 출력**

```text
1 0
```

## 복잡도와 주의점

평균 시간 O(N+M), 공간 O(U+M) 출력 포함.

음수도 키로 허용한다. 질의 결과가 정렬되는 것이 아니라 질의 순서를 따라야 한다.
