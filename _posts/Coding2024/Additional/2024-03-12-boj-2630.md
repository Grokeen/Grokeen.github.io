실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

정사각형이 같은 색이면 한 장이고 아니면 네 부분으로 나눈다. 종이의 개수와 달리 분할 수가 4개이며 색은 두 종류다.

## 풀이 순서

1. 영역의 균일성을 확인한다.
2. 균일하면 색별 장수를 늘린다.
3. 아니면 반으로 나눈 네 영역을 각각 처리한다.

## 풀이가 성립하는 이유

각 분할은 원래 영역을 겹치지 않게 덮는다. 균일 영역을 세고 나머지에 같은 규칙을 적용하면 최종 색종이의 개수가 정확히 합산된다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    paper = new int[n][n];
    for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) paper[i][j] = fs.nextInt();
    divide(0, 0, n);
    System.out.println(counts[0] + "\n" + counts[1]);
  }

  static int[][] paper;
  static int[] counts = new int[2];

  static boolean same(int r, int c, int n) {
    for (int i = r; i < r + n; i++) for (int j = c; j < c + n; j++) if (
      paper[i][j] != paper[r][c]
    ) return false;
    return true;
  }

  static void divide(int r, int c, int n) {
    if (same(r, c, n)) {
      counts[paper[r][c]]++;
      return;
    }
    int k = n / 2;
    divide(r, c, k);
    divide(r, c + k, k);
    divide(r + k, c, k);
    divide(r + k, c + k, k);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
2
1 0
0 1
```

**기대 출력**

```text
2
2
```

**예제 2 입력**

```text
2
1 1
1 1
```

**기대 출력**

```text
0
1
```

## 복잡도와 주의점

최악 시간 O(N² log N), 공간 O(N²+log N).

출력은 흰색 개수 다음 파란색 개수다. 값 0과 1의 의미를 뒤집지 않는다.
