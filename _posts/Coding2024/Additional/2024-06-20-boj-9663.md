## 문제를 이해한 방식

행마다 퀸 하나를 놓고 열·두 대각선 충돌을 배제한다. 비트마스크로 다음 행에 금지된 열을 계산하면 전체 보드 검사를 줄일 수 있다.

## 풀이 순서

1. 사용한 열과 두 방향 대각선 비트를 관리한다.
2. 가능한 열의 최하위 1비트를 하나씩 선택한다.
3. 다음 행에서 대각선 마스크를 한 칸 이동한다.

## 풀이가 성립하는 이유

행을 하나씩 처리하므로 같은 행 충돌은 없다. 열과 대각선 공격 위치를 배제한 후보만 선택해 모든 유효 배치를 정확히 한 번 생성한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    full = (1 << n) - 1;
    search(0, 0, 0);
    System.out.println(count);
  }

  static int full;
  static long count;

  static void search(int columns, int left, int right) {
    if (columns == full) {
      count++;
      return;
    }
    int available = full & ~(columns | left | right);
    while (available != 0) {
      int bit = available & -available;
      available -= bit;
      search(columns | bit, ((left | bit) << 1) & full, (right | bit) >>> 1);
    }
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

탐색 시간 상한 O(N!), 재귀 공간 O(N), 비트 상태는 상수 개.

대각선의 이동 방향과 마스크 범위를 확인한다. unsigned 우측 이동 >>>로 부호 비트 영향을 피한다.
