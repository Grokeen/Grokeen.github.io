실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

구간 합이 M으로 나누어떨어지는 조건은 양 끝 누적합의 나머지가 같다는 뜻이다. 각 나머지가 이전에 나온 횟수를 세어 새로운 구간을 누적한다.

## 풀이 순서

1. 빈 누적합의 나머지 0을 한 번 기록한다.
2. 새 누적합의 나머지를 계산한다.
3. 같은 나머지의 기존 개수를 답에 더한 뒤 빈도를 늘린다.

## 풀이가 성립하는 이유

prefix[r]-prefix[l]의 나머지가 0인 것과 두 나머지의 동등성은 같다. 현재 위치보다 앞선 누적합만 빈도에 들어 있으므로 각 구간이 정확히 한 번 계산된다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    long[] freq = new long[m];
    freq[0] = 1;
    long rem = 0,
      ans = 0;
    for (int i = 0; i < n; i++) {
      rem = (rem + fs.nextLong()) % m;
      ans += freq[(int) rem];
      freq[(int) rem]++;
    }
    System.out.println(ans);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3 3
1 2 3
```

**기대 출력**

```text
3
```

**예제 2 입력**

```text
4 1
1 1 1 1
```

**기대 출력**

```text
10
```

## 복잡도와 주의점

시간 O(N+M), 공간 O(M).

빈 누적합을 빠뜨리면 첫 원소에서 시작하는 구간을 놓친다. 구간 개수는 long이 필요하다.
