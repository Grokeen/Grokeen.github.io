실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

맨 앞 카드를 버리고 다음 카드를 뒤로 옮기는 작업을 큐로 그대로 표현한다. 카드가 한 장이 되면 멈춘다.

## 풀이 순서

1. 1부터 N을 큐에 넣는다.
2. 앞 한 장을 버린다.
3. 다음 앞 한 장을 뒤로 옮기는 작업을 반복한다.

## 풀이가 성립하는 이유

큐의 순서는 현재 카드 더미의 위에서 아래 순서다. poll과 offer로 한 번의 작업을 정확히 재현하므로 마지막 원소가 남는 카드다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 1; i <= n; i++) q.offer(i);
    while (q.size() > 1) {
      q.poll();
      q.offer(q.poll());
    }
    System.out.println(q.peek());
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(N), 공간 O(N).

N=1에서는 제거 작업을 시작하지 않는다. 버린 뒤 큐가 비는 상황을 반복 조건으로 막는다.
