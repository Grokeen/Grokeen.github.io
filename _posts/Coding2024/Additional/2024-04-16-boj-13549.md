실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

순간이동은 0초, 한 칸 걷기는 1초다. 간선 비용이 0과 1뿐이므로 0-1 BFS에서 0비용은 deque 앞, 1비용은 뒤에 넣는다.

## 풀이 순서

1. 시작 거리를 0, 나머지를 큰 값으로 둔다.
2. 더 짧은 거리를 찾을 때만 갱신한다.
3. 2배 위치는 앞에, ±1 위치는 뒤에 넣는다.

## 풀이가 성립하는 이유

deque가 작은 거리의 정점을 앞에서 처리하도록 유지된다. 단순 BFS처럼 첫 방문만 고정하지 않고 완화 조건을 사용해 0비용 경로의 개선을 반영한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int start = fs.nextInt(),
      target = fs.nextInt();
    int[] d = new int[100001];
    Arrays.fill(d, Integer.MAX_VALUE);
    Deque<Integer> q = new ArrayDeque<>();
    d[start] = 0;
    q.add(start);
    while (!q.isEmpty()) {
      int x = q.pollFirst();
      int twice = x * 2;
      if (twice < d.length && d[twice] > d[x]) {
        d[twice] = d[x];
        q.addFirst(twice);
      }
      for (int next : new int[] { x - 1, x + 1 })
        if (next >= 0 && next < d.length && d[next] > d[x] + 1) {
          d[next] = d[x] + 1;
          q.addLast(next);
        }
    }
    System.out.println(d[target]);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(B), 공간 O(B). B는 위치 범위이며 간선 수가 정점 수의 상수배다.

2배 이동에 1을 더하면 1697을 풀게 된다. x=0의 자기 이동도 엄격한 개선 조건으로 차단한다.
