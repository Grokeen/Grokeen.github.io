실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

주어진 화폐 단위 조건에서 큰 동전부터 최대한 사용해 개수를 줄인다. 모든 임의의 동전 집합에 같은 탐욕법이 성립하는 것은 아니다.

## 풀이 순서

1. 큰 단위부터 목표 금액을 나눈다.
2. 몫만큼 개수에 더한다.
3. 나머지 금액을 다음 작은 단위로 처리한다.

## 풀이가 성립하는 이유

작은 단위의 배수인 화폐 체계 조건에서는 큰 동전 하나를 여러 작은 동전으로 바꿔도 개수가 줄지 않는다. 큰 단위를 최대한 쓰는 선택을 반복할 수 있다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    long k = fs.nextLong();
    long[] a = new long[n];
    for (int i = 0; i < n; i++) a[i] = fs.nextLong();
    long count = 0;
    for (int i = n - 1; i >= 0; i--) {
      count += k / a[i];
      k %= a[i];
    }
    System.out.println(count);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3 14
1
5
10
```

**기대 출력**

```text
5
```

**예제 2 입력**

```text
3 6
1
2
4
```

**기대 출력**

```text
2
```

## 복잡도와 주의점

시간 O(N), 공간 O(N).

1,3,4 같은 임의 단위에 6을 만드는 변형은 탐욕법이 실패한다. 문제의 단위 조건을 근거로 사용한다.
