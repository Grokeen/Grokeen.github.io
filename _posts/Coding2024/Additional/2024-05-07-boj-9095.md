실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

합이 N인 순서 있는 표현의 개수를 센다. 마지막에 붙인 수가 1,2,3인 경우를 나누면 서로 겹치지 않는 점화식을 얻는다.

## 풀이 순서

1. dp[0]=1을 빈 표현의 한 가지로 둔다.
2. dp[i]에 가능한 dp[i-1],dp[i-2],dp[i-3]을 더한다.
3. 질의 중 최대값까지 한 번 계산한다.

## 풀이가 성립하는 이유

모든 표현은 마지막 수에 따라 정확히 한 경우에 속한다. 마지막 수를 제거하면 더 작은 합의 표현과 일대일 대응하므로 세 개수를 합할 수 있다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int t = fs.nextInt(),
      max = 0;
    int[] query = new int[t];
    for (int i = 0; i < t; i++) {
      query[i] = fs.nextInt();
      max = Math.max(max, query[i]);
    }
    int[] d = new int[max + 1];
    d[0] = 1;
    for (int i = 1; i <= max; i++) for (int step = 1; step <= 3; step++) if (
      i >= step
    ) d[i] += d[i - step];
    for (int n : query) out.append(d[n]).append("\n");
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(max N+T), 공간 O(max N+T).

1+2와 2+1을 다른 경우로 센다. 순서 없는 동전 조합 DP와 반복 순서가 다르다.
