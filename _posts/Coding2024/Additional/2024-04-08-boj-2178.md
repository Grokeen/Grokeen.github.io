실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

이동 비용이 모두 1인 격자에서 BFS로 최단 경로를 찾는다. 이 문제의 거리는 시작 칸과 도착 칸을 포함한 칸 수다.

## 풀이 순서

1. 시작 칸 거리를 1로 둔다.
2. 이동 가능한 미방문 사방 칸을 거리+1로 넣는다.
3. 도착 칸의 거리를 출력한다.

## 풀이가 성립하는 이유

BFS가 거리 순으로 확장하므로 처음 방문한 값이 최소 칸 수다. 통로 여부와 방문 거리 배열을 분리해 벽과 미방문을 혼동하지 않는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    char[][] a = new char[n][];
    for (int i = 0; i < n; i++) a[i] = fs.next().toCharArray();
    int[][] d = new int[n][m];
    int[] dr = { -1, 1, 0, 0 },
      dc = { 0, 0, -1, 1 };
    Deque<Integer> q = new ArrayDeque<>();
    q.add(0);
    d[0][0] = 1;
    while (!q.isEmpty()) {
      int p = q.poll(),
        r = p / m,
        c = p % m;
      for (int k = 0; k < 4; k++) {
        int x = r + dr[k],
          y = c + dc[k];
        if (x >= 0 && y >= 0 && x < n && y < m && a[x][y] == '1' && d[x][y] == 0) {
          d[x][y] = d[r][c] + 1;
          q.add(x * m + y);
        }
      }
    }
    System.out.println(d[n - 1][m - 1]);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
2 2
11
11
```

**기대 출력**

```text
3
```

**예제 2 입력**

```text
2 3
111
001
```

**기대 출력**

```text
4
```

## 복잡도와 주의점

시간 O(NM), 공간 O(NM).

시작 거리를 0으로 두면 이동 횟수가 되어 요구된 칸 수와 1 차이가 난다.
