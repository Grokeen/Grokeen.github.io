실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

같은 칸이라도 벽을 아직 부술 수 있는 상태와 이미 사용한 상태는 다르다. 좌표와 사용 여부를 함께 방문 상태로 저장한다.

## 풀이 순서

1. 거리 배열을 벽 사용 여부별 두 겹으로 만든다.
2. 빈 칸은 상태 유지, 벽은 사용 전일 때만 상태 1로 이동한다.
3. BFS에서 처음 도착한 거리 또는 불가능 시 -1을 출력한다.

## 풀이가 성립하는 이유

확장된 정점은 (행,열,사용 여부)다. 각 이동 비용이 1이므로 이 그래프에서 BFS가 최단 경로를 보장한다. 좌표만 방문 표시하면 더 유리한 상태를 버릴 수 있다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    char[][] a = new char[n][];
    for (int i = 0; i < n; i++) a[i] = fs.next().toCharArray();
    int[][][] d = new int[2][n][m];
    Deque<Integer> q = new ArrayDeque<>();
    q.add(0);
    d[0][0][0] = 1;
    int ans = -1;
    int[] dr = { -1, 1, 0, 0 },
      dc = { 0, 0, -1, 1 };
    while (!q.isEmpty()) {
      int code = q.poll(),
        used = code % 2,
        p = code / 2,
        r = p / m,
        c = p % m;
      if (r == n - 1 && c == m - 1) {
        ans = d[used][r][c];
        break;
      }
      for (int k = 0; k < 4; k++) {
        int x = r + dr[k],
          y = c + dc[k];
        if (x < 0 || y < 0 || x >= n || y >= m) continue;
        int next = used + (a[x][y] == '1' ? 1 : 0);
        if (next <= 1 && d[next][x][y] == 0) {
          d[next][x][y] = d[used][r][c] + 1;
          q.add((x * m + y) * 2 + next);
        }
      }
    }
    System.out.println(ans);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(NM), 공간 O(NM), 상태 수는 칸 수의 2배.

시작·도착 칸을 포함한 거리를 계산한다. 두 상태의 방문 기록을 합치지 않는다.
