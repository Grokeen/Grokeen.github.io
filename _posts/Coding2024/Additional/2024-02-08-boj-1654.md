실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

길이를 정하면 만들 수 있는 랜선 개수를 계산할 수 있다. 길이가 길어질수록 개수는 늘지 않으므로 가능한 최대 길이를 이분 탐색한다.

## 풀이 순서

1. 최대 입력 길이를 상한으로 둔다.
2. 중간 길이로 잘랐을 때 개수가 목표 이상인지 센다.
3. 가능하면 길이를 늘리고 아니면 줄인다.

## 풀이가 성립하는 이유

가능한 길이는 작은 쪽에 연속으로 모인다. 상한 중간값을 사용하면 인접한 두 경계에서도 진전하며 마지막 lo가 최대 가능 길이다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int k = fs.nextInt();
    long need = fs.nextLong(),
      hi = 0;
    long[] a = new long[k];
    for (int i = 0; i < k; i++) {
      a[i] = fs.nextLong();
      hi = Math.max(hi, a[i]);
    }
    long lo = 0;
    while (lo < hi) {
      long mid = lo + (hi - lo + 1) / 2,
        count = 0;
      for (long x : a) count += x / mid;
      if (count >= need) lo = mid;
      else hi = mid - 1;
    }
    System.out.println(lo);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
2 4
4
6
```

**기대 출력**

```text
2
```

**예제 2 입력**

```text
1 1
2147483647
```

**기대 출력**

```text
2147483647
```

## 복잡도와 주의점

시간 O(K log L), 공간 O(K).

길이 0으로 나누지 않도록 탐색을 구성한다. 길이 합·조각 수 누적에는 long을 사용한다.
