실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

양수 수열에서 합이 목표 이상인 가장 짧은 연속 구간을 찾는다. 오른쪽을 늘리면 합이 증가하고 왼쪽을 줄이면 감소하는 성질로 슬라이딩 윈도우를 쓴다.

## 풀이 순서

1. 오른쪽 원소를 합에 더한다.
2. 합이 목표 이상인 동안 길이를 갱신하고 왼쪽을 제거한다.
3. 정답이 한 번도 없으면 0을 출력한다.

## 풀이가 성립하는 이유

각 오른쪽 끝에 대해 조건을 만족하는 가장 짧은 왼쪽 위치까지 줄인다. 이전의 긴 구간은 이후 답을 개선하지 못하므로 버려도 된다. 각 포인터가 N번 이하 움직인다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    long target = fs.nextLong(),
      sum = 0;
    int[] a = new int[n];
    for (int i = 0; i < n; i++) a[i] = fs.nextInt();
    int left = 0,
      best = n + 1;
    for (int right = 0; right < n; right++) {
      sum += a[right];
      while (sum >= target) {
        best = Math.min(best, right - left + 1);
        sum -= a[left++];
      }
    }
    System.out.println(best == n + 1 ? 0 : best);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

1

## 복잡도와 주의점

시간 O(N), 공간 O(N).

양수 조건이 중요하다. 음수가 있는 수열에 그대로 적용하면 합의 단조성이 깨진다.
