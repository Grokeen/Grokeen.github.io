실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

여러 익은 토마토가 동시에 퍼지므로 모든 시작점을 큐에 넣는 다중 시작점 BFS를 사용한다. 빈 칸 -1은 통과하지 않는다.

## 풀이 순서

1. 처음 익은 칸을 모두 큐에 넣는다.
2. 인접한 0을 현재 값+1로 바꾸며 전파한다.
3. 0이 남으면 -1, 아니면 최대 날짜값-1을 출력한다.

## 풀이가 성립하는 이유

같은 큐에서 모든 출발점을 거리 0으로 시작한 것과 같다. 처음 도달한 날짜가 가장 가까운 익은 토마토에서 퍼진 최소 날짜다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int m = fs.nextInt(),
      n = fs.nextInt();
    int[][] a = new int[n][m];
    Deque<Integer> q = new ArrayDeque<>();
    for (int r = 0; r < n; r++) for (int c = 0; c < m; c++) {
      a[r][c] = fs.nextInt();
      if (a[r][c] == 1) q.add(r * m + c);
    }
    int[] dr = { -1, 1, 0, 0 },
      dc = { 0, 0, -1, 1 };
    while (!q.isEmpty()) {
      int p = q.poll(),
        r = p / m,
        c = p % m;
      for (int k = 0; k < 4; k++) {
        int x = r + dr[k],
          y = c + dc[k];
        if (x >= 0 && y >= 0 && x < n && y < m && a[x][y] == 0) {
          a[x][y] = a[r][c] + 1;
          q.add(x * m + y);
        }
      }
    }
    int max = 1;
    boolean missing = false;
    for (int[] row : a)
      for (int x : row) {
        if (x == 0) missing = true;
        max = Math.max(max, x);
      }
    System.out.println(missing ? -1 : max - 1);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3 1
1 0 0
```

**기대 출력**

```text
2
```

**예제 2 입력**

```text
3 1
1 -1 0
```

**기대 출력**

```text
-1
```

**예제 3 입력**

```text
2 1
1 1
```

**기대 출력**

```text
0
```

## 복잡도와 주의점

시간 O(NM), 공간 O(NM).

한 시작점씩 따로 BFS해 날짜를 덮어쓰지 않는다. 처음부터 모두 익었으면 0이다.
