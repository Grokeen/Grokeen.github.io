실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

각 원소 오른쪽에서 처음 만나는 더 큰 수를 찾는다. 아직 답을 못 찾은 인덱스를 단조 스택에 두면 뒤의 큰 값이 여러 후보를 한 번에 해결한다.

## 풀이 순서

1. 답을 -1로 초기화한다.
2. 현재 값보다 작은 스택 꼭대기들의 답을 현재 값으로 정한다.
3. 현재 인덱스를 스택에 넣는다.

## 풀이가 성립하는 이유

스택에 남은 값은 위로 갈수록 작거나 같다. 현재 값이 더 크면 해당 인덱스 뒤에서 그보다 큰 첫 값이므로 정답을 확정할 수 있다. 각 인덱스는 한 번만 제거된다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    int[] a = new int[n],
      ans = new int[n],
      st = new int[n];
    Arrays.fill(ans, -1);
    int top = 0;
    for (int i = 0; i < n; i++) a[i] = fs.nextInt();
    for (int i = 0; i < n; i++) {
      while (top > 0 && a[st[top - 1]] < a[i]) ans[st[--top]] = a[i];
      st[top++] = i;
    }
    for (int i = 0; i < n; i++) {
      if (i > 0) out.append(" ");
      out.append(ans[i]);
    }
    System.out.println(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
5
3 3 5 2 4
```

**기대 출력**

```text
5 5 -1 4 -1
```

**예제 2 입력**

```text
3
3 2 1
```

**기대 출력**

```text
-1 -1 -1
```

## 복잡도와 주의점

시간 O(N), 공간 O(N).

오큰수는 엄격하게 더 큰 값이다. 같은 값에서 pop하면 틀릴 수 있다. 값이 아니라 인덱스를 저장한다.
