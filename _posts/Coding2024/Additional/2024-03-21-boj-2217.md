실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

선택한 로프들이 같은 하중을 나눠 들 때 가장 약한 로프의 한계×로프 수가 전체 한계다. 정렬 후 각 원소를 최약 로프로 삼는 경우를 검사한다.

## 풀이 순서

1. 로프 한계를 오름차순 정렬한다.
2. i번째부터 끝까지 선택한 경우를 계산한다.
3. a[i]×(N-i)의 최댓값을 구한다.

## 풀이가 성립하는 이유

최약 로프가 정해졌다면 그보다 강한 로프를 추가하는 것이 최대 하중을 줄이지 않는다. 따라서 정렬된 접미사만 검사해도 모든 최적 후보를 포함한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    long[] a = new long[n];
    for (int i = 0; i < n; i++) a[i] = fs.nextLong();
    Arrays.sort(a);
    long best = 0;
    for (int i = 0; i < n; i++) best = Math.max(best, a[i] * (n - i));
    System.out.println(best);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(N log N), 공간 O(N).

모든 로프를 반드시 쓰는 문제가 아니다. 가장 강한 로프 한 개만 쓰는 경우도 검사한다.
