실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

소괄호와 대괄호가 섞이면 개수뿐 아니라 종류와 중첩 순서를 확인해야 한다. 문장 안의 다른 문자는 무시하고 괄호만 스택에 반영한다.

## 풀이 순서

1. 한 줄 전체를 읽고 점 한 글자면 종료한다.
2. 여는 괄호는 스택에 넣고 닫는 괄호는 꼭대기 종류와 비교한다.
3. 오류가 없고 스택이 비면 yes다.

## 풀이가 성립하는 이유

가장 최근 열린 괄호가 가장 먼저 닫혀야 하므로 LIFO가 맞다. 종류가 다르거나 스택이 비어 있으면 이후 입력으로 복구할 수 없는 오류다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    String line;
    while ((line = br.readLine()) != null && !line.equals(".")) {
      Deque<Character> st = new ArrayDeque<>();
      boolean ok = true;
      for (char c : line.toCharArray()) {
        if (c == '(' || c == '[') st.push(c);
        else if (c == ')' || c == ']') {
          if (st.isEmpty() || st.pop() != (c == ')' ? '(' : '[')) {
            ok = false;
            break;
          }
        }
      }
      out.append(ok && st.isEmpty() ? "yes" : "no").append("\n");
    }
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
([text]).
([)].
hello.
.
```

**기대 출력**

```text
yes
no
yes
```

**예제 2 입력**

```text
(
.
```

**기대 출력**

```text
no
```

## 복잡도와 주의점

시간 O(전체 문자 수), 공간 O(최대 중첩 깊이).

공백이 있는 문장이므로 next 한 토큰으로 읽지 않는다. 종료는 문장 속 점이 아니라 점만 있는 한 줄이다.
