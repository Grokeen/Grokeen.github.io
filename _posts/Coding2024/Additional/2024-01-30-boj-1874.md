실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

1부터 N까지 오름차순으로 push하면서 주어진 순서로 pop할 수 있는지 확인한다. 다음 목표보다 작은 수는 필요한 만큼 넣을 수 있지만 이미 지나간 수의 순서를 바꿀 수 없다.

## 풀이 순서

1. 다음에 넣을 수를 1로 시작한다.
2. 목표값까지 push하고 +를 기록한다.
3. 꼭대기가 목표면 pop하고 아니면 NO다.

## 풀이가 성립하는 이유

목표값이 아직 들어오지 않았다면 그 값까지 push하는 선택밖에 없다. 이미 들어온 목표가 꼭대기가 아니면 위의 원소를 먼저 빼야 하므로 목표 수열을 만들 수 없다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      next = 1;
    Deque<Integer> st = new ArrayDeque<>();
    boolean ok = true;
    for (int i = 0; i < n; i++) {
      int target = fs.nextInt();
      if (!ok) continue;
      while (next <= target) {
        st.push(next++);
        out.append("+\n");
      }
      if (st.isEmpty() || st.pop() != target) ok = false;
      else out.append("-\n");
    }
    System.out.print(ok ? out.toString() : "NO\n");
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(N), 공간 O(N). 각 수는 한 번 들어가고 한 번 나온다.

실패하면 중간 연산 기록을 출력하지 않고 NO만 출력한다.
