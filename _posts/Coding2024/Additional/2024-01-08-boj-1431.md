실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

문자열 길이, 포함된 숫자의 합, 사전순이라는 세 기준을 차례로 비교한다. 숫자의 합은 숫자 문자만 대상으로 계산한다.

## 풀이 순서

1. 길이를 먼저 비교한다.
2. 같으면 숫자 합을 비교한다.
3. 두 값도 같으면 문자열 자체를 비교한다.

## 풀이가 성립하는 이유

앞 기준이 다른 경우 뒤 기준은 결과에 영향을 주지 않는다. 모든 기준이 같으면 같은 문자열 순서다. 숫자 문자의 코드값이 아니라 0을 뺀 값을 더한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    String[] a = new String[n];
    for (int i = 0; i < n; i++) a[i] = fs.next();
    Arrays.sort(
      a,
      Comparator.comparingInt(String::length)
        .thenComparingInt(Main::digitSum)
        .thenComparing(Comparator.naturalOrder())
    );
    for (String s : a) out.append(s).append("\n");
    System.out.print(out);
  }

  static int digitSum(String s) {
    int sum = 0;
    for (char c : s.toCharArray()) if (c >= '0' && c <= '9') sum += c - '0';
    return sum;
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
4
A1
B0
AB
Z
```

**기대 출력**

```text
Z
AB
B0
A1
```

**예제 2 입력**

```text
1
X9
```

**기대 출력**

```text
X9
```

## 복잡도와 주의점

시간 O(N log N·L), 공간 O(N·L).

알파벳을 숫자 합에 포함하지 않는다. 문자열 숫자 전체를 하나의 정수로 파싱하는 문제도 아니다.
