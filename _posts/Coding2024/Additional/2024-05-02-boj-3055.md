실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

물이 각 칸에 도착하는 시간을 먼저 계산하고 고슴도치가 그보다 먼저 도착할 수 있는 칸만 탐색한다. 도착지 D는 물이 들어가지 않는 별도 칸이다.

## 풀이 순서

1. 물의 다중 시작점 BFS로 도착 시간을 구한다.
2. 고슴도치 BFS에서는 다음 시간에 물이 차는 칸을 제외한다.
3. D에 도착하면 시간, 아니면 KAKTUS를 출력한다.

## 풀이가 성립하는 이유

시간에 따라 변하는 위험을 최초 도착 시간 제약으로 바꾼다. 다음 칸 도착 시간이 물과 같으면 허용하지 않고, 도착지를 물 탐색에서 제외해 규칙을 반영한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt(),
      start = 0,
      end = 0;
    char[][] a = new char[n][];
    int[][] water = new int[n][m],
      d = new int[n][m];
    for (int[] row : water) Arrays.fill(row, -1);
    for (int[] row : d) Arrays.fill(row, -1);
    Deque<Integer> q = new ArrayDeque<>();
    for (int r = 0; r < n; r++) {
      a[r] = fs.next().toCharArray();
      for (int c = 0; c < m; c++) {
        if (a[r][c] == '*') {
          water[r][c] = 0;
          q.add(r * m + c);
        }
        if (a[r][c] == 'S') start = r * m + c;
        if (a[r][c] == 'D') end = r * m + c;
      }
    }
    int[] dr = { -1, 1, 0, 0 },
      dc = { 0, 0, -1, 1 };
    while (!q.isEmpty()) {
      int p = q.poll(),
        r = p / m,
        c = p % m;
      for (int k = 0; k < 4; k++) {
        int x = r + dr[k],
          y = c + dc[k];
        if (
          x >= 0 &&
          y >= 0 &&
          x < n &&
          y < m &&
          water[x][y] < 0 &&
          a[x][y] != 'X' &&
          a[x][y] != 'D'
        ) {
          water[x][y] = water[r][c] + 1;
          q.add(x * m + y);
        }
      }
    }
    q.add(start);
    d[start / m][start % m] = 0;
    while (!q.isEmpty()) {
      int p = q.poll(),
        r = p / m,
        c = p % m;
      for (int k = 0; k < 4; k++) {
        int x = r + dr[k],
          y = c + dc[k],
          next = d[r][c] + 1;
        if (
          x >= 0 &&
          y >= 0 &&
          x < n &&
          y < m &&
          a[x][y] != 'X' &&
          d[x][y] < 0 &&
          (water[x][y] < 0 || water[x][y] > next)
        ) {
          d[x][y] = next;
          q.add(x * m + y);
        }
      }
    }
    int answer = d[end / m][end % m];
    System.out.println(answer < 0 ? "KAKTUS" : answer);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
1 3
S.D
```

```text
2
```

```text
1 3
S*D
```

**기대 출력**

```text
KAKTUS
```

## 복잡도와 주의점

시간 O(RC), 공간 O(RC).

물이 먼저 차는 칸에 같은 분에 진입할 수 없다. 물이 없거나 도착하지 않는 칸의 -1 표시는 안전 시간 무한대로 취급한다.
