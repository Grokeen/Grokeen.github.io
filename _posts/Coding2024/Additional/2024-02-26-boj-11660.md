실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

2차원 누적합은 직사각형 합을 네 값으로 계산한다. 위·왼쪽 영역을 빼며 두 번 빠진 겹친 부분을 다시 더한다.

## 풀이 순서

1. 0행·0열을 여유 경계로 둔다.
2. 현재 값+위+왼쪽-대각선으로 누적합을 만든다.
3. 질의의 두 모서리로 포함·배제 공식을 적용한다.

## 풀이가 성립하는 이유

prefix[x][y]는 좌상단부터 x,y까지의 합이다. 위와 왼쪽을 제외할 때 교집합이 두 번 제거되므로 한 번 더해 정확히 목표 직사각형만 남긴다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    long[][] p = new long[n + 1][n + 1];
    for (int x = 1; x <= n; x++) for (int y = 1; y <= n; y++) p[x][y] =
      fs.nextLong() + p[x - 1][y] + p[x][y - 1] - p[x - 1][y - 1];
    for (int i = 0; i < m; i++) {
      int x1 = fs.nextInt(),
        y1 = fs.nextInt(),
        x2 = fs.nextInt(),
        y2 = fs.nextInt();
      out
        .append(p[x2][y2] - p[x1 - 1][y2] - p[x2][y1 - 1] + p[x1 - 1][y1 - 1])
        .append("\n");
    }
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
2 2
1 2
3 4
1 1 2 2
2 2 2 2
```

**기대 출력**

```text
10
4
```

**예제 2 입력**

```text
1 1
5
1 1 1 1
```

**기대 출력**

```text
5
```

## 복잡도와 주의점

시간 O(N²+M), 공간 O(N²+M).

좌표를 0부터로 바꾸는 중간에 1기준 공식을 섞지 않는다. 큰 합은 long으로 저장한다.
