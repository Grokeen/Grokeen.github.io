실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

각 위치에서 끝나는 엄격히 증가하는 부분 수열의 최대 길이를 구한다. 연속 구간이 아니므로 중간 원소를 건너뛸 수 있다.

## 풀이 순서

1. dp[i]를 1로 초기화한다.
2. j<i이고 a[j]<a[i]인 모든 이전 위치를 비교한다.
3. dp[j]+1의 최댓값으로 갱신하고 전체 최댓값을 출력한다.

## 풀이가 성립하는 이유

i에서 끝나는 길이 2 이상 수열은 어떤 이전 j에서 끝나는 수열 뒤에 i를 붙인 것이다. 가능한 j를 모두 검사해 최적 길이를 얻는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    int[] a = new int[n],
      d = new int[n];
    for (int i = 0; i < n; i++) a[i] = fs.nextInt();
    int best = 0;
    for (int i = 0; i < n; i++) {
      d[i] = 1;
      for (int j = 0; j < i; j++) if (a[j] < a[i]) d[i] = Math.max(d[i], d[j] + 1);
      best = Math.max(best, d[i]);
    }
    System.out.println(best);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(N²), 공간 O(N).

같은 값은 엄격한 증가가 아니므로 <=가 아니라 <를 쓴다. 연속 오름차순 구간 길이와 다르다.
