실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

모든 도시 쌍의 최단 비용을 구한다. 중간 정점으로 허용할 집합을 하나씩 늘리는 Floyd–Warshall을 사용한다. 평행 간선은 처음부터 최솟값을 저장한다.

## 풀이 순서

1. 자기 자신은 0, 나머지는 INF로 초기화한다.
2. k를 가장 바깥 반복으로 두고 i→k→j를 비교한다.
3. 도달 불가 쌍은 0으로 출력한다.

## 풀이가 성립하는 이유

k단계 이후 거리는 1~k 정점만 중간에 쓰는 최단 거리다. k를 쓰지 않는 기존 값과 쓰는 두 경로의 합을 비교해 이 불변식을 유지한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    long inf = Long.MAX_VALUE / 4;
    long[][] d = new long[n + 1][n + 1];
    for (int i = 1; i <= n; i++) {
      Arrays.fill(d[i], inf);
      d[i][i] = 0;
    }
    for (int e = 0; e < m; e++) {
      int a = fs.nextInt(),
        b = fs.nextInt(),
        w = fs.nextInt();
      d[a][b] = Math.min(d[a][b], w);
    }
    for (int k = 1; k <= n; k++) for (int i = 1; i <= n; i++) for (
      int j = 1;
      j <= n;
      j++
    ) if (d[i][k] < inf && d[k][j] < inf) d[i][j] = Math.min(d[i][j], d[i][k] + d[k][j]);
    for (int i = 1; i <= n; i++) {
      for (int j = 1; j <= n; j++) {
        if (j > 1) out.append(" ");
        out.append(d[i][j] >= inf ? 0 : d[i][j]);
      }
      out.append("\n");
    }
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3
3
1 2 4
2 3 5
1 3 10
```

**기대 출력**

```text
0 4 9
0 0 5
0 0 0
```

**예제 2 입력**

```text
2
2
1 2 9
1 2 3
```

**기대 출력**

```text
0 3
0 0
```

## 복잡도와 주의점

시간 O(N³), 공간 O(N²).

간선 입력을 덮어쓰기만 하면 나중의 비싼 평행 간선이 남을 수 있다. k 반복 순서를 바꾸지 않는다.
