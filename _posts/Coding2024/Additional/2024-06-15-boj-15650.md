> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

같은 수를 중복 선택하지 않는 조합을 오름차순으로 출력한다. 다음 선택을 현재 값보다 크게 제한하면 순서만 다른 중복 경우를 없앨 수 있다.

## 풀이 순서

1. 다음 후보의 최소값 start를 전달한다.
2. 현재 x를 고르면 다음은 x+1부터 선택한다.
3. 깊이 M에서 수열을 출력한다.

## 풀이가 성립하는 이유

모든 선택 집합은 유일한 오름차순 표현을 가진다. 증가하는 경로만 생성하면 그 표현을 정확히 한 번 방문하므로 중복 제거 Set이 필요 없다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    n = fs.nextInt();
    m = fs.nextInt();
    chosen = new int[m];
    dfs(0, 1);
    System.out.print(answer);
  }

  static int n, m;
  static int[] chosen;
  static StringBuilder answer = new StringBuilder();

  static void dfs(int depth, int start) {
    if (depth == m) {
      for (int i = 0; i < m; i++) {
        if (i > 0) answer.append(" ");
        answer.append(chosen[i]);
      }
      answer.append("\n");
      return;
    }
    for (int x = start; x <= n - (m - depth) + 1; x++) {
      chosen[depth] = x;
      dfs(depth + 1, x + 1);
    }
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3 2
```

**기대 출력**

```text
1 2
1 3
2 3
```

**예제 2 입력**

```text
2 2
```

**기대 출력**

```text
1 2
```

## 복잡도와 주의점

시간 O(C(N,M)·M+탐색 노드), 공간 O(M+출력 길이).

다음 시작을 x로 넘기면 같은 수를 다시 고르는 중복 조합이 된다.
