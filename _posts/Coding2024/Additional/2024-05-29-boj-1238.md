실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

모든 학생의 왕복 최단 시간을 구한다. X에서 각 정점으로의 거리와 각 정점에서 X로의 거리를 구하면 되며 후자는 역방향 그래프에서 X를 출발하면 얻는다.

## 풀이 순서

1. 원래 그래프와 모든 간선을 뒤집은 그래프를 만든다.
2. 각 그래프에서 X 출발 Dijkstra를 한 번씩 실행한다.
3. 두 거리 합의 최댓값을 구한다.

## 풀이가 성립하는 이유

원래 i→X 경로는 역방향 X→i 경로와 간선 비용 합이 같다. N번 탐색 대신 두 번으로 모든 왕복 거리를 얻는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt(),
      x = fs.nextInt();
    List<int[]>[] g = graph(n),
      rev = graph(n);
    for (int i = 0; i < m; i++) {
      int a = fs.nextInt(),
        b = fs.nextInt(),
        w = fs.nextInt();
      g[a].add(new int[] { b, w });
      rev[b].add(new int[] { a, w });
    }
    long[] go = shortest(g, x),
      back = shortest(rev, x);
    long best = 0;
    for (int i = 1; i <= n; i++) best = Math.max(best, go[i] + back[i]);
    System.out.println(best);
  }

  static final long INF = Long.MAX_VALUE / 4;

  static List<int[]>[] graph(int n) {
    List<int[]>[] g = new ArrayList[n + 1];
    for (int i = 1; i <= n; i++) g[i] = new ArrayList<>();
    return g;
  }

  static long[] shortest(List<int[]>[] g, int start) {
    long[] d = new long[g.length];
    Arrays.fill(d, INF);
    d[start] = 0;
    PriorityQueue<long[]> q = new PriorityQueue<>(Comparator.comparingLong(p -> p[0]));
    q.add(new long[] { 0, start });
    while (!q.isEmpty()) {
      long[] p = q.poll();
      int v = (int) p[1];
      if (p[0] != d[v]) continue;
      for (int[] e : g[v]) {
        long next = p[0] + e[1];
        if (next < d[e[0]]) {
          d[e[0]] = next;
          q.add(new long[] { next, e[0] });
        }
      }
    }
    return d;
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3 4 2
1 2 3
2 1 4
```

```text
7
```


```text
11
```

## 복잡도와 주의점

시간 O((N+M) log M), 공간 O(N+M).

편도 그래프의 방향을 무시하면 다른 문제를 풀게 된다. 문제의 모든 왕복 경로 존재 조건을 사용한다.
