실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

비음수 가중치 방향 그래프의 한 출발점 최단 거리를 구한다. 최소 힙으로 가장 짧은 후보를 먼저 처리하고 이미 낡은 거리 항목은 건너뛴다.

## 풀이 순서

1. 방향 간선을 인접 목록에 저장한다.
2. 시작 거리 0에서 Dijkstra 완화를 수행한다.
3. 도달하지 못한 정점은 INF 문자열로 출력한다.

## 풀이가 성립하는 이유

가장 작은 거리 후보를 꺼냈을 때 비음수 간선을 더해 우회해도 그보다 먼저 더 작은 미발견 경로가 생길 수 없다. stale 항목은 현재 거리와 다르므로 추가 확장하지 않는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt(),
      start = fs.nextInt();
    List<int[]>[] g = graph(n);
    for (int i = 0; i < m; i++) g[fs.nextInt()].add(
      new int[] { fs.nextInt(), fs.nextInt() }
    );
    long[] d = shortest(g, start);
    for (int i = 1; i <= n; i++) out
      .append(d[i] >= INF ? "INF" : Long.toString(d[i]))
      .append("\n");
    System.out.print(out);
  }

  static final long INF = Long.MAX_VALUE / 4;

  static List<int[]>[] graph(int n) {
    List<int[]>[] g = new ArrayList[n + 1];
    for (int i = 1; i <= n; i++) g[i] = new ArrayList<>();
    return g;
  }

  static long[] shortest(List<int[]>[] g, int start) {
    long[] d = new long[g.length];
    Arrays.fill(d, INF);
    d[start] = 0;
    PriorityQueue<long[]> q = new PriorityQueue<>(Comparator.comparingLong(p -> p[0]));
    q.add(new long[] { 0, start });
    while (!q.isEmpty()) {
      long[] p = q.poll();
      int v = (int) p[1];
      if (p[0] != d[v]) continue;
      for (int[] e : g[v]) {
        long next = p[0] + e[1];
        if (next < d[e[0]]) {
          d[e[0]] = next;
          q.add(new long[] { next, e[0] });
        }
      }
    }
    return d;
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
4 3
1
1 2 7
1 3 2
3 2 1
```

**기대 출력**

```text
0
3
2
INF
```

**예제 2 입력**

```text
1 0
1
```

**기대 출력**

```text
0
```

## 복잡도와 주의점

시간 O((V+E) log E), 공간 O(V+E), 중복 힙 삽입 구현 기준.

음수 간선에는 이 정당성이 성립하지 않는다. 무방향으로 양쪽에 넣지 않는다.
