> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

왼쪽에서 신호를 받을 수 있는 가장 가까운 높은 탑을 찾는다. 현재 탑보다 낮은 이전 탑은 현재 탑에 가려져 앞으로의 후보가 될 수 없다.

## 풀이 순서

1. 왼쪽부터 높이를 읽는다.
2. 현재보다 낮은 스택 꼭대기를 제거한다.
3. 남은 꼭대기의 번호를 답으로 쓰고 현재 탑을 넣는다.

## 풀이가 성립하는 이유

낮은 탑을 지워도 더 오른쪽에 있는 현재 탑이 이후 신호를 먼저 받으므로 손해가 없다. 스택 꼭대기는 아직 유효한 왼쪽 탑 중 가장 가까운 후보다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      top = 0;
    int[] heights = new int[n],
      idx = new int[n];
    for (int i = 1; i <= n; i++) {
      int h = fs.nextInt();
      while (top > 0 && heights[top - 1] < h) top--;
      if (i > 1) out.append(" ");
      out.append(top == 0 ? 0 : idx[top - 1]);
      heights[top] = h;
      idx[top++] = i;
    }
    System.out.println(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
5
6 9 5 7 4
```

**기대 출력**

```text
0 0 2 2 4
```

**예제 2 입력**

```text
3
1 2 3
```

**기대 출력**

```text
0 0 0
```

## 복잡도와 주의점

시간 O(N), 공간 O(N).

출력은 높이가 아니라 1부터 시작하는 탑 번호다. 문제 조건에 맞는 높이 비교와 수신 방향을 확인한다.
