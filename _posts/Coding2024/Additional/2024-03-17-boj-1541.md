실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

덧셈·뺄셈 식에 괄호를 넣어 값을 최소화한다. 첫 뺄셈 이후의 모든 수를 빼도록 묶으면 최소가 된다.

## 풀이 순서

1. 수를 읽으며 연산자 위치에서 값을 반영한다.
2. 첫 -를 만나면 이후는 빼기 모드로 전환한다.
3. 끝의 마지막 수도 가상 연산자로 처리한다.

## 풀이가 성립하는 이유

첫 - 이후의 덧셈 묶음을 모두 빼면 뺄 수 있는 양이 최대다. 처음 - 이전에는 양수를 덧셈으로 처리할 수밖에 없다. 입력에 임의의 곱셈·음수 문법이 없는 조건을 사용한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    String s = fs.next();
    long value = 0,
      ans = 0;
    boolean minus = false;
    for (int i = 0; i <= s.length(); i++) {
      char c = i < s.length() ? s.charAt(i) : '+';
      if (c >= '0' && c <= '9') value = value * 10 + c - '0';
      else {
        ans += minus ? -value : value;
        value = 0;
        if (c == '-') minus = true;
      }
    }
    System.out.println(ans);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
55-50+40
```

**기대 출력**

```text
-35
```

**예제 2 입력**

```text
001+002+3
```

**기대 출력**

```text
6
```

## 복잡도와 주의점

시간 O(식 길이), 공간 O(식 길이).

선행 0이 있어도 십진수로 누적한다. 마지막 숫자를 반영하는 처리를 빠뜨리지 않는다.
