실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

양수 수열의 연속 부분합이 목표와 같은 구간 수를 센다. 합이 너무 크면 왼쪽을 제거하고 같으면 개수를 늘린다.

## 풀이 순서

1. 오른쪽 원소를 합에 추가한다.
2. 목표보다 큰 동안 왼쪽을 제거한다.
3. 남은 합이 목표와 같으면 한 구간을 센다.

## 풀이가 성립하는 이유

양수이므로 오른쪽 끝이 정해졌을 때 목표 합을 만드는 왼쪽 끝은 최대 하나다. 너무 큰 합은 왼쪽을 늘리는 방향으로만 줄일 수 있다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    long target = fs.nextLong(),
      sum = 0;
    int[] a = new int[n];
    for (int i = 0; i < n; i++) a[i] = fs.nextInt();
    int left = 0,
      count = 0;
    for (int right = 0; right < n; right++) {
      sum += a[right];
      while (left <= right && sum > target) sum -= a[left++];
      if (sum == target) count++;
    }
    System.out.println(count);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
4 2
1 1 1 1
```

**기대 출력**

```text
3
```

**예제 2 입력**

```text
3 9
1 2 3
```

**기대 출력**

```text
0
```

## 복잡도와 주의점

시간 O(N), 공간 O(N).

0이나 음수가 있는 변형에서는 같은 오른쪽 끝에 여러 시작점이 가능해 이 구현을 그대로 쓰면 안 된다.
