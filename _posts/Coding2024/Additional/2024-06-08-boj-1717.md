> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

두 원소가 같은 집합인지 조회하고 집합을 합친다. DSU의 대표 원소가 같으면 연결된 집합이며 경로 압축과 크기 기준 합치기로 효율을 높인다.

## 풀이 순서

1. 0부터 N까지 각각 자기 집합으로 시작한다.
2. 합치기 요청은 두 대표를 연결한다.
3. 조회 요청은 대표 동등성을 출력한다.

## 풀이가 성립하는 이유

대표가 같은 원소는 같은 트리에 속한다. union은 두 트리를 하나로 만들며 경로 압축은 소속을 바꾸지 않고 대표까지의 경로만 짧게 한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    init(n);
    for (int i = 0; i < m; i++) {
      int type = fs.nextInt(),
        a = fs.nextInt(),
        b = fs.nextInt();
      if (type == 0) union(a, b);
      else out.append(find(a) == find(b) ? "YES" : "NO").append("\n");
    }
    System.out.print(out);
  }

  static int[] parent, size;

  static void init(int n) {
    parent = new int[n + 1];
    size = new int[n + 1];
    for (int i = 0; i <= n; i++) {
      parent[i] = i;
      size[i] = 1;
    }
  }

  static int find(int x) {
    while (x != parent[x]) {
      parent[x] = parent[parent[x]];
      x = parent[x];
    }
    return x;
  }

  static boolean union(int a, int b) {
    a = find(a);
    b = find(b);
    if (a == b) return false;
    if (size[a] < size[b]) {
      int t = a;
      a = b;
      b = t;
    }
    parent[b] = a;
    size[a] += size[b];
    return true;
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3 5
0 1 2
1 1 2
1 0 3
0 0 3
1 0 3
```

**기대 출력**

```text
YES
NO
YES
```

**예제 2 입력**

```text
1 2
1 0 0
1 0 1
```

**기대 출력**

```text
YES
NO
```

## 복잡도와 주의점

시간 O((N+M) α(N)), 공간 O(N+M) 출력 포함.

원소 0도 유효하다. 이미 같은 집합을 다시 합칠 때 크기를 중복 증가시키지 않는다.
