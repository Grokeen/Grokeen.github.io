> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

중복 단어를 없앤 뒤 길이 우선, 같은 길이에서는 사전순으로 정렬한다. 중복 제거와 정렬은 서로 다른 요구 조건이다.

## 풀이 순서

1. Set으로 중복을 제거한다.
2. 배열로 옮겨 길이와 사전순으로 정렬한다.
3. 각 단어를 한 번씩 출력한다.

## 풀이가 성립하는 이유

같은 단어는 Set에 하나만 남는다. 길이 비교 후 naturalOrder를 연결하면 같은 길이 단어의 순서까지 명확해진다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    Set<String> set = new HashSet<>();
    for (int i = 0; i < n; i++) set.add(fs.next());
    String[] a = set.toArray(new String[0]);
    Arrays.sort(
      a,
      Comparator.comparingInt(String::length).thenComparing(Comparator.naturalOrder())
    );
    for (String s : a) out.append(s).append("\n");
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

평균 중복 제거 O(N·L), 정렬 O(U log U·L), 공간 O(N·L). L은 단어 길이, U는 고유 단어 수.

길이만 정렬하면 같은 길이의 순서가 틀릴 수 있다. TreeSet 기본 정렬만 쓰면 길이 우선이 아니다.
