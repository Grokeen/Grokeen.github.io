실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

남길 치킨집 M개를 고른 뒤 각 집에서 가장 가까운 남은 점포까지의 거리 합을 계산한다. 거리는 장애물 없는 맨해튼 거리라 BFS가 필요 없다.

## 풀이 순서

1. 집과 점포 좌표를 별도 목록으로 만든다.
2. 점포 중 M개 조합을 탐색한다.
3. 집별 최소 거리의 합으로 정답을 갱신한다.

## 풀이가 성립하는 이유

각 점포 조합을 빠짐없이 확인한다. 한 조합 안에서는 집들이 서로 독립적으로 가장 가까운 점포를 선택하므로 집별 최솟값의 합이 그 조합의 정확한 비용이다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {
  static final FastScanner fs=new FastScanner(System.in);
  public static void main(String[] args) throws Exception {
    StringBuilder out=new StringBuilder();
    int n=fs.nextInt();keep=fs.nextInt();for(int r=0;r<n;r++)for(int c=0;c<n;c++){int x=fs.nextInt();if(x==1)homes.add(new int[]{r,c});if(x==2)shops.add(new int[]{r,c});}chosen=new int[keep];choose(0,0);System.out.println(best);
  }
  static int keep,best=Integer.MAX_VALUE;static List<int[]> homes=new ArrayList<>(),shops=new ArrayList<>();static int[] chosen;static void choose(int at,int start){if(at==keep){int total=0;for(int[] h:homes){int nearest=Integer.MAX_VALUE;for(int i:chosen){int[] s=shops.get(i);nearest=Math.min(nearest,Math.abs(h[0]-s[0])+Math.abs(h[1]-s[1]));}total+=nearest;}best=Math.min(best,total);return;}for(int i=start;i<=shops.size()-(keep-at);i++){chosen[at]=i;choose(at+1,i+1);}}
  static final class FastScanner {
    private final InputStream in; private final byte[] buffer=new byte[1<<16]; private int ptr,len;
    FastScanner(InputStream in){this.in=in;}
    private int read() throws IOException {if(ptr>=len){len=in.read(buffer);ptr=0;if(len<0)return -1;}return buffer[ptr++]&255;}
    String next() throws IOException {int c;do{c=read();}while(c<=32&&c!=-1);if(c==-1)return null;ByteArrayOutputStream b=new ByteArrayOutputStream();while(c>32&&c!=-1){b.write(c);c=read();}return b.toString("UTF-8");}
    long nextLong() throws IOException {int c;do{c=read();}while(c<=32&&c!=-1);if(c==-1)throw new EOFException();int sign=1;if(c==45){sign=-1;c=read();}long value=0;while(c>32&&c!=-1){value=value*10+c-48;c=read();}return value*sign;}
    int nextInt() throws IOException {return Math.toIntExact(nextLong());}
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
2 1
1 2
0 1
```

**기대 출력**

```text
2
```

**예제 2 입력**

```text
3 1
1 0 2
0 0 0
2 0 1
```

**기대 출력**

```text
4
```

## 복잡도와 주의점

시간 O(C(S,M)·H·M), 공간 O(S+H+M). S는 점포 수, H는 집 수.

도시 전체에 가장 가까운 점포 한 개를 고르는 문제가 아니다. 각 집의 최근접 점포가 달라도 된다.
