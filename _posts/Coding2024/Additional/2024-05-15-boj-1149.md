실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

이웃한 집이 같은 색이 아니도록 전체 비용을 최소화한다. 현재 집의 색을 상태에 포함하면 이전 집에서 허용된 두 색 중 작은 비용을 고를 수 있다.

## 풀이 순서

1. 이전 행의 색별 최솟값을 저장한다.
2. 현재 색 비용+다른 두 이전 색의 최솟값을 계산한다.
3. 마지막 세 값의 최솟값을 출력한다.

## 풀이가 성립하는 이유

현재 색이 정해지면 미래에 필요한 과거 정보는 그 색까지의 최소 비용뿐이다. 이전 두 색 선택을 모두 비교하므로 국소 최저 색만 고르는 오류를 피한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    long[] prev = new long[3];
    for (int i = 0; i < n; i++) {
      long[] cost = { fs.nextLong(), fs.nextLong(), fs.nextLong() },
        next = new long[3];
      for (int c = 0; c < 3; c++) next[c] =
        cost[c] + Math.min(prev[(c + 1) % 3], prev[(c + 2) % 3]);
      prev = next;
    }
    System.out.println(Math.min(prev[0], Math.min(prev[1], prev[2])));
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(N), 추가 공간 O(1).
