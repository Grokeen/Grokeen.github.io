실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

1부터 N 중 서로 다른 수 M개를 순서 있게 고른다. 같은 원소를 다시 쓰지 않도록 방문 배열을 관리하고 깊이 M에서 수열을 출력한다.

## 풀이 순서

1. 현재 깊이에서 1부터 N까지 후보를 본다.
2. 미사용 수를 선택하고 다음 깊이를 탐색한다.
3. 복귀하면 사용 표시를 되돌린다.

## 풀이가 성립하는 이유

선택 순서가 트리 경로와 같아 모든 순열이 한 번씩 만들어진다. 후보를 오름차순으로 보므로 출력도 사전순이며 복귀 시 상태 복원으로 다른 가지에 영향을 주지 않는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    n = fs.nextInt();
    m = fs.nextInt();
    chosen = new int[m];
    used = new boolean[n + 1];
    dfs(0);
    System.out.print(answer);
  }

  static int n, m;
  static int[] chosen;
  static boolean[] used;
  static StringBuilder answer = new StringBuilder();

  static void dfs(int depth) {
    if (depth == m) {
      for (int i = 0; i < m; i++) {
        if (i > 0) answer.append(" ");
        answer.append(chosen[i]);
      }
      answer.append("\n");
      return;
    }
    for (int x = 1; x <= n; x++) if (!used[x]) {
      used[x] = true;
      chosen[depth] = x;
      dfs(depth + 1);
      used[x] = false;
    }
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3 2
```

**기대 출력**

```text
1 2
1 3
2 1
2 3
3 1
3 2
```

**예제 2 입력**

```text
1 1
```

**기대 출력**

```text
1
```

## 복잡도와 주의점

시간 O(P(N,M)·M), 공간 O(N+M+출력 길이).

재귀 뒤 used를 복구하지 않으면 이후 경우가 누락된다. 조합처럼 시작값을 늘리는 문제가 아니다.
