실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

두 이름 집합의 교집합을 구하고 사전순으로 출력한다. 빠른 포함 검사와 출력 순서 요구를 분리한다.

## 풀이 순서

1. 첫 집합을 HashSet에 넣는다.
2. 두 번째 목록에서 첫 집합에 포함된 이름을 모은다.
3. 교집합을 정렬해 개수와 이름을 출력한다.

## 풀이가 성립하는 이유

이름이 두 목록 모두에 있을 때만 답에 들어간다. 입력 목록의 이름이 각각 중복되지 않는 조건을 사용하며 TreeSet으로 결과 중복도 방지한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    Set<String> heard = new HashSet<>();
    for (int i = 0; i < n; i++) heard.add(fs.next());
    Set<String> both = new TreeSet<>();
    for (int i = 0; i < m; i++) {
      String s = fs.next();
      if (heard.contains(s)) both.add(s);
    }
    out.append(both.size()).append("\n");
    for (String s : both) out.append(s).append("\n");
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

평균 시간 O(N+M+K log K), 문자열 비교 비용 별도. 공간 O(N+K).

교집합 개수를 먼저 출력한다. HashSet 순회를 사전순으로 착각하지 않는다.
