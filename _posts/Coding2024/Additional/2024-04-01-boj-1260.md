> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

같은 그래프를 깊이 우선과 너비 우선으로 방문한다. 여러 후보가 있으면 번호가 작은 정점부터 방문하므로 인접 목록을 정렬해야 한다.

## 풀이 순서

1. 무방향 간선을 양쪽 목록에 추가한다.
2. 인접 목록을 정렬하고 DFS를 수행한다.
3. 방문 배열을 초기화한 뒤 BFS를 수행한다.

## 풀이가 성립하는 이유

DFS는 현재 정점에서 더 깊이 진행하고 BFS는 발견한 순서대로 큐에서 꺼낸다. 방문 표시는 각 정점을 한 번만 출력하게 하며 정렬된 인접 목록이 동률 방문 순서를 정한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

## 직접 만든 확인 예제

**예제 1 입력**

```text
4 4 1

1 3

3 4
```

```text
1 2 4 3

```

**예제 2 입력**

```text

```

**기대 출력**

```text

1
```

## 복잡도와 주의점

탐색 O(V+E), 인접 정렬 비용 추가. 공간 O(V+E).

DFS의 방문 표시를 BFS에 그대로 쓰지 않는다. 재귀 깊이가 큰 변형에서는 반복 스택을 검토한다.
