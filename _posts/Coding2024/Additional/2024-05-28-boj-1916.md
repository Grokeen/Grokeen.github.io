실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

출발 도시에서 도착 도시까지 최소 버스 비용을 구한다. 같은 두 도시 사이에 여러 버스가 있을 수 있으므로 모든 간선을 보존해도 완화가 최소를 선택한다.

## 풀이 순서

1. 방향 버스 노선을 저장한다.
2. 출발점에서 Dijkstra를 실행한다.
3. 목표 도시의 최소 비용만 출력한다.

## 풀이가 성립하는 이유

양의 비용에서는 최소 거리 후보를 기준으로 탐색해 안전하게 거리를 확정할 수 있다. 평행 간선은 더 싼 경로가 거리를 갱신하므로 별도 중복 제거가 필수는 아니다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    List<int[]>[] g = graph(n);
    for (int i = 0; i < m; i++) g[fs.nextInt()].add(
      new int[] { fs.nextInt(), fs.nextInt() }
    );
    int start = fs.nextInt(),
      end = fs.nextInt();
    System.out.println(shortest(g, start)[end]);
  }

  static final long INF = Long.MAX_VALUE / 4;

  static List<int[]>[] graph(int n) {
    List<int[]>[] g = new ArrayList[n + 1];
    for (int i = 1; i <= n; i++) g[i] = new ArrayList<>();
    return g;
  }

  static long[] shortest(List<int[]>[] g, int start) {
    long[] d = new long[g.length];
    Arrays.fill(d, INF);
    d[start] = 0;
    PriorityQueue<long[]> q = new PriorityQueue<>(Comparator.comparingLong(p -> p[0]));
    q.add(new long[] { 0, start });
    while (!q.isEmpty()) {
      long[] p = q.poll();
      int v = (int) p[1];
      if (p[0] != d[v]) continue;
      for (int[] e : g[v]) {
        long next = p[0] + e[1];
        if (next < d[e[0]]) {
          d[e[0]] = next;
          q.add(new long[] { next, e[0] });
        }
      }
    }
    return d;
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

```text
3
4
```

```text
5
```

```text
2
1
1 2 8
1 2
```

**기대 출력**

```text
8
```

## 복잡도와 주의점

시간 O((N+M) log M), 공간 O(N+M).

목표까지 첫 발견된 비용이 아니라 최소 힙에서 처리되는 최적 비용을 사용한다. 간선 합은 long으로 둔다.
