실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

배열 뒤집기와 앞 원소 삭제를 반복한다. 실제로 매번 뒤집거나 맨 앞을 지우지 않고 남은 구간의 양 끝과 방향만 관리한다.

## 풀이 순서

1. 문자열 배열을 파싱한다.
2. R은 방향만 반전하고 D는 방향에 맞는 끝을 이동한다.
3. 삭제 시 빈 구간이면 error, 아니면 현재 방향대로 출력한다.

## 풀이가 성립하는 이유

남은 배열은 원본의 연속 구간이며 방향만 달라진다. R과 D가 이 표현을 유지하므로 전체 배열을 옮기지 않아도 동일한 결과를 얻는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int t = fs.nextInt();
    while (t-- > 0) {
      String cmd = fs.next();
      int n = fs.nextInt();
      String raw = fs.next();
      String[] a = n == 0 ? new String[0] : raw.substring(1, raw.length() - 1).split(",");
      int l = 0,
        r = n - 1;
      boolean rev = false,
        error = false;
      for (char c : cmd.toCharArray()) {
        if (c == 'R') rev = !rev;
        else if (l > r) {
          error = true;
          break;
        } else if (rev) r--;
        else l++;
      }
      if (error) {
        out.append("error\n");
        continue;
      }
      out.append("[");
      for (int k = 0; k <= r - l; k++) {
        if (k > 0) out.append(",");
        out.append(a[rev ? r - k : l + k]);
      }
      out.append("]\n");
    }
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3
RDD
4
[1,2,3,4]
D
0
[]
R
0
[]
```

**기대 출력**

```text
[2,1]
error
[]
```

**예제 2 입력**

```text
1
RR
1
[7]
```

**기대 출력**

```text
[7]
```

## 복잡도와 주의점

시간 O(명령 수+원소 수), 공간 O(원소 수).

빈 배열 []를 split하면 잘못된 원소가 생길 수 있어 별도 처리한다. R 자체는 빈 배열에서도 오류가 아니다.
