실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

이진 영상을 균일한 정사각형 단위로 압축한다. 균일하지 않으면 괄호 안에 네 사분면의 압축 결과를 정해진 순서로 이어 붙인다.

## 풀이 순서

1. 영역이 0 또는 1로 균일한지 검사한다.
2. 균일하면 한 문자만 출력한다.
3. 아니면 괄호를 열고 좌상·우상·좌하·우하를 재귀 출력한다.

## 풀이가 성립하는 이유

각 영역의 압축 표현은 균일 값 하나 또는 네 하위 표현으로 유일하게 구성된다. 사분면 순서를 지키면 원래 위치 정보를 괄호 구조가 보존한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    image = new char[n][];
    for (int i = 0; i < n; i++) image[i] = fs.next().toCharArray();
    encode(0, 0, n);
    System.out.println(encoded);
  }

  static char[][] image;
  static StringBuilder encoded = new StringBuilder();

  static void encode(int r, int c, int n) {
    boolean same = true;
    for (int i = r; i < r + n; i++) for (int j = c; j < c + n; j++) if (
      image[i][j] != image[r][c]
    ) same = false;
    if (same) {
      encoded.append(image[r][c]);
      return;
    }
    int k = n / 2;
    encoded.append("(");
    encode(r, c, k);
    encode(r, c + k, k);
    encode(r + k, c, k);
    encode(r + k, c + k, k);
    encoded.append(")");
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
2
10
01
```

**기대 출력**

```text
(1001)
```

**예제 2 입력**

```text
1
1
```

**기대 출력**

```text
1
```

## 복잡도와 주의점

최악 시간 O(N² log N), 공간 O(N²+출력 길이+log N).

같은 문자 수를 세는 것이 아니라 공간 위치를 보존하는 압축이다. 괄호를 중복하거나 빠뜨리지 않는다.
