실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

많은 정수를 오름차순으로 정렬한다. 입력·출력 호출을 원소마다 반복하는 비용을 줄이고 숫자 자료형에 맞는 정렬을 사용한다.

## 풀이 순서

1. 배열에 수를 모두 읽는다.
2. Arrays.sort로 정렬한다.
3. StringBuilder로 결과를 모아 한 번에 출력한다.

## 풀이가 성립하는 이유

정렬 후 모든 인접 원소가 비내림차순이면 전체 배열이 오름차순이다. 비교 정렬을 직접 구현하는 대신 표준 정렬과 입출력 병목을 구분해 학습한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    int[] a = new int[n];
    for (int i = 0; i < n; i++) a[i] = fs.nextInt();
    Arrays.sort(a);
    for (int x : a) out.append(x).append("\n");
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
4
10
-1
2
0
```

**기대 출력**

```text
-1
0
2
10
```

**예제 2 입력**

```text
1
7
```

```text
7
```

## 복잡도와 주의점

시간 평균 O(N log N), 배열·출력 공간 O(N). Java 11 기본형 정렬의 최악 시간 보장과는 구분한다.

문자열로 정렬하면 10이 2보다 먼저 올 수 있다. 숫자로 읽고 비교한다.
