실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

지금까지 지난 도시 중 가장 싼 가격으로 다음 도로의 연료를 산다고 생각한다. 미래의 싼 도시에 도달하려면 현재 도로를 지나야 하므로 미래 가격을 미리 사용할 수 없다.

## 풀이 순서

1. 도로 길이와 도시 가격을 읽는다.
2. 왼쪽부터 현재까지 최소 가격을 갱신한다.
3. 그 가격×다음 도로 길이를 더한다.

## 풀이가 성립하는 이유

더 싼 가격을 만나기 전에는 과거 최저 가격으로 필요한 연료를 미리 사는 것이 손해가 없다. 더 싼 도시 이후의 연료는 그 도시에서 사는 편이 낫다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    long[] road = new long[n - 1],
      price = new long[n];
    for (int i = 0; i < n - 1; i++) road[i] = fs.nextLong();
    for (int i = 0; i < n; i++) price[i] = fs.nextLong();
    long min = Long.MAX_VALUE,
      total = 0;
    for (int i = 0; i < n - 1; i++) {
      min = Math.min(min, price[i]);
      total += min * road[i];
    }
    System.out.println(total);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
4
2 3 1
5 2 4 1
```

**기대 출력**

```text
18
```

**예제 2 입력**

```text
2
3
7 1
```

**기대 출력**

```text
21
```

## 복잡도와 주의점

시간 O(N), 공간 O(N).

마지막 도시 가격은 지나온 도로 비용에 영향을 주지 않는다. 곱셈 전에 long으로 계산한다.
