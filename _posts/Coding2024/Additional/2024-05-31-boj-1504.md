실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

1에서 N으로 가면서 두 필수 정점을 모두 지나야 한다. 두 정점의 방문 순서는 두 가지뿐이므로 필요한 최단 거리 조각들을 합쳐 비교한다.

## 풀이 순서

1. 1,v1,v2에서 각각 Dijkstra를 실행한다.
2. 1→v1→v2→N과 반대 순서의 비용을 계산한다.
3. 둘 다 도달 불가면 -1이다.

## 풀이가 성립하는 이유

어떤 유효 경로도 두 필수 정점의 첫 방문 순서가 둘 중 하나다. 각 구간을 최단 경로로 교체해 비용을 늘리지 않을 수 있어 두 합의 최솟값이 답이다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      m = fs.nextInt();
    List<int[]>[] g = graph(n);
    for (int i = 0; i < m; i++) {
      int a = fs.nextInt(),
        b = fs.nextInt(),
        w = fs.nextInt();
      g[a].add(new int[] { b, w });
      g[b].add(new int[] { a, w });
    }
    int a = fs.nextInt(),
      b = fs.nextInt();
    long[] d1 = shortest(g, 1),
      da = shortest(g, a),
      db = shortest(g, b);
    long best = Math.min(d1[a] + da[b] + db[n], d1[b] + db[a] + da[n]);
    System.out.println(best >= INF ? -1 : best);
  }

  static final long INF = Long.MAX_VALUE / 4;

  static List<int[]>[] graph(int n) {
    List<int[]>[] g = new ArrayList[n + 1];
    for (int i = 1; i <= n; i++) g[i] = new ArrayList<>();
    return g;
  }

  static long[] shortest(List<int[]>[] g, int start) {
    long[] d = new long[g.length];
    Arrays.fill(d, INF);
    d[start] = 0;
    PriorityQueue<long[]> q = new PriorityQueue<>(Comparator.comparingLong(p -> p[0]));
    q.add(new long[] { 0, start });
    while (!q.isEmpty()) {
      long[] p = q.poll();
      int v = (int) p[1];
      if (p[0] != d[v]) continue;
      for (int[] e : g[v]) {
        long next = p[0] + e[1];
        if (next < d[e[0]]) {
          d[e[0]] = next;
          q.add(new long[] { next, e[0] });
        }
      }
    }
    return d;
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
4 3
1 2 1
2 3 1
3 4 1
2 3
```

**기대 출력**

```text
3
```

**예제 2 입력**

```text
4 1
1 2 1
2 3
```

**기대 출력**

```text
-1
```

## 복잡도와 주의점

시간 O((N+E) log E), 공간 O(N+E), 탐색 3회 상수 포함.

경로에서 정점 재방문이 허용되는 조건이다. INF 조각이 들어간 합을 정상 답으로 출력하지 않는다.
