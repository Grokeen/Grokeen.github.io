> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

재귀 피보나치를 그대로 실행하지 않고 기저 호출 0과 1의 횟수를 각각 DP로 센다. 두 종류의 횟수도 피보나치처럼 이전 두 상태를 더한다.

## 풀이 순서

1. n=0은 0 호출 한 번, n=1은 1 호출 한 번으로 둔다.
2. 각 횟수 배열을 이전 두 항의 합으로 갱신한다.
3. 질의마다 두 횟수를 출력한다.

## 풀이가 성립하는 이유

fib(n)의 호출 트리는 fib(n-1)과 fib(n-2)의 호출 트리를 합친 것이다. 따라서 두 기저 호출의 개수도 각각 합해진다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int t = fs.nextInt(),
      max = 1;
    int[] query = new int[t];
    for (int i = 0; i < t; i++) {
      query[i] = fs.nextInt();
      max = Math.max(max, query[i]);
    }
    int[] zero = new int[max + 1],
      one = new int[max + 1];
    zero[0] = 1;
    one[1] = 1;
    for (int i = 2; i <= max; i++) {
      zero[i] = zero[i - 1] + zero[i - 2];
      one[i] = one[i - 1] + one[i - 2];
    }
    for (int n : query) out.append(zero[n]).append(" ").append(one[n]).append("\n");
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3
0
1
3
```

**기대 출력**

```text
1 0
0 1
1 2
```

**예제 2 입력**

```text
1
2
```

**기대 출력**

```text
1 1
```

## 복잡도와 주의점

시간 O(max N+T), 공간 O(max N+T).

fib(n)의 값 하나와 0·1 호출 횟수 두 개를 혼동하지 않는다. n=0,1을 별도로 초기화한다.
