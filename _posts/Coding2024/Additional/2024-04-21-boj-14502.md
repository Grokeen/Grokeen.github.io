실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

빈 칸 세 곳을 벽으로 고른 뒤 바이러스가 퍼진 결과의 안전 칸 수를 비교한다. 작은 격자에서는 모든 벽 조합을 검사하는 완전 탐색이 가능하다.

## 풀이 순서

1. 빈 칸 목록에서 인덱스 증가 순으로 세 곳을 선택한다.
2. 원본을 복사하고 벽을 세워 다중 시작점 BFS한다.
3. 바이러스가 닿지 않은 0의 최댓값을 구한다.

## 풀이가 성립하는 이유

모든 세 칸 조합을 한 번씩 검사하므로 최적 벽 배치를 포함한다. 각 배치의 전파를 독립 복사본에서 계산해 이전 탐색의 오염을 막는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    rows = fs.nextInt();
    cols = fs.nextInt();
    lab = new int[rows][cols];
    for (int r = 0; r < rows; r++) for (int c = 0; c < cols; c++) {
      lab[r][c] = fs.nextInt();
      if (lab[r][c] == 0) empty.add(r * cols + c);
    }
    choose(0, 0);
    System.out.println(best);
  }

  static int rows, cols, best;
  static int[][] lab;
  static List<Integer> empty = new ArrayList<>();
  static int[] walls = new int[3],
    dr = { -1, 1, 0, 0 },
    dc = { 0, 0, -1, 1 };

  static void choose(int start, int depth) {
    if (depth == 3) {
      evaluate();
      return;
    }
    for (int i = start; i <= empty.size() - (3 - depth); i++) {
      walls[depth] = empty.get(i);
      choose(i + 1, depth + 1);
    }
  }

  static void evaluate() {
    int[][] a = new int[rows][cols];
    Deque<Integer> q = new ArrayDeque<>();
    for (int r = 0; r < rows; r++) {
      a[r] = lab[r].clone();
      for (int c = 0; c < cols; c++) if (a[r][c] == 2) q.add(r * cols + c);
    }
    for (int p : walls) a[p / cols][p % cols] = 1;
    while (!q.isEmpty()) {
      int p = q.poll(),
        r = p / cols,
        c = p % cols;
      for (int k = 0; k < 4; k++) {
        int x = r + dr[k],
          y = c + dc[k];
        if (x >= 0 && y >= 0 && x < rows && y < cols && a[x][y] == 0) {
          a[x][y] = 2;
          q.add(x * cols + y);
        }
      }
    }
    int safe = 0;
    for (int[] row : a) for (int x : row) if (x == 0) safe++;
    best = Math.max(best, safe);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(C(E,3)·NM), 공간 O(NM+E). E는 빈 칸 수.

바이러스 전파 후 원본이 바뀌면 다음 배치의 결과가 잘못된다. 벽을 세 개보다 적게 놓지 않는다.
