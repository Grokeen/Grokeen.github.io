실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

네 칸 도형 중 경로 모양은 깊이 4 DFS로 만들 수 있지만 T 모양은 한 번의 단순 경로로 덮을 수 없다. T를 중심+세 이웃으로 별도 검사한다.

## 풀이 순서

1. 모든 칸에서 4칸 단순 경로 DFS를 수행한다.
2. 각 중심에서 유효한 이웃 중 큰 세 값을 더한다.
3. 두 방식의 최대 합을 비교한다.

## 풀이가 성립하는 이유

일자·정사각형·L·S 계열은 4칸을 지나는 경로가 있다. 분기점이 세 개인 T만 추가로 계산하면 회전·대칭을 포함한 모든 모양을 덮는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    rows = fs.nextInt();
    cols = fs.nextInt();
    a = new int[rows][cols];
    seen = new boolean[rows][cols];
    for (int r = 0; r < rows; r++) for (int c = 0; c < cols; c++) a[r][c] = fs.nextInt();
    for (int r = 0; r < rows; r++) for (int c = 0; c < cols; c++) {
      seen[r][c] = true;
      dfs(r, c, 1, a[r][c]);
      seen[r][c] = false;
      int[] near = new int[4];
      int count = 0;
      for (int k = 0; k < 4; k++) {
        int x = r + dr[k],
          y = c + dc[k];
        if (valid(x, y)) near[count++] = a[x][y];
      }
      if (count >= 3) {
        Arrays.sort(near, 0, count);
        best = Math.max(
          best,
          a[r][c] + near[count - 1] + near[count - 2] + near[count - 3]
        );
      }
    }
    System.out.println(best);
  }

  static int rows, cols, best;
  static int[][] a;
  static boolean[][] seen;
  static int[] dr = { -1, 1, 0, 0 },
    dc = { 0, 0, -1, 1 };

  static boolean valid(int r, int c) {
    return r >= 0 && c >= 0 && r < rows && c < cols;
  }

  static void dfs(int r, int c, int count, int sum) {
    if (count == 4) {
      best = Math.max(best, sum);
      return;
    }
    for (int k = 0; k < 4; k++) {
      int x = r + dr[k],
        y = c + dc[k];
      if (valid(x, y) && !seen[x][y]) {
        seen[x][y] = true;
        dfs(x, y, count + 1, sum + a[x][y]);
        seen[x][y] = false;
      }
    }
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

시간 O(NM), DFS 깊이 4 상수, 공간 O(NM).

DFS만 작성하면 T를 놓친다. 테두리에서 이웃이 세 개 미만이면 T 후보가 아니다.
