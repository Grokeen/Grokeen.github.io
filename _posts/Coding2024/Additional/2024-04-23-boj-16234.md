실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

하루의 연합은 그날 시작 인구를 기준으로 결정한다. 모든 연합의 평균을 계산한 뒤 동시에 반영하며 더 이상 열린 국경이 없으면 종료한다.

## 풀이 순서

1. 하루마다 방문 배열과 다음 인구 배열을 새로 만든다.
2. 인구 차가 L~R인 이웃을 BFS로 묶는다.
3. 연합 평균을 다음 배열에 기록하고 하루 종료 후 교체한다.

## 풀이가 성립하는 이유

연합은 조건을 만족하는 간선으로 연결된 요소다. 같은 요소를 한 번만 탐색하고 원래 인구로 모든 간선을 판단하면 갱신 순서에 따른 결과 차이를 막는다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt(),
      low = fs.nextInt(),
      high = fs.nextInt();
    int[][] a = new int[n][n];
    for (int r = 0; r < n; r++) for (int c = 0; c < n; c++) a[r][c] = fs.nextInt();
    int days = 0;
    int[] dr = { -1, 1, 0, 0 },
      dc = { 0, 0, -1, 1 };
    while (true) {
      boolean[][] seen = new boolean[n][n];
      int[][] next = new int[n][n];
      boolean moved = false;
      for (int r = 0; r < n; r++) for (int c = 0; c < n; c++) if (!seen[r][c]) {
        List<Integer> cells = new ArrayList<>();
        Deque<Integer> q = new ArrayDeque<>();
        q.add(r * n + c);
        seen[r][c] = true;
        int sum = 0;
        while (!q.isEmpty()) {
          int p = q.poll(),
            x = p / n,
            y = p % n;
          cells.add(p);
          sum += a[x][y];
          for (int k = 0; k < 4; k++) {
            int rr = x + dr[k],
              cc = y + dc[k];
            if (rr < 0 || cc < 0 || rr >= n || cc >= n || seen[rr][cc]) continue;
            int diff = Math.abs(a[x][y] - a[rr][cc]);
            if (diff >= low && diff <= high) {
              seen[rr][cc] = true;
              q.add(rr * n + cc);
            }
          }
        }
        if (cells.size() > 1) moved = true;
        int avg = sum / cells.size();
        for (int p : cells) next[p / n][p % n] = avg;
      }
      if (!moved) break;
      a = next;
      days++;
    }
    System.out.println(days);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 복잡도와 주의점

하루 O(N²), 총 O(DN²), 공간 O(N²). D는 실제 이동 일수.

연합 평균은 정수 나눗셈이다. 한 칸짜리 요소만 있으면 이동 일수를 늘리지 않는다.
