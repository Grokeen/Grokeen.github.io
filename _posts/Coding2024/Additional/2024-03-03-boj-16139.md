실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

같은 문자열의 구간에서 특정 문자가 몇 번 나오는지 반복 질의한다. 알파벳별 누적 개수를 만들면 각 질의를 두 값의 차이로 처리할 수 있다.

## 풀이 순서

1. 각 문자마다 길이 N+1의 누적 배열을 만든다.
2. 문자를 하나 읽을 때 이전 빈도를 복사하고 해당 문자만 늘린다.
3. 0기준 [l,r] 질의는 prefix[r+1]-prefix[l]로 계산한다.

## 풀이가 성립하는 이유

길이 위치와 문자 인덱스를 분리해 누적하면 앞 l개를 제외한 r까지의 문자 개수만 남는다. 질의마다 부분 문자열을 새로 만들 필요가 없다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    String s = fs.next();
    int[][] p = new int[26][s.length() + 1];
    for (int i = 0; i < s.length(); i++) {
      for (int c = 0; c < 26; c++) p[c][i + 1] = p[c][i];
      p[s.charAt(i) - 'a'][i + 1]++;
    }
    int q = fs.nextInt();
    while (q-- > 0) {
      int c = fs.next().charAt(0) - 'a',
        l = fs.nextInt(),
        r = fs.nextInt();
      out.append(p[c][r + 1] - p[c][l]).append("\n");
    }
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
abaca
3
a 0 4
b 2 4
c 3 3
```

**기대 출력**

```text
3
0
1
```

**예제 2 입력**

```text
a
1
a 0 0
```

**기대 출력**

```text
1
```

## 복잡도와 주의점

시간 O(26N+Q), 공간 O(26N+Q).

질의 좌표는 0부터이고 오른쪽 끝을 포함한다. 누적 배열에서는 r+1을 사용한다.
