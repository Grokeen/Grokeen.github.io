실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

사방으로 연결된 집을 한 단지로 보고 각 단지의 크기를 센다. 대각선은 연결에 포함하지 않는다. 단지 수와 정렬된 크기를 함께 출력한다.

## 풀이 순서

1. 미방문 집에서 BFS를 시작한다.
2. 방문한 집 수를 단지 크기로 기록한다.
3. 모든 크기를 오름차순으로 출력한다.

## 풀이가 성립하는 이유

각 집은 한 번 큐에 들어가므로 정확히 한 단지에 속한다. 새 시작점의 수가 단지 수이고 탐색 중 센 정점 수가 그 단지의 크기다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    char[][] a = new char[n][];
    for (int i = 0; i < n; i++) a[i] = fs.next().toCharArray();
    List<Integer> sizes = new ArrayList<>();
    int[] dr = { -1, 1, 0, 0 },
      dc = { 0, 0, -1, 1 };
    for (int r = 0; r < n; r++) for (int c = 0; c < n; c++) if (a[r][c] == '1') {
      int size = 0;
      Deque<Integer> q = new ArrayDeque<>();
      a[r][c] = '0';
      q.add(r * n + c);
      while (!q.isEmpty()) {
        int p = q.poll(),
          x = p / n,
          y = p % n;
        size++;
        for (int k = 0; k < 4; k++) {
          int nr = x + dr[k],
            nc = y + dc[k];
          if (nr >= 0 && nc >= 0 && nr < n && nc < n && a[nr][nc] == '1') {
            a[nr][nc] = '0';
            q.add(nr * n + nc);
          }
        }
      }
      sizes.add(size);
    }
    Collections.sort(sizes);
    out.append(sizes.size()).append("\n");
    for (int x : sizes) out.append(x).append("\n");
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3

001
```

**기대 출력**

```text

```

**예제 2 입력**

```text
1
0
```

**기대 출력**

```text
0
```

## 복잡도와 주의점

시간 O(N²+C log C), 공간 O(N²). C는 단지 수.

입력 한 줄은 공백 없는 숫자 문자열이다. 섬의 개수와 달리 사방만 이동한다.
