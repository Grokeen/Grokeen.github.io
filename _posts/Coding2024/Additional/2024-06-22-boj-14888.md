실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

수의 순서는 고정하고 연산자 배치만 탐색한다. 일반 수식 우선순위가 아니라 왼쪽부터 차례대로 계산하며 음수 나눗셈은 0을 향해 버린다.

## 풀이 순서

1. 남은 연산자 개수를 종류별로 관리한다.
2. 한 종류를 사용해 현재 값과 다음 수를 계산한다.
3. 끝에서 최댓값·최솟값을 갱신하고 개수를 복원한다.

## 풀이가 성립하는 이유

각 경로는 가능한 연산자 배치 하나다. 같은 종류를 구별하지 않고 남은 개수로 선택하므로 중복을 줄이면서 모든 유효 배치를 포함한다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    n = fs.nextInt();
    a = new long[n];
    for (int i = 0; i < n; i++) a[i] = fs.nextLong();
    for (int i = 0; i < 4; i++) ops[i] = fs.nextInt();
    dfs(1, a[0]);
    System.out.println(max + "\n" + min);
  }

  static int n;
  static long[] a;
  static int[] ops = new int[4];
  static long min = Long.MAX_VALUE,
    max = Long.MIN_VALUE;

  static void dfs(int at, long value) {
    if (at == n) {
      min = Math.min(min, value);
      max = Math.max(max, value);
      return;
    }
    for (int k = 0; k < 4; k++) if (ops[k] > 0) {
      ops[k]--;
      long next = k == 0
        ? value + a[at]
        : k == 1
          ? value - a[at]
          : k == 2
            ? value * a[at]
            : value / a[at];
      dfs(at + 1, next);
      ops[k]++;
    }
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3
5 6 2
0 1 0 1
```

**기대 출력**

```text
0
-2
```

**예제 2 입력**

```text
2
7 3
0 0 0 1
```

**기대 출력**

```text
2
2
```

## 복잡도와 주의점

시간 O(연산자 배치 수·N), 공간 O(N).

곱셈 우선으로 다시 계산하면 틀린다. Java 정수 나눗셈은 음수에서도 0 방향 절삭이다.
