실버·골드권 문제를 연습하는 추가 100문제 중 한 편이다.

> 2024년 1~6월 공부 순서로 재구성한 Java 11 학습 노트다. [원문 접근 상태·난도 분류·실행 범위](/study/2024/baekjoon/#source)를 확인한다. 아래 예제는 직접 구성했으며 온라인 정답 판정 기록은 아니다.

## 문제를 이해한 방식

좌표를 x 우선, 동률이면 y 순으로 정렬한다. 요구한 기준을 비교 함수에 차례대로 연결한다.

## 풀이 순서

1. 좌표를 2열 배열에 저장한다.
2. x 비교 뒤 y 비교를 연결한다.
3. 정렬된 두 값을 한 줄씩 출력한다.

## 풀이가 성립하는 이유

사전식 비교는 첫 값이 다르면 그 결과를 쓰고 같을 때만 두 번째 값을 비교한다. 좌표를 문자열로 바꾸거나 x+y로 정렬하면 이 순서와 다르다.

## Java 풀이

아래 전체를 UTF-8 Main.java로 저장한다. javac --release 11 -encoding UTF-8 Main.java로 컴파일한 뒤 java -Dfile.encoding=UTF-8 Main으로 실행하고 입력을 전달한다.

{% raw %}
```java
import java.io.*;
import java.util.*;

public class Main {

  static final FastScanner fs = new FastScanner(System.in);

  public static void main(String[] args) throws Exception {
    StringBuilder out = new StringBuilder();
    int n = fs.nextInt();
    int[][] a = new int[n][2];
    for (int[] p : a) {
      p[0] = fs.nextInt();
      p[1] = fs.nextInt();
    }
    Arrays.sort(
      a,
      Comparator.comparingInt((int[] p) -> p[0]).thenComparingInt(p -> p[1])
    );
    for (int[] p : a) out.append(p[0]).append(" ").append(p[1]).append("\n");
    System.out.print(out);
  }

  static final class FastScanner {

    private final InputStream in;
    private final byte[] buffer = new byte[1 << 16];
    private int ptr, len;

    FastScanner(InputStream in) {
      this.in = in;
    }

    private int read() throws IOException {
      if (ptr >= len) {
        len = in.read(buffer);
        ptr = 0;
        if (len < 0) return -1;
      }
      return buffer[ptr++] & 255;
    }

    String next() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) return null;
      ByteArrayOutputStream b = new ByteArrayOutputStream();
      while (c > 32 && c != -1) {
        b.write(c);
        c = read();
      }
      return b.toString("UTF-8");
    }

    long nextLong() throws IOException {
      int c;
      do {
        c = read();
      } while (c <= 32 && c != -1);
      if (c == -1) throw new EOFException();
      int sign = 1;
      if (c == 45) {
        sign = -1;
        c = read();
      }
      long value = 0;
      while (c > 32 && c != -1) {
        value = value * 10 + c - 48;
        c = read();
      }
      return value * sign;
    }

    int nextInt() throws IOException {
      return Math.toIntExact(nextLong());
    }
  }
}
```

## 직접 만든 확인 예제

**예제 1 입력**

```text
3
1 2
0 9
1 -1
```

**기대 출력**

```text
0 9
1 -1
1 2
```

**예제 2 입력**

```text
1
-2 3
```

**기대 출력**

```text
-2 3
```

## 복잡도와 주의점

시간 O(N log N), 공간 O(N).

x가 같을 때 두 번째 기준을 빠뜨리지 않는다. 비교 뺄셈 대신 comparingInt를 사용한다.
