main·컴파일·실행의 순서을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

JDK는 컴파일러와 실행 도구를 제공한다. public 클래스 이름과 파일 이름을 맞추고 main을 진입점으로 사용한다. 이 과정은 Java 11 문법을 기준으로 한다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.io.*;
import java.math.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.*;
import java.util.*;
import java.util.stream.*;

public class Main {

  public static void main(String[] args) throws Exception {
    System.out.println("Java 11");
    System.out.println(args.length);
  }
}
```
{% endraw %}

## 확인 결과

```text
Java 11
0
```

## 코드를 따라 읽기

javac가 소스를 바이트코드로 만들고 java가 Main 클래스를 실행한다. 인자를 주지 않으면 args 배열 길이는 0이다. IDE 실행 버튼도 이 과정을 대신 수행한다.

## 헷갈린 부분과 주의점

JRE만 설치한 환경에는 javac가 없을 수 있다. java Main.java 소스 실행과 javac 후 클래스 실행의 명령을 섞지 않는다.

## 복습 문제

인자를 두 개 주면 두 번째 줄은?

**풀이:** args.length가 2가 된다.
