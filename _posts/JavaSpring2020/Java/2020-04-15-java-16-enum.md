enum으로 허용된 상태 표현하기을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

enum은 정해진 값의 집합을 타입으로 표현한다. 문자열 오타를 줄일 수 있지만 상태 전이 규칙까지 자동으로 정해 주지는 않는다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.io.*;
import java.math.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.*;
import java.util.*;
import java.util.stream.*;

public class Main {

  public static void main(String[] args) throws Exception {
    State state = State.READY;
    if (state == State.READY) state = State.DONE;
    System.out.println(state);
  }

  enum State {
    READY,
    DONE,
  }
}
```
{% endraw %}

## 확인 결과

```text
DONE
```

## 코드를 따라 읽기

상태를 enum 상수로 비교하고 변경한다. ==로 enum 상수를 비교할 수 있다. 외부 문자열을 valueOf로 바꿀 때는 허용되지 않은 값의 예외 처리를 검토한다.

## 헷갈린 부분과 주의점

ordinal을 영구 저장 코드로 사용하면 선언 순서 변경에 취약하다. 외부 저장용 코드는 명시적으로 설계한다.

## 복습 문제

valueOf에 소문자 ready를 주면?

**풀이:** 대소문자가 일치하지 않아 IllegalArgumentException이 발생한다.
