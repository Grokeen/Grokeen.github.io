ArrayDeque로 큐와 스택 다루기을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

Deque는 양쪽 끝에서 넣고 뺄 수 있다. 큐는 뒤에 넣고 앞에서 빼며 스택은 같은 쪽에서 넣고 뺀다. 빈 경우 null을 돌려주는 poll과 예외를 던지는 remove를 구분한다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.io.*;
import java.math.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.*;
import java.util.*;
import java.util.stream.*;

public class Main {

  public static void main(String[] args) throws Exception {
    Deque<Integer> q = new ArrayDeque<>();
    q.offerLast(1);
    q.offerLast(2);
    System.out.println(q.pollFirst());
    q.push(3);
    System.out.println(q.pop());
    System.out.println(q.pollFirst());
  }
}
```
{% endraw %}

## 확인 결과

```text
1
3
2
```

## 코드를 따라 읽기

큐에서 1을 뺀 뒤 앞에 3을 push했다. pop은 앞의 3을 제거하고 남은 2를 pollFirst로 꺼낸다. 알고리즘에서 한 자료구조를 사용할 때 연산 방향을 통일한다.

## 헷갈린 부분과 주의점

ArrayDeque는 null 원소를 허용하지 않는다. 빈 큐의 반환값과 실제 null 데이터를 구분할 필요가 없다.

## 복습 문제

빈 deque의 pollFirst 결과는?

**풀이:** null이다.
