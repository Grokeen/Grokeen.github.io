기본형·참조형·배열 복사의 차이을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

기본형 변수에는 값이 저장되고 참조형 변수에는 객체를 가리키는 참조가 저장된다. 참조를 복사했다고 객체까지 복제되는 것은 아니다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.io.*;
import java.math.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.*;
import java.util.*;
import java.util.stream.*;

public class Main {

  public static void main(String[] args) throws Exception {
    int a = 3;
    int b = a;
    b = 9;
    int[] x = { 3 };
    int[] y = x;
    y[0] = 9;
    System.out.println(a + " " + b);
    System.out.println(x[0]);
  }
}
```
{% endraw %}

## 확인 결과

```text
3 9
9
```

## 코드를 따라 읽기

b의 변경은 a와 무관하다. 반면 x와 y는 같은 배열을 가리키므로 y를 통한 원소 변경이 x에서도 보인다. 배열 전체 복사가 필요하면 복사 API를 선택한다.

## 헷갈린 부분과 주의점

참조의 공유와 두 변수의 이름이 같은지 여부를 혼동하지 않는다. 다차원 배열은 바깥 배열 복사만으로 내부까지 독립되지 않는다.

## 복습 문제

y=x.clone()이었다면 x[0]은?

**풀이:** 원소가 int인 1차원 배열이므로 3으로 남는다.
