반복 범위와 누적 변수를 분리하기을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

반복문은 시작값, 계속 조건, 증가 규칙으로 읽는다. 배열을 순회할 때 마지막 유효 인덱스는 길이보다 1 작다. 합계를 저장할 자료형은 입력 전체 합의 범위로 정한다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.util.*;
import java.util.stream.*;
import java.math.*;
import java.io.*;
import java.nio.file.*;
import java.nio.charset.StandardCharsets;
import java.time.*;

public class Main {
  public static void main(String[] args) throws Exception {
    int[] values={2,4,6};
    long sum=0;
    for(int i=0;i<values.length;i++) sum+=values[i];
    System.out.println(sum);
  }

}
```
{% endraw %}

## 확인 결과

```text
12
```

## 코드를 따라 읽기

i는 0,1,2를 거치고 3에서 종료된다. 누적 변수는 반복문 바깥에 두어 매번 초기화되지 않는다. 인덱스가 필요 없다면 향상된 for문으로 같은 합을 구할 수 있다.

## 헷갈린 부분과 주의점

i<=values.length는 마지막에 배열 범위를 넘는다. continue 뒤에 필요한 갱신이 건너뛰어지는지도 확인한다.

## 복습 문제

빈 배열의 합은?

**풀이:** 반복을 한 번도 하지 않아 초기값 0이다.
