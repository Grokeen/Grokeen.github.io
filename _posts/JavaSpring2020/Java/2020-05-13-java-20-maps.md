Map으로 빈도 집계하기을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

Map은 키에 값을 연결한다. 같은 키에 put하면 기존 값이 교체되므로 빈도 집계에서는 누적 연산이 필요하다. 결과 출력 순서가 필요하면 정렬되는 구현이나 별도 정렬을 선택한다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.io.*;
import java.math.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.*;
import java.util.*;
import java.util.stream.*;

public class Main {

  public static void main(String[] args) throws Exception {
    Map<String, Integer> count = new TreeMap<>();
    for (String s : Arrays.asList("b", "a", "b")) count.merge(s, 1, Integer::sum);
    System.out.println(count);
  }
}
```
{% endraw %}

## 확인 결과

```text
{a=1, b=2}
```

## 코드를 따라 읽기

merge는 키가 없으면 1을 넣고 있으면 기존 값과 1을 더한다. TreeMap을 선택해 키 순서대로 출력되도록 했다. HashMap의 순서를 기대하지 않는다.

## 헷갈린 부분과 주의점

null 허용 여부와 동시성 보장은 구현마다 다르다. 공유 Map에 복합 연산을 할 때는 별도 검토가 필요하다.

## 복습 문제

b를 한 번 더 읽으면?

**풀이:** merge 결과로 b의 값이 3이 된다.
