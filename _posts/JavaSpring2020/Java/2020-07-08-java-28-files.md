UTF-8 파일 읽기·쓰기와 경로을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

문자 인코딩을 명시하면 운영체제 기본 문자셋 차이로 한글이 깨지는 문제를 줄일 수 있다. 임시 파일은 예제에서 새로 만들고 사용 후 정리한다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.io.*;
import java.math.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.*;
import java.util.*;
import java.util.stream.*;

public class Main {

  public static void main(String[] args) throws Exception {
    Path p = Files.createTempFile("java-note-", ".txt");
    try {
      Files.writeString(p, "공부", StandardCharsets.UTF_8);
      System.out.println(Files.readString(p, StandardCharsets.UTF_8));
    } finally {
      Files.deleteIfExists(p);
    }
  }
}
```
{% endraw %}

## 확인 결과

```text
공부
```

## 코드를 따라 읽기

Java 11의 writeString과 readString으로 문자열을 처리한다. 파일 내용과 인코딩을 함께 지정했다. finally에서 이 예제가 만든 임시 파일만 지운다.

## 헷갈린 부분과 주의점

상대 경로는 현재 작업 디렉터리 기준이다. 실제 사용자 파일을 예제 경로로 덮어쓰지 않는다.

## 복습 문제

실행 폴더가 바뀌면 상대 경로도 바뀔까?

**풀이:** 같은 문자열이어도 기준 작업 폴더에 따라 가리키는 파일이 달라진다.
