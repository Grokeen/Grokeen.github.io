Instant·OffsetDateTime·시간대을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

Instant는 타임라인의 한 순간이고 OffsetDateTime은 UTC 오프셋을 포함한다. 지역 시간대의 역사적 규칙이 필요하면 ZoneId와 ZonedDateTime을 사용한다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.util.*;
import java.util.stream.*;
import java.math.*;
import java.io.*;
import java.nio.file.*;
import java.nio.charset.StandardCharsets;
import java.time.*;

public class Main {
  public static void main(String[] args) throws Exception {
    Instant instant=Instant.parse("2020-01-01T00:00:00Z");
    System.out.println(instant.atOffset(ZoneOffset.ofHours(9)));
    System.out.println(instant.atOffset(ZoneOffset.UTC));
  }

}
```
{% endraw %}

## 확인 결과

```text
2020-01-01T09:00+09:00
2020-01-01T00:00Z
```

## 코드를 따라 읽기

같은 순간을 +09:00과 UTC로 표시했다. 시계 숫자는 다르지만 Instant로 되돌리면 같다. 서버 저장, 사용자 표시, 날짜만 필요한 자료를 구분해 타입을 선택한다.

## 헷갈린 부분과 주의점

오프셋 하나는 지역의 모든 과거·미래 시간대 규칙을 표현하지 않는다. 서버 기본 시간대에 무조건 의존하지 않는다.

## 복습 문제

두 출력의 순간은 다를까?

**풀이:** 표시는 다르지만 같은 순간이다.
