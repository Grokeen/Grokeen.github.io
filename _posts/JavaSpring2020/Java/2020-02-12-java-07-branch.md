조건문에서 경계값을 먼저 확인하기을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

범위 조건은 겹침과 빈틈이 없어야 한다. Java 11의 switch는 전통적인 문장 형태를 사용하고 최신 switch 표현식을 이 과정에 섞지 않는다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.io.*;
import java.math.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.*;
import java.util.*;
import java.util.stream.*;

public class Main {

  public static void main(String[] args) throws Exception {
    int score = 80;
    String grade;
    if (score >= 90) grade = "A";
    else if (score >= 80) grade = "B";
    else grade = "C";
    System.out.println(grade);
  }
}
```
{% endraw %}

## 확인 결과

```text
B
```

## 코드를 따라 읽기

큰 경계부터 검사했기 때문에 90 이상이 B 분기에 먼저 들어가지 않는다. 80을 포함하는지 >와 >=를 직접 비교해 확인한다. 유효 범위 검증은 등급 분류와 별도로 둘 수 있다.

## 헷갈린 부분과 주의점

score가 100보다 크거나 음수인 입력을 어떻게 처리할지 정하지 않으면 분류가 되더라도 올바른 입력은 아닐 수 있다.

## 복습 문제

score가 90이면?

**풀이:** 첫 분기가 실행되어 A가 된다.
