배열 정렬과 복사 범위을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

배열은 길이가 고정된다. copyOfRange의 끝 인덱스는 포함하지 않으므로 [시작, 끝) 범위로 읽는다. 정렬은 대상 배열의 순서를 직접 변경한다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.io.*;
import java.math.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.*;
import java.util.*;
import java.util.stream.*;

public class Main {

  public static void main(String[] args) throws Exception {
    int[] a = { 4, 1, 3, 2 };
    int[] part = Arrays.copyOfRange(a, 1, 3);
    Arrays.sort(part);
    System.out.println(Arrays.toString(part));
    System.out.println(Arrays.toString(a));
  }
}
```
{% endraw %}

## 확인 결과

```text
[1, 3]
[4, 1, 3, 2]
```

## 코드를 따라 읽기

인덱스 1과 2의 값만 새 배열로 복사했다. 복사본을 정렬해도 기본형 원소를 가진 원본 배열의 순서는 유지된다. 원본과 복사본의 변경 범위를 확인하는 예제다.

## 헷갈린 부분과 주의점

객체 배열은 원소 객체 참조가 공유될 수 있다. 배열 복사와 객체 깊은 복사를 구분한다.

## 복습 문제

copyOfRange(a,0,1)의 길이는?

**풀이:** 1이며 첫 원소만 포함한다.
