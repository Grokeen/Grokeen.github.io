문자 수·UTF-8 바이트 수 구분하기을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

문자열 길이와 네트워크·파일의 바이트 수는 다르다. Java String.length는 UTF-16 코드 단위 수이며 사용자에게 보이는 글자 수와도 항상 같지 않다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.io.*;
import java.math.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.time.*;
import java.util.*;
import java.util.stream.*;

public class Main {

  public static void main(String[] args) throws Exception {
    String s = "가A";
    System.out.println(s.length());
    System.out.println(s.getBytes(StandardCharsets.UTF_8).length);
  }
}
```
{% endraw %}

## 확인 결과

```text
2
4
```

## 코드를 따라 읽기

가와 A는 이 예제에서 각각 한 UTF-16 코드 단위다. UTF-8에서는 가가 3바이트, A가 1바이트여서 합계가 4다. 저장 길이 제한이 문자 기준인지 바이트 기준인지 먼저 확인한다.

## 헷갈린 부분과 주의점

이모지처럼 서로게이트 쌍을 사용하는 문자는 length가 2일 수 있다. 바이트를 중간에서 자르면 인코딩이 깨질 수 있다.

## 복습 문제

UTF-8 바이트 수를 String.length로 알 수 있을까?

**풀이:** 아니다. 지정한 인코딩으로 변환한 바이트 길이를 확인해야 한다.
