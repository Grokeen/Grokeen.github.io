인스턴스 상태와 static 상태을 예제로 확인하며 정리했다.

> 2020년 학습 순서를 재구성한 공부 노트다. Java 11 기준이며 실제 근무·수강 이력을 주장하지 않는다. [실행 준비와 공통 pom.xml](/study/2020/java-spring/#run)을 먼저 확인한다.

## 오늘 정리한 개념

인스턴스 필드는 객체마다 생기고 static 필드는 클래스에 속한다. 가변 static 상태는 여러 요청이나 테스트가 공유할 수 있어 주의해야 한다.

## 따라 해 보기

아래 전체를 UTF-8 Main.java로 저장한 뒤 javac --release 11 -encoding UTF-8 Main.java, java -Dfile.encoding=UTF-8 Main으로 실행한다.

{% raw %}
```java
import java.util.*;
import java.util.stream.*;
import java.math.*;
import java.io.*;
import java.nio.file.*;
import java.nio.charset.StandardCharsets;
import java.time.*;

public class Main {
  public static void main(String[] args) throws Exception {
    Box a=new Box(); Box b=new Box();
    a.count++; b.count+=2;
    System.out.println(a.count+" "+b.count);
    System.out.println(Box.created);
  }
    static class Box { static int created; int count; Box(){created++;} }
}
```
{% endraw %}

## 확인 결과

```text
1 2
2
```

## 코드를 따라 읽기

두 Box의 count는 독립적이다. 생성자에서 증가하는 created는 두 객체가 공유하는 클래스 필드다. 객체별 값과 전체 집계 값을 분리해 읽는다.

## 헷갈린 부분과 주의점

웹 서버의 여러 요청이 공유하는 static 가변 필드에는 동시성 문제가 생길 수 있다. 요청 데이터를 임시 저장하지 않는다.

## 복습 문제

세 번째 Box를 만들면 created는?

**풀이:** 같은 클래스 로더 범위에서 3이 된다.
