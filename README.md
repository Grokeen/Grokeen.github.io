# 미니홈피 기록 보관함

싸이월드 미니홈피의 분위기로 글과 추억을 둘러보는 Jekyll 정적 웹사이트입니다. 제본형 화면과 미니룸을 중심으로 게시글, 경제신문 스크랩, 사진첩과 음악 플레이어를 제공합니다.

## 주요 기능

- 홈: 최근 게시글, 미니룸과 일촌평
- 프로필: 소개 화면과 기분·스킨 선택
- 다이어리: 월별 달력과 날짜별 메모
- 사진첩: 분류별 사진 보기와 확대
- 게시판: 기술 문서·경제신문 스크랩 목록과 제목 검색
- 방명록: 방문 메시지 입력과 삭제
- BGM: 재생·일시정지, 곡 변경과 음량 조절
- 청첩장: 별도 레이아웃을 사용하는 독립 페이지

경제신문 스크랩은 기사 출처와 발행일을 함께 기록합니다. AI 관련 글은 주요 내용, 기술·산업의 변화, 향후 전망과 사회적 쟁점을 나눠 다룹니다.

다이어리·일촌평·방명록 입력은 현재 열린 페이지의 메모리에서만 유지되며 새로고침하면 초기화됩니다. 계정·방문자 추적이나 서버 저장 기능은 없습니다. 방문 카운터와 도토리는 장식용 표시입니다.

## 기술과 구성

Jekyll과 Markdown으로 게시글을 생성하고 HTML·CSS·JavaScript로 화면과 상호작용을 구성합니다. GitHub Pages에서 정적 파일을 제공합니다.

| 경로 | 역할 |
| --- | --- |
| _layouts/ | 미니홈피·게시글·청첩장 레이아웃 |
| _posts/ | 게시글과 경제신문 스크랩 |
| css/, js/, img/ | 스타일·기능·이미지 |
| _data/ | 페이지 데이터 |
