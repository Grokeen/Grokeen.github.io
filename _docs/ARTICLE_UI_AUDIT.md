# 일반 게시글 UI 점검

2026-10-16, 배포 커밋 `d7f6a4d1d1d3e44ced70fd7716d94aadad975417` 기준으로 확인했다. 청첩장은 점검·수정 대상에서 제외했다.

## 확인 결과

공개 미니홈피 게시판에 연결된 일반 게시글 459개의 HTTP 응답과 HTML을 확인했다. 모두 200 응답이며 `blog-page → blog-shell → blog-paper → article-page` 틀과 `/css/blog.css`를 사용한다. 개별 본문에서 전역 스타일을 추가하는 `style` 또는 스타일시트 링크는 없었다.

설치된 Chrome을 별도 헤드리스 테스트 프로세스로 실행했다. 459개 글을 320px·390px·1440px 폭에서 각각 렌더링하여 1,377개 화면의 페이지 가로 넘침, 최상위 본문 요소의 영역 이탈, 공통 문서 폭과 글꼴을 확인했다. 검사한 조건에서 넘침과 문서 틀 누락은 없었다. 대표 글 8개는 데스크톱·모바일 화면을 비교하고 이미지도 확인했다.

| 화면 폭 | 본문 글자 크기 | 공통 글꼴 |
| --- | --- | --- |
| 320px | 15px | Malgun Gothic / Apple SD Gothic Neo / sans-serif |
| 390px | 15px | Malgun Gothic / Apple SD Gothic Neo / sans-serif |
| 1440px | 16px | Malgun Gothic / Apple SD Gothic Neo / sans-serif |

실행 중인 로컬 Jekyll 서버를 사용했으며, 로컬에서 이미 삭제되어 있는 기존 기술 글은 공개 HTML을 읽어 공통 로컬 자산으로 렌더링했다. 사용자의 기존 삭제 상태를 복원하거나 커밋하지 않았다. 연결된 브라우저 도구가 제공되지 않아 사용자 브라우저를 조작하지 않고 독립 테스트 프로세스로 검사했다.

## 확인 범위의 한계

제목의 길이, 이미지·표·문제 형식에 따라 본문 배치와 제목 높이는 달라질 수 있다. 이번 검사에서는 글별로 다른 공통 UI가 적용되는 현상을 재현하지 못했으므로 근거 없는 레이아웃 변경은 하지 않았다. 사용자 브라우저의 캐시·확장 프로그램·운영체제 글꼴 환경까지 검증한 것은 아니다. 특정 게시글 주소나 제목을 전달받으면 해당 화면을 추가 비교한다.

기존 30개 사이트 검사는 게시글 문서·정적 자산·목차·코드 보존·청첩장 독립 레이아웃 등을 통과한 상태다. 원시 검사 결과와 스크린샷은 배포에서 제외한 `.jekyll-local/ui-audit/`에 저장했다.
