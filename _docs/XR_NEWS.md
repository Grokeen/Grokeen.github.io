# AR·VR·XR 경제신문스크랩 작업 기록

- 요청 기간: 2025-01-01 ~ 2026-10-16
- 작성: 서로 다른 공식 원문 100개, 게시글 100편
- 실제 선택된 기사 게시일: 2025-01-08 ~ 2026-10-14
- 목록: `/scrap/xr/`
- 전체 파일·날짜·출처·본문·확인 방법: `XR_NEWS_MANIFEST.json`

## 구성과 작성 기준

Apple 6편, Google 5편, Snap 13편, Meta 뉴스룸 3편·개발자 자료 24편, Qualcomm 4편, NVIDIA 2편, HTC VIVE 26편, XREAL 3편, Samsung 3편, Sony 1편, Khronos 3편, Niantic Spatial 7편을 정리했다. 제품·반도체·입력·운영체제·개발 도구·표준·기업 운영·교육·의료·공연·문화유산·창작 경제를 포함한다.

각 글은 기존 경제신문스크랩 형식의 핵심 내용, 변화, 전망, 사회적 쟁점으로 작성했다. 전망·쟁점은 작성자의 해석으로 표시하며 기업의 성능·비용·이용자 수는 발표 조건 안에서 읽는다. 원문 전문이나 보도자료를 번역 복제하지 않고 한국어로 요약했다.

동일 원문 URL과 제목을 중복하지 않았다. 같은 플랫폼의 후속 글은 최초 도구 공개·정식 버전·실물 시험 지원처럼 확인되는 새 단계나 별도 활용 사례를 중심으로 구분했다. 같은 문화 작품의 예고·개막·영화제 선정은 여러 편으로 반복하지 않았다. 기존 AI·로봇 묶음과 원문 URL의 중복도 검사한다.

## 출처와 날짜 검토

- 원문 본문과 공개일을 확인하고 게시일·행사일·배포일·후속 수정일을 구분했다. 조사 기준일은 2026-10-16이다.
- Meta Ray-Ban Display의 현지 최초 발표일 2025-09-17과 UTC 메타데이터 2025-09-18 차이를 설명했다. 판매 시작 업데이트도 따로 표시했다.
- XREAL의 영문 게시일은 본문 행사 보도자료 날짜와 다를 수 있어 둘을 함께 설명했다. 날짜만 표시된 값을 시간대 변환해 전날로 바꾸지 않았다.
- VIVE 블로그의 날짜는 공개 CMS의 `publish_date`와 본문 표시를 대조했다. 뉴스룸 3편은 본문에 별도 일자가 없어 공식 날짜 URL을 기준으로 했음을 명시했다.
- Qualcomm의 JavaScript 본문 3편은 검색 도구로 읽었다. Reality Elite 발표는 원문 HTML이 연결하는 공식 `.md` 대체 문서로 본문을 확인했다.
- 미리보기·시제품·초기 접근·베타·판매 예정과 실제 제공을 구분했다. Meta VR Glasses는 2027년 봄 판매 예정이라는 원문 범위를 유지했다.

## 과장과 혼동 방지

화면 없는 AI 안경, 작은 렌즈 표시형 안경, 공간 디스플레이, 광학·비디오 투과형 XR, VR 헤드셋을 구분했다. 근전도 입력은 생각을 읽는 기술로 설명하지 않았다. 자동 2D→3D 변환은 실제 깊이의 정확한 복원으로 표현하지 않았다.

의료 도입과 공급사 기고는 독립 임상시험·보편적 치료 효과로 바꾸지 않았다. Cineon 보고의 승인 범위는 TACET Walkaround의 OTD로 한정하고 비행 훈련 전체의 인증으로 확대하지 않았다. OpenXR 확장 지원은 모든 엔진·기기에서의 자동 호환을 보장하지 않음을 설명했다.

Eternal Notre-Dame 원문의 방문자 수가 제목·본문과 URL·중간 제목에서 달라 수치를 인용하지 않았다. 해당 원문의 실제 성당 재개관 날짜도 옮기지 않았다. 역사 체험은 고증·추정·극적 재구성을 구분해 설명했다.
