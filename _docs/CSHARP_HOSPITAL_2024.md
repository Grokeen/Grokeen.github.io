- 게시 날짜: 2024-05-01 ~ 2024-12-31. 학습용 날짜를 재구성했다.

## 내용과 버전

C# 12·.NET 8을 기준으로 하며 C# 13 이후 기능을 섞지 않는다. 병원 업무는 기존 프로젝트의 바코드·자료 처리·RPA 흐름과 연결해 작성했다. 실제 환자·직원·기관 정보 대신 TEST 접두사의 가상 ID와 임의 값을 사용한다. FHIR R4 자원과 DICOM 2024c는 업무 개념의 참고이며 예제 내부 record를 해당 표준 전체의 구현으로 표시하지 않는다. 임상 판단·수가·급여·실제 신고·법적 보존 기간을 임의로 정하지 않는다.

Microsoft, HL7, DICOM, OWASP 공식 문서를 확인하고 각 글에 관련 링크를 제공한다. 출처와 날짜·파일·기대 출력은 [목록 파일](CSHARP_HOSPITAL_2024_MANIFEST.json)에 둔다.

## 실행 검증

`scripts/validate-csharp-notes.py`는 게시글의 C# 코드를 추출해 C# 12·net8.0으로 컴파일한다. 예제별 별도 네임스페이스로 자료형 이름을 격리하고 각 실행의 표준 출력을 포착해 본문 결과와 비교한다. 문화권을 InvariantCulture로 고정하며 외부 NuGet 소스를 비워 추가 패키지에 의존하지 않는다. 로컬 SDK는 8.0.100이다.

HTTP는 모의 핸들러, DB는 메모리 모델, 병원 업무는 가상 자료만 사용한다. 파일 예제는 새 임시 파일만 만들고 정리한다. 실제 병원 서버·장비·결제·진료 업무에 연결하지 않으며 운영 호환성을 검증했다고 주장하지 않는다. GitHub Actions에서도 .NET 8 SDK를 선택해 같은 검사를 실행한다.

```bash
python3 scripts/validate-csharp-notes.py
npm test
```

사이트 검사는 개수·기간·순서·목차·각 글의 코드와 결과·링크·게시판 노출을 확인한다. README와 청첩장은 변경하지 않는다. 기존 작업 폴더의 67개 삭제 상태는 별도 사용자 작업으로 유지한다.
