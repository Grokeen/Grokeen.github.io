# 2024 C#·원무행정 노트 작성 기록

총 80편: C# 48편, 병원 원무·행정 절차 32편. 날짜는 2024-05-01~12-31 학습 순서로 재구성했다. 목차는 `/study/2024/csharp-hospital/`다. 병원 글은 사용자 범위 확인에 따라 전산 자동화 예제를 원무·행정 절차, 가상 사례, 풀이로 교체했다. 기존 파일·주소·학습 순서를 유지했다.

## 내용과 근거

C#은 C# 12·.NET 8 기준으로 Microsoft 공식 문서를 참고한다. 병원 글은 실제 근무 경험 대신 가상 사례를 사용한다. 외래·예약·입퇴원·수납·증명서·기록 사본·정보 보호·마감·인수인계를 다룬다. 임상 판단과 행정 업무를 구분하고 임의의 수가·보험 부담률·보관 기간을 제시하지 않는다.

2024-05-20 건강보험 본인확인 시행은 2024-04-12 보건복지부 정책 안내를 확인했다. 기록 신청은 의료법 시행규칙 2024-09-26 시행본(보건복지부령 제1056호, lsiSeq=265647) 제13조의3을 확인했다. 가족과 지정 대리인의 서류 요건, 연령별 예외를 구분한다. 동의 불가능 사례는 별표 확인 필요성을 명시하고 미확인 구비서류 목록을 만들지 않았다. 서류 보관은 문서별 근거를 확인하도록 안내한다.

서울대학교병원 절차와 건강보험심사평가원 안내는 업무 흐름을 이해하는 공식 참고이며 특정 기관의 2024년 운영 전체를 복원했다는 주장은 하지 않는다. 원문과 사례별 출처는 각 게시글 및 [목록 파일](CSHARP_HOSPITAL_2024_MANIFEST.json)에 있다.
