# 로봇 경제신문스크랩 100편

2023-01-01~2026-10-16 범위에서 공식 연구·제조사·고객·산업 단체 자료 100편을 정리했다. 채택 자료의 실제 발표·게시일 범위는 2023-01-03~2026-09-30이며 정리 기준일은 2026-10-16이다. 공개 목차는 `/scrap/robotics/`, 파일·출처·본문 대응은 [목록](ROBOTICS_NEWS_MANIFEST.json)에 있다.

## 구성과 편집

Google Research·DeepMind 17편, NVIDIA 30편, Boston Dynamics 12편, Agility Robotics 10편, Figure 9편, Amazon 10편, IFR 12편이다. 원문 전문을 복제하지 않고 한국어 요약·변화·전망·사회적 쟁점을 작성했다. 기업 사례의 성능·안전·비용·최초 주장은 해당 회사의 발표로 한정했다. 전망과 쟁점은 해석으로 표시했다.

VLA·공간 추론·보상 설계·보행·촉각·시뮬레이션·데이터 공유·엣지 계산·군집 운영과 물류·제조·농업·식품·해양·에너지·의료·돌봄 사례를 포함한다. 같은 모델 계열은 새로운 발표·평가·현장 결과가 있는 사건을 선정했다. 같은 원문을 나눠 세거나 기존 최근 1년 AI 글의 로봇 기사 3편을 다시 추가하지 않았다.

## 날짜와 수치의 해석

- 계약·MOU·예정 생산 능력과 실제 생산·판매·운영 대수를 구분했다. BMW의 자동차 생산 기여는 판금 적재 공정 참여이며 자동차 전체 자율 조립으로 쓰지 않았다.
- IFR는 보고서 공개 연도와 집계 연도를 분리했다. 서비스 로봇 표본 239개사(2023 보고서)·298개사(2024)·294개사(2025)는 모집단 전체 추정치가 아니다. IFR의 안내에 따라 서로 다른 연도 보고서의 합계를 이어 증가율을 재계산하지 않았다. 산업용 로봇의 가동 기반과 신규 설치도 구분했다.
- ROSCon 행사 예고·초기 접근·베타·정식 제공·후속 계획을 나눠 적었다. Jetson Thor와 IGX Thor는 제품과 제공 일정이 다르다.
- NVIDIA 본문의 현지 표시일과 JSON-LD UTC 날짜가 다른 경우 본문 표시일을 사용하고 원문 메타데이터를 함께 기록했다. Hyundai Mobis 공지의 사건일과 재게시일도 구분했다.
- Blue Jay의 2025년 발표에는 원문이 명시한 2026-02-25 운영 사용 종료를 함께 적었다. Vulcan 원문의 2026년 후속 업데이트를 2025년 최초 발표 성과로 섞지 않았다.
- 수술·돌봄·세포 제조의 연구 또는 사례 소개를 임상 효능·제품 전체의 안전 인증·일반 사용 승인으로 표현하지 않았다. 공개 프레임워크나 부품의 안전 기능을 완성 시스템의 인증으로 일반화하지 않았다.

## 출처와 화면 검사

선정한 공식 원문 100개의 본문과 날짜를 확인했다. 사이트의 관련 기사 카드나 빈 main 요소가 본문으로 수집된 일부 페이지는 실제 기사 본문을 다시 읽었다. Boston Dynamics NFI 공지는 사이트 메타데이터와 달리 본문 사건이 2022년이므로 제외하고 다른 2024년 기술 글로 대체했다.

`tests/news-expansion.test.cjs`는 기존 AI·과거 AI·로봇 사이 원문 중복, 기간·개수·날짜 예외·공통 본문 레이아웃·목차·실제 출처 링크를 검사한다. 출처 제목의 파이프 문자가 표를 만드는 Markdown 변환 문제도 검사한다. README와 청첩장은 변경하지 않았다.
