# 2022~2023 AI·빅데이터 경제신문스크랩

2022-01-01~2023-03-31 범위의 공식 발표·연구·정책 자료 108편을 추가했다. 실제 채택 자료의 날짜는 2022-01-21~2023-03-31이다. 2022-11-30 ChatGPT 첫 공개와 2023년 Plus·API·GPT-4·플러그인 발표를 각각 별도 사건으로 다룬다.

기존 경제신문스크랩의 content 레이아웃과 네 개 본문 항목을 따른다. 공개 목차는 `/scrap/ai-bigdata-2022-2023/`다. 파일·원문·날짜·본문의 대응은 [목록](HISTORICAL_AI_NEWS_MANIFEST.json)에 보관한다. 원문 전문은 게시하지 않았다.

## 편집과 날짜 기준

모델·데이터셋·MLOps·분산 처리·쿼리 엔진·클라우드 조달·반도체·산업 활용·데이터 정책을 포함한다. 동일 원문을 나눠 세지 않았고, 기존 최근 1년 AI 글과도 원문 URL을 대조했다. 전망·사회적 쟁점은 해석으로 표시하고 기업의 성능 주장을 독립 검증 결과로 쓰지 않았다.

미리보기·제안·계획과 정식 제공을 구분했다. 특히 Spark Connect는 2022년 설계 제안, MLflow 2.0은 당시 예정된 버전, Snowflake Hybrid Tables·Native Application Framework는 비공개 미리보기다. GPT-4의 영상 입력 연구를 모든 사용자의 이미지 입력 정식 제공으로 설명하지 않았다.

원문의 수정일을 최초 발표일로 사용하지 않았다. ChatGPT·Whisper API의 현재 본문 수정일은 2024-04-24이므로 공식 개발자 공지의 2023-03-01을 보완 근거로 기록했다. AlphaCode는 원문이 구분하는 2월 발표와 12월 Science 업데이트 중 후자의 날짜에 배치했다. Data Act의 공식 요약 페이지 표시일과 실제 제안 사건일, NVIDIA 대학 시설 기사의 현지 표시일과 UTC 메타데이터, FTC 문서 날짜와 페이지 생성 메타데이터의 차이는 해당 본문에 명시했다. 법안·협상 입장·임시 조치를 최종 법률이나 현재 상태로 일반화하지 않았다.

## 출처 확인과 검증

공식 원문 본문을 읽어 요약했다. 직접 HTTP 접근이 막힌 일부 OpenAI·EU 이사회 자료는 웹 도구로 확인했으며 HTTP 200으로 기록하지 않았다. 목록의 `source_verification`에 확인 방식을 구분했다. 단순 URL 응답 성공만으로 기사 내용을 확인했다고 처리하지 않았다.

`tests/news-expansion.test.cjs`는 기간·개수·원문 중복·날짜 예외 설명·ChatGPT 첫 공개 포함 여부와 빌드된 108개 본문·목차를 검사한다. README와 청첩장은 변경하지 않았다. 개발 결과는 이 문서에만 기록한다.
