# 개발 기록

프로젝트 소개는 [README](../README.md), 실행 방법은 [실행 가이드](RUNNING.md)에 둔다. 이 문서는 구현·수정 내용과 검증 범위를 기록한다.

## 미니홈피와 일반 게시글

- 이력서·자기소개서·지원 기록·개인 사진·연락처를 현재 소스에서 제거하고 일반 문서의 개인 경로를 예시로 바꿨다. 과거 Git 커밋은 별도로 남아 있다.
- 홈 화면에 프로필·최근 소식·미니룸·일촌평·세로 탭·BGM 플레이어를 구성했다.
- [아시아경제의 과거 미니홈피 화면](https://cm.asiae.co.kr/article/2019101912224446735)을 참고했다. 기존 미니룸 이미지를 유지하고 기본 미니미와 노을은 SVG로 작성했다.
- 일반 게시글의 HTML 문서와 스타일을 정리하고 긴 코드·표·이미지를 본문 안에서 읽을 수 있도록 구성했다.
- 청첩장은 별도 레이아웃·스타일·스크립트를 유지했다.

## 경제신문 스크랩

- URL 위주로 남아 있던 기존 파일 10개를 보완했다.
- 2025-10-16부터 2026-10-16까지의 기간을 대상으로 AI 관련 글 108편을 추가했다.
- 기사 발행일과 기존 스크랩 파일명의 날짜를 구분하고, 기업 발표와 전망·해석을 표시했다.
- 조사 기준·출처·예외는 [조사 기록](AI_NEWS_RESEARCH.md)에 남겼다.

## BGM 자동 재생

- 미니홈피에 접속하면 기본 볼륨 40%로 음악 재생을 시도한다.
- 브라우저가 소리 있는 자동 재생을 차단하면 화면 클릭·터치·키 입력 때 다시 시도하고 안내 문구를 표시한다. [브라우저 자동 재생 정책](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay) 때문에 모든 환경에서 접속 즉시 소리가 나는 것을 보장할 수는 없다.
- 직접 일시정지한 뒤에는 다른 화면 조작으로 음악이 다시 켜지지 않는다. 곡 이동과 재생·일시정지 버튼은 기존처럼 사용할 수 있다.
- 자동 재생 성공·차단·첫 화면 조작·직접 정지·재생 요청 경합·파일 오류를 오디오 API 대역으로 확인한다.

## 2021 파이썬·라즈베리파이 학습 노트

- 2021-01-04부터 2021-12-27까지 파이썬 72편과 라즈베리파이 36편, 총 108편을 추가했다.
- 개념·예제·실행 결과 또는 장비 확인 방법·코드 해설·주의점·복습 문제와 풀이·공식 문서 링크를 각 글에 담았다. 목차와 앞뒤 학습 링크로 이어 읽을 수 있다.
- 학습용으로 날짜를 재구성했다는 점을 목차에서 설명하며 장비 실험을 수행한 것처럼 기록하지 않는다.
- 검증 방법과 환경 기준은 [학습 노트 작성 기록](STUDY_2021.md)에 둔다. README는 프로젝트 소개로 유지한다.

## 검증과 범위

2022년 지방세 개념 노트 120편을 추가했다. 월별 10편씩 설명·가상 사례·풀이·당시 조문을 제공하며 [작성 기록](LOCAL_TAX_2022.md)에 역사적 기준과 산술 검증 범위를 적었다.

일반 게시글 UI 차이 제보에 따라 공개 글 459개와 3가지 화면 폭의 렌더링을 확인했다. 결과와 검사 한계는 [UI 점검 기록](ARTICLE_UI_AUDIT.md)에 남겼다.

2021~2023년 정보처리기사 40편·빅데이터분석기사 32편을 개념별로 추가했다. 창작 문제와 풀이, 합성 자료 실습을 제공하며 [작성 기록](CERTIFICATION_2021_2023.md)에 역사적 기준과 예제 검증 방법을 적었다.

2024년 5~12월 C# 48편·병원 업무 자동화 32편을 추가했다. 설명·예제·풀이와 단계별 목차를 제공하며 [작성·검증 기록](CSHARP_HOSPITAL_2024.md)에 실행 환경과 모의 예제의 범위를 적었다.

Node.js 검사에서는 메뉴·입력·달력·제목 검색·사진첩·음악 제어, 일반 게시글 문서·정적 자산·목록, 청첩장 독립 레이아웃, 스크랩 수·기간·출처·본문 생성을 확인한다. 오디오와 대화상자 API는 DOM 검사에서 대역을 사용하며 실제 오디오 출력이나 브라우저 화면 배치를 검증한 것은 아니다.

개발 의존성은 `npm ci`로 설치하고 Jekyll 빌드 뒤 `npm test`를 실행한다. GitHub Pages 자동 배포도 같은 검사를 실행한다.
